# Riffra Arrange画面仕様

## 1. スコープ

Arrangeワークスペース（トラック・クリップの配置／編集／録音を行う画面）の画面仕様を正準化する。

### 書くこと

- 画面の全体構造とシェル（トップバー・サイドパネル・トランスポートバー）との関係
- Arrangeワークスペースを構成する各領域（ツールバー・ルーラー・タイムライン・トラック・ロワーパネル・インスペクタ）の仕様
- 操作（選択・編集・ドラッグ&ドロップ・ショートカット）の仕様
- インスペクタ・トランスポートバーが持つ状態と編集手段

### 書かないこと

- 各操作の裏にあるセッション編集の正確な仕様とレイヤー適用規則（`architecture.md` 参照）
- クリップ描画の実装詳細（波形のピーク計算方法など）（code参照）
- Design ワークスペースの仕様
- 各API呼び出しのシグネチャ（code参照）

層構造と状態遷移は `architecture.md`、IPC契約は `ipc.md`、エンティティ定義は `data-model.md` を参照。

## 2. 画面の全体構造

```text
┌──────────────────────────────────────────────────────────────────┐
│ GlobalBar（セッション名／アンドゥ・リドゥ／ワークスペース／コマンド／音声設定／同期状態）│
├──────────┬───────────────────────────────────────┬──────────────┐
│ Library  │         Arrange ワークスペース        │  Inspector   │
│ パネル   │  ┌─────────────────────────────────┐  │  パネル      │
│          │  │ ArrangeToolbar（ツール・スナップ  │  │              │
│          │  │  ・ズーム・ルーラー・フォロー・    │  │              │
│          │  │  オートメーション）              │  │              │
│          │  ├─────────────────────────────────┤  │              │
│          │  │ タイムライン                    │  │              │
│          │  │  （ルーラー・グリッド・プレイヘッド │  │              │
│          │  │  ・トラックレーン・クリップ）     │  │              │
│          │  ├─────────────────────────────────┤  │              │
│          │  │ ロワーパネル（Play Surface /     │  │              │
│          │  │  MIDI Editor）                  │  │              │
│          │  └─────────────────────────────────┘  │              │
├──────────┴───────────────────────────────────────┴──────────────┤
│ TransportBar（マスターゲイン・BPM・拍子・再生／停止・録音・メーター）      │
└──────────────────────────────────────────────────────────────────┘
```

- レイアウトは `apps/desktop/src/components/layout/` のシェルコンポーネントと `components/arrange/WorkspaceArrange.tsx` で構成される。
- ライブラリ・インスペクタ・ロワーパネルの幅／高さはドラッグで変更できる。矢印キー操作は±8px、Shift押下時は±24px。
- パネルは折りたたみ可能（高さ48pxのタブバーだけ残る）。
- インスペクタの既定サイズ: 幅280px（最小220px／最大420px）。ライブラリパネルの既定サイズ: 幅220px（最小176px／最大360px）。
- ワークスペース切替（`1` キー=Arrange、`2` キー=Design）とフォーカスモードでパネル表示が切り替わる。

## 5. タイムライン

### 5.1 ルーラー

- クリック／ドラッグで再生位置（プレイヘッド）をシーク。
- ドラッグ量が4pxを超えると**タイムセレクション**を作成する。選択範囲はチップ表示され、「Set Loop」「Set Punch」ボタンでループ／パンチ範囲に反映できる。
- **マーカー**: ルーラーのコンテキストメニュー「Add Marker Here」または `M` キー（プレイヘッド位置）で追加。リネーム・削除・移動が可能。
- **ループ範囲**: ルーラー上の帯と両端ハンドルで設定。コンテキストメニューに「Set Loop to Selection」「Clear Loop」。
- **パンチ範囲**: 同様に帯とハンドルで設定（録音の置き換え範囲）。「Set Punch Range」「Clear Punch」。
- 選択時にクリップが選択されている場合は、ループ範囲は選択クリップに合わせて設定される（クリップ単位のループ設定）。

### 5.2 グリッドとプレイヘッド

- グリッドは小節・拍・分割単位の密度で表示され、SNAP設定に従う。
- プレイヘッドは再生中 `requestAnimationFrame` で描画される。
- グリッド／クリップはSNAPに基づく量子化位置へ吸着して移動・リサイズされる（`useArrangeEditor.ts` のスナップロジック）。

### 5.3 トラックレーン

`ArrangeTrack.tsx`

| 要素               | 仕様                                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| ヘッダー           | トラック名（ダブルクリックでリネーム）、MUTE／SOLO／ARM／MONITORING トグル（楽観的UI: コミット完了までPending表示）、INSTRUMENT／AUDIO種別タグ |
| ミックス表示       | トラックサイズが compact 以外のときヘッダー下部にゲイン・パン表示                                                                              |
| サイズ変更         | ヘッダー下端のハンドルをドラッグで compact → normal → large を循環（25px移動ごとに1段階）                                                      |
| 並べ替え           | トラックヘッダーをドラッグして順序変更（dataTransfer に `x-riffra-track` をセット）                                                            |
| 複製・削除         | ヘッダーから複製、削除（確認ダイアログ付き）                                                                                                   |
| インストゥルメント | ヘッダーにPlay Surface起動ボタンを持つ                                                                                                         |
| レーン             | クリップのタイムスタンプ重なりに応じて `laneCount` が増え、トラック内で上下にレーンが分割される。レーン高さはトラックサイズで決まる            |

### 5.4 クリップ

- **オーディオクリップ** (`AudioClipView`): 波形表示。フェードイン／アウトハンドル、左右トリムハンドル、ミュート、ループ設定。
- **MIDIクリップ** (`MidiClipView`): ノートデータのサマリ描画。ダブルクリックでMIDIエディタを開く。
- **クリップのコンテキストメニュー**: プレイヘッド位置での分割（Split at Playhead）、複製（Duplicate）、ミュート、ループ、前後のクリップとの結合（Merge with Previous／Next）、MIDIクリップには量子化（Quantize）も表示。
- **選択**: クリップクリックで単一選択。Ctrl+クリックで追加選択。タイムライン上のドラッグ（マーキー）で矩形選択（Ctrlで追加）。選択中クリップは `selectedClipIds` で強調表示される。

### 5.5 ドラッグ&ドロップ

- ライブラリからのアセット投入（`RIFFRA_ASSET_MIME`）。オーディオトラックはMIDIを拒否し、その逆も同様に種別検証を行う。
- OSファイルマネージャからの `.mid`／`.midi` の投入はMIDIクリップとして配置される。
- トラック間のクリップ移動はクリップのドラッグで行う。

### 5.6 空状態

トラックが無いときは「Start arranging」の空状態を表示し、「Add Audio Track」「Add Instrument Track」を提供する。ここへアセットをドロップしても追加できる。録音はトランスポートバーの Record を使用する。

### 5.7 録音プレビュー

録音中（`transport.recordingPhase !== 'idle'`）は、録音開始位置からの進行をハイライト帯（recording preview）で表示する。帯には `{PHASE} · {アーム済みトラック名} · PASS {n}` を表示する。

### 5.8 オートメーション

オートメーショントグルが有効なとき、選択トラックの下にオートメーションレーン（`AutomationLaneView`）を表示する。パラメータ（音量ほか）をレーン上で変更できる。

## 6. ロワーパネル

`arrange/lower-panel/ArrangeLowerPanel.tsx`

- タブ: **Play Surface** ／ **MIDI Editor**。MIDI EditorタブはアクティブなMIDIクリップが無い場合は無効（`activeMidiClip` が null）。
- タブ右にコンテキスト表示（Play Surface時はサマリ、MIDI Editor時はクリップ名）。
- リサイズハンドルで高さを変更（150px〜ワークスペース高の55%）。56px以下で折りたたみ、折りたたみ時は48px。
- Play Surface: 選択したインストゥルメントトラックのMIDI鍵盤・ドラムパッドの演奏面。
- MIDI Editor: 選択クリップのノート編集（追加・削除・長さ・ピッチ・ベロシティ）。

## 7. インスペクタ

選択状態に応じて以下のいずれかを表示する（`arrange/` 配下のInspectorコンポーネント）。

| インスペクタ       | 表示内容                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| TrackInspector     | ゲイン・パンなどのミックス、プラグインチェーン（並べ替え・追加・削除・欠落プラグイン表示）、インストゥルメント設定 |
| AudioClipInspector | 名前・開始位置・ループ・ミュート、ゲイン・パン、フェード、ループ設定のクリップ反映                                 |
| MidiClipInspector  | ノート一覧・ベロシティ・量子化・削除                                                                               |
| TakeInspector      | 録音テイク一覧（§7.1）                                                                                             |
| MultiClipInspector | 複数クリップ選択時の共通編集                                                                                       |

### 7.1 テイク（TakeInspector）

- 選択クリップが録音テイクを持つとき、同一録音セッション・同一トラックのテイクを一覧表示する（Take 1, Take 2, ...）。
- 操作: **Preview**（単独試聴）、**Use**（アクティブテイク切替）、**Place copy**（別クリップとして配置）。
- raw と processed の両方が存在するテイクは **A/B比較** できる（`startTakeComparison` で開始し、`switchTakeComparisonVariant` で raw／processed を切替。A · RAW / B · PROCESSED 表示）。インスペクタが閉じると比較は停止する。

## 8. トランスポートバー

`layout/TransportBar.tsx`

| 要素           | 仕様                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 再生／停止     | Play ／ Stop ボタン。Go To Start で先頭へ                                                                                              |
| 録音           | Record トグル。アーム中トラックがあれば録音開始（コミット待ち中は操作中表示）                                                          |
| マスターゲイン | ドラフト編集（40msデバウンスで `previewMasterGainDb` を送信して試聴）→ 確定で `setMasterGainDb` をコミット。失敗時は直前の確定値に戻す |
| テンポ／拍子   | BPM（20〜400）と拍子（2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 9/8, 12/8）を編集してコミット。Arrangeワークスペースでのみ有効                     |
| メーター       | `useAudioMeters` によるレベルメーター表示                                                                                              |
| ステータス行   | 接続状態ドットと、再生中の録音サンプル数または音声エンジンの最新メッセージを表示                                                       |

## 9. ステータス・通知

アプリ全体の一時的通知は、右下のトースト領域（`components/shared/ToastStack.tsx`、`lib/toasts.ts`）に集約する。

- **同期ズレ通知**: Arrange でセッションとUIが整合しないとき、トーストに「Playback runtime is out of sync」とRetryボタンを表示する。
- **再生スキップ通知**: 欠落ソース・欠落デバイスのために再生をスキップしたクリップ数があるとき、その旨を表示する（「Playback skipped N missing sources and M missing devices.」）。
- **編集メッセージ**: エディタ操作の成否メッセージ（`useArrangeEditor` の `message`）を自動消滅トーストで表示する。
- 起動時にセーフモード／リカバリ状態の場合はバナーを表示する。

## 10. ショートカット

### 10.1 グローバル（`hooks/useApp.ts`）

- `Ctrl+K` コマンドパレット、`Esc` 閉じる
- `Ctrl+Z` アンドゥ、`Ctrl+Shift+Z`／`Ctrl+Y` リドゥ
- `Ctrl+Shift+M` 選択トラックのミュート切替
- `1` Arrange ワークスペース、`2` Design ワークスペース

### 10.2 Arrange（`hooks/arrange/useArrangeEditor.ts`）

- `Ctrl+A` 全クリップ選択、`Ctrl+C` コピー、`Ctrl+V` ペースト、`Ctrl+D` 複製（ペーストをクリップ末尾に配置）
- `Ctrl+E` プレイヘッド位置で分割（Split）
- `Delete` 選択クリップの削除／選択範囲・マーカーの削除
- `M` プレイヘッド位置にマーカーを追加
- `Z` タイムセレクションの範囲にズーム（倍率は 0.35〜4.0 にクランプ。タイムセレクションが無い場合は何もしない）
- `F` 全クリップを包む範囲にフィット（クリップが無い場合は何もしない）
- `Esc` ルーラー選択（タイムセレクション・ループ・パンチ）の解除、ダイアログを閉じる
