# リズムセクション

ドラム、ベース、そして全体のグルーヴを扱う。リズムセクションは拍の土台、低域の動き、パート間の関係を同時に担う。前半でリズムそのものの構造、中盤でドラムとベースそれぞれの設計、後半でパート間の噛み合わせとフィールを扱い、最後に既存グルーヴを見るときの観点をまとめる。

## 1. リズムの構造

### 拍と分割

同じテンポでも、内部をどう数えるかでグルーヴの性格が変わる。拍子は小節の大きな周期、分割はその内部の時間感を作る。

| 感じ方       | 例               | 聞こえ方                                 |
| ------------ | ---------------- | ---------------------------------------- |
| 4分中心      | `1 2 3 4`        | 大きく安定した脈を感じやすい             |
| 8分中心      | `1 & 2 & ...`    | Rock/Pop系の基本的な推進を作りやすい     |
| 16分中心     | `1 e & a ...`    | 細かなアクセントやGhost Noteを置きやすい |
| 3連中心      | `1-trip-let ...` | Swing、Shuffle、Triplet feelへつながる   |
| 5連・7連など | 拍を5・7等分     | 均等分割とは異なる流れや装飾を作れる     |

### アクセント

アクセントは、同じ発音数のままリズムの重心を変える方法である。16分を並べても、強調位置が違えば別のパターンとして聞こえる。

| 方法          | 変化                     | 効果                         |
| ------------- | ------------------------ | ---------------------------- |
| Velocity      | 音量差を付ける           | 強拍・弱拍を明確にする       |
| Open / Closed | Hi-hatなどの奏法を変える | 特定位置だけ余韻を広げる     |
| 楽器変更      | Hat→Ride、Snare→Tomなど  | 同じリズムへ別の重心を与える |
| 音価          | 一部だけ長くする         | 長い音が区切りや頂点になる   |
| 同時発音      | Crash + Kickなどを重ねる | セクション境界を強く示す     |
| 休符          | 直前を空ける             | 次のAttackを強調する         |

Accent pattern自体を数小節単位で反復すると、Kick/Snare配置とは別の層にモチーフを作れる。

### シンコペーション

拍の予想と実際の強調位置をずらすことで、前進感や引っ掛かりを作る。

| 形                   | 例                                 | 効果                             |
| -------------------- | ---------------------------------- | -------------------------------- |
| 裏拍アクセント       | `&` を強くする                     | 拍の間へ推進を作る               |
| 先取り               | 次の拍の音を少し前に出す           | 次の拍へ引っ張る                 |
| 拍をまたぐ保持       | 裏から始めた音を次の強拍まで伸ばす | 強拍のAttackを消して浮遊感を作る |
| 強拍を空ける         | 1拍目などを休符にする              | 前後の音を目立たせる             |
| パターン全体のずらし | 同じ形を16分1つ分ずらす            | 元の形を保ちながら重心だけ変える |

シンコペーションはKick、Snare、Hi-hat、Bass、コード伴奏のどのパートでも作れる。どのパートが拍をずらすかの分担については「5. パート間のグルーヴ」で扱う。

### グルーピング

細かな刻みを`3+3+2`のようなまとまりとして感じさせると、拍子を変えずに内部の流れを変えられる。同じ8つの8分音符でも、アクセントや休符の位置の違いだけで別のグループとして聞こえる。

```text
3 + 3 + 2
X.. X.. X.
```

```text
3 + 2 + 3
X.. X. X..
```

```text
2 + 3 + 3
X. X.. X..
```

使い方の例:

- Kickだけを`3+3+2`にする
- BassとKickで同じグルーピングを共有する
- Hi-hatは均等、Snare/Tomだけを3音周期にする
- 1小節を越えて`3+3+3+3+2+2`のような長い周期を作る

Tresilloはこの考え方の代表例で、ドラムだけでなくBass、コード伴奏、メロディへも移せる。

### Swing / Shuffle

等間隔の8分を長短のある時間配置へ変えることで生まれる。

```text
Straight:  long = short
Swing:    long > short
```

Swingの比率はテンポや演奏によって幅を持ち、弱いSwingではStraightに近く、強いSwingでは三連系の長短がはっきりする。同じSwing感でもアクセントの置き場所で性格が変わる。

- RideでSwingの流れを示す
- Hi-hatでShuffleを刻む
- BassだけSwing寄りにする
- Snare Ghost Noteを3連内部へ置く

Swingはタイミング比だけでなく、Accent、音価、Velocityと組み合わさってフィールを作る。

### 反復セルと変奏

グルーヴには、短いリズムセルを繰り返して認識させる方法がある。

| 形          | 内容                             |
| ----------- | -------------------------------- |
| `A A A B`   | 4小節目だけ大きく変える          |
| `A A' A B`  | 2小節目に小変化、4小節目に大変化 |
| `A B A C`   | 問いと応答を2種類作る            |
| `A A' B B'` | 前半と後半で別セルを展開する     |

`A'`の変化は、Kickを1音追加する、Ghost Noteを変える、Hi-hatを一度開くといった小さな差でも成立する。反復感を保ったまま流れを作れる。

### 複数のリズム層

複数パートが同じ周期を共有する形だけでなく、異なる周期を重ねる形もある。

**位相をずらす**: 同じパターンを少しずらして重ねると、形そのものは同じでもAttack位置のずれが継続的な動きを生む。

```text
A: X---X---X---X---
B: --X---X---X---X-
```

**異なるグルーピングを重ねる**: 4の拍感の上に3音周期、8分の均等なHatの上に`3+3+2`のKickなど。こうした重なりは、片方が拍の基準を示していると認識しやすい。

**Polyrhythm / Polymeter**: `3:2`のように異なる分割を同時に鳴らす方法や、パートごとに異なる拍節周期を持つ方法。短い装飾として使う形から、曲全体の構造にする形まで幅がある。

### 複数小節の展開

1小節のパターンをそのまま繰り返すだけでなく、2・4・8小節へ段階的な変化を置ける。

| 長さ  | 変化の例                           |
| ----- | ---------------------------------- |
| 1小節 | Ghost Note、Kick 1音、Hat Accent   |
| 2小節 | Bassの終端、Snare装飾              |
| 4小節 | Fill、Register移動、Percussion追加 |
| 8小節 | Feel変更、Break、Section移行       |

```text
Bar 1: A
Bar 2: A'
Bar 3: A
Bar 4: B
```

8小節では、後半へ向けて差を大きくする形も作れる。

```text
A  A'  A  B
A  A'  C  Fill
```

複数小節の展開では、「どの音を増やすか」だけでなく、**どの要素を維持して同じグルーヴだと感じさせるか**が重要になる。

## 2. 名前付きパターン

名前付きパターンは、特定の配置、フィール、地域的なグルーヴ、特定録音から広まったブレイクなど、指す範囲がそれぞれ異なる。名前そのものより、**何がそのパターンを特徴づけているか**を見ると応用しやすい。完成形のテンプレートとして使うことも、特徴の一部だけ借りることも、別のパターンと組み合わせることもできる。

### Pop / Rock / Dance

| 名称                             | 核となる特徴                                                                | 変化させやすい要素                                 |
| -------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------- |
| **Backbeat**                     | 4/4でSnareを主に2・4拍へ置く                                                | Kick、Hi-hat、Ghost Note、Fill                     |
| **Basic Rock Beat**              | Backbeat + 8分Hi-hat + Kickの基本形                                         | Kick位置、Hi-hat密度、Open Hat、Fill               |
| **Money Beat**                   | Rock系で広く使われる簡潔なBackbeat系パターン                                | Kick配置、Hi-hat、ゴースト、2小節目の変化          |
| **Four-on-the-floor / 四つ打ち** | Kickを1・2・3・4拍すべてに置く                                              | Snare、Offbeat Hat、16分Hat、Percussion            |
| **Disco Groove**                 | 四つ打ち + 2・4のSnare + 裏拍のOpen Hatが代表的                             | Hi-hatの開閉、16分の細かな動き、Bassとの噛み合わせ |
| **Half-time**                    | Backbeatの周期を広げ、4/4ではSnareを主に3拍目へ感じさせる                   | Hi-hatの細かさ、Kick、Ghost Note                   |
| **Double-time**                  | Backbeatや刻みを倍速側へ感じさせる                                          | Kick密度、Cymbal、Snareの位置                      |

### Punk / Metal

| 名称                   | 核となる特徴                                         | 変化させやすい要素                   |
| ---------------------- | ---------------------------------------------------- | ------------------------------------ |
| **D-beat**             | 高速な8分系のKick/Snare配置を核にしたHardcore/Punk系 | Cymbal、Kick、テンポ                 |
| **Blast Beat**         | Snare、Cymbal、Kickを高速で密集させるMetal系技法     | SnareとKickの交互/同時、Cymbal、速度 |
| **Double-kick Groove** | 2 Pedal / 2 Bassで連続的なKickを作る                 | 8分、16分、3連、シンコペーション     |

展開の例として、四つ打ちのKickだけを借りてSnare/Hatを別の語彙に変える、TresilloをBassだけに移す、Purdie ShuffleのGhost Noteの考え方だけ使う、といった部分借用ができる。

## 3. ドラム

### Kick / Snare / Hi-hatの役割

ドラムセットでは、各パートが違う時間層を担当できる。

| パート               | 主に作れるもの                             | 変化させると変わること            |
| -------------------- | ------------------------------------------ | --------------------------------- |
| **Kick**             | 拍の土台、低域のアクセント、Bassとの一体感 | グルーヴの前進感、低域の密度      |
| **Snare**            | Backbeat、強い区切り、応答                 | 拍の重心、Half-time/Double-time感 |
| **Hi-hat / Ride**    | 8分・16分・3連などの細かな刻み             | 全体の速度感、Swing感、密度       |
| **Ghost Note**       | 主アクセント間の細かな動き                 | 内部のノリ、Velocity階層          |
| **Crash / Open Hat** | 境界、頂点、強調                           | セクション感、フレーズの区切り    |
| **Tom / Percussion** | Fill、別周期、色付け                       | 移行感、リズム層の追加            |

**Kick**: 強拍中心なら拍を明確にし、裏拍中心ならシンコペーションを強める。連打は一時的な推進やFill、Bassと同時なら低域のAttackをまとめ、Bassの隙間なら低域を掛け合いにする。

**Snare**: 2・4拍のBackbeatを保つほか、3拍目中心に置けばHalf-time、細かなGhost NoteはBackbeatの周囲に内部運動を追加し、拍直前/直後の装飾は次のBackbeatを強調する。

**Hi-hat / Ride**: 刻み方で曲の表面速度が大きく変わる。

| 刻み      | 印象                       |
| --------- | -------------------------- |
| 4分       | 大きく簡潔                 |
| 8分       | 安定した基本Pulse          |
| 16分      | 細かな推進                 |
| 3連       | Swing / Shuffle系          |
| 一部休符  | Patternに穴を作る          |
| Open Hat  | 特定位置を伸ばしてAccent化 |
| Ride Bell | 高域の強い周期を作る       |

### Ghost Note

主要なSnareやBass Drumより小さい音で、**主アクセントの間に細かな運動を作る**。

| 置く場所         | 効果                                     |
| ---------------- | ---------------------------------------- |
| Backbeat直前     | Snareへ向かう短い導入を作る              |
| Backbeat直後     | 強いSnareの余韻に応答する                |
| 16分の空き位置   | 細かな刻みを補い、Funk的な内部運動を作る |
| 3連の空き位置    | Shuffle / Swingの中間を埋める            |
| Kickの隙間       | KickとSnareで掛け合いを作る              |
| Hi-hatの弱い位置 | Hatとは別のVelocity層を加える            |

存在感は音数より**強弱差**で決まる。主要Snareと同じ強さに近づくほど独立したAccentとして聞こえ、小さくするほど内部の揺れとして聞こえる。

### ドラムパターンを変える軸

| 軸         | 変えるもの                           | 変化する印象               |
| ---------- | ------------------------------------ | -------------------------- |
| 発音位置   | Kick/Snare/Hatの位置                 | リズム骨格そのもの         |
| 密度       | 発音数                               | 活動量、推進               |
| Accent     | 強調位置                             | 重心、周期感               |
| Velocity   | 強弱差                               | 人間的な階層、Ghost感      |
| 奏法       | Open Hat、Cross-stick、Ride Bellなど | 音色、余韻、セクション感   |
| 楽器配置   | Hat→Ride、Snare→Tomなど              | 同じリズムでも別の色へ変化 |
| 音価       | 長くする/短く切る                    | 空間、次の音とのつながり   |
| タイミング | Swing、前ノリ、後ノリ                | フィール                   |

同じパターンでも、Hi-hatだけを8分から16分へ変える、SnareをCross-stickへ変える、4小節目だけOpen Hatを入れる、といった変化で十分に別の表情を作れる。

### Fill

通常のグルーヴから一時的に変化し、次の拍・小節・フレーズ・セクションへ接続する役割を持つ。

| 種類               | 内容                             | 主な効果                        |
| ------------------ | -------------------------------- | ------------------------------- |
| リズムFill         | 発音位置を増減・変形             | 元Patternとの連続性を保ちやすい |
| Tom Fill           | Snare/Tomへ音を移す              | 音域移動で区切りを作る          |
| Snare Fill         | Snare連打、Rudiment、Ghostの拡大 | 強い前進感                      |
| Kick Fill          | Kickの連打や細かな配置           | 低域から次のDownbeatへ押し出す  |
| Cymbal Fill        | Crash、Open Hat、Ride変更        | セクション境界を明確にする      |
| Dropout            | 一部または全部を一時的に抜く     | 次のAttackを強調する            |
| Pickup             | 次小節直前に短い導入を置く       | 次の1拍目へ引き込む             |
| Orchestration Fill | 同じリズムを別のドラムへ移す     | 音数を変えずに変化を作る        |

Fillは半拍だけの小さな変化から、1小節全体を使う大きなFillまで幅がある。毎回同じ長さ・同じTom回しを使う以外にも、DropoutやCymbal変更だけで移行を作れる。

### Half-time / Double-time

BPMを保ったままBackbeatや刻みの感じ方を変えると、知覚上の速度を変えられる。

| Feel        | 代表的な変化             | 印象                       |
| ----------- | ------------------------ | -------------------------- |
| Normal      | 2・4拍のBackbeat         | 基準                       |
| Half-time   | Snareを主に3拍目へ       | 広い、重い、空間が増える   |
| Double-time | Backbeatや刻みを倍速側へ | 急速、細かい、推進が増える |

同じコード進行やメロディのままFeelだけを切り替える方法もあり、セクション差を大きく作れる。

### 複数小節の展開

```text
Bar 1: A
Bar 2: A'
Bar 3: A
Bar 4: B
```

8小節では、後半へ向けて差を大きくする形も作れる。

```text
A  A'  A  B
A  A'  C  Fill
```

変化の材料:

- Kickを1〜2音変える
- Ghost Noteの位置を変える
- Hi-hatを一度開く
- 8分Hatを16分へ変える
- Crashを追加する
- Tomへ移す
- 1拍だけDropoutする
- Half-time / Double-timeへ切り替える
- Percussionを追加する

展開では、「どの音を増やすか」だけでなく、**どの要素を維持して同じグルーヴだと感じさせるか**が重要になる。

## 4. ベース

ベースは、**和声の土台、リズム、独立した旋律線**を同時に担える。

| 役割   | 主な内容                        | 何が変わるか           |
| ------ | ------------------------------- | ---------------------- |
| 和声   | Root、3rd、5th、7th、Pedal      | コードの明瞭さ、転回感 |
| リズム | Attack、休符、Syncopation、音価 | Groove、Kickとの関係   |
| 旋律線 | Passing、Approach、Motif、Fill  | コード間の方向、独立性 |

曲中で比率を変えることもできる。VerseではRoot中心、ChorusではOctaveやPassingを増やす、間奏では旋律線を前面へ出す、といった使い分けがある。

### 音高の語彙

Root、3rd、5th、7thしか使ってはいけないわけではない。

| 音の種類               | 役割                          | 使い方の例                      |
| ---------------------- | ----------------------------- | ------------------------------- |
| **Root**               | コードを最も直接的に示す      | 強拍、コードチェンジ点          |
| **3rd**                | Major/Minorの品質を示す       | Rootを避けた開始、Voice Leading |
| **5th**                | 安定した補助音                | Rootとの往復、跳躍              |
| **7th**                | コード色と次への方向を作る    | 次コードへ半音/全音で接続       |
| **Octave**             | 同じPitch classで音域を変える | 反復、裏拍、Slap系              |
| **Arpeggio**           | コード内部を動く              | `1→3→5→7` など                  |
| **Scale Tone**         | コード間を順次につなぐ        | Rootから次Rootまで線を作る      |
| **Chromatic Approach** | 半音で目標音へ近づく          | 次コード直前の導入              |
| **Passing Tone**       | 重要音の間を埋める            | `C→D→E`                         |
| **Neighbor Tone**      | 基準音の周辺を動く            | `C→D→C`                         |
| **Enclosure**          | 上下から目標音へ収束          | `E♭→C#→D`                       |
| **Pedal**              | 同じBass音を保持              | 上のコードだけ変化させる        |

### コード間の接続

ベースは現在コードの構成音だけで完結させず、次のコードの目標音へ向かう線として設計できる。

```text
C      Am      F       G
C-B-A  A-G-F   F-F#-G  G
```

各小節の末尾が次のRootへ向かうため、コードチェンジ自体が旋律線の一部になる。

### リズムの語彙

| リズム        | 内容                   | 主な印象             |
| ------------- | ---------------------- | -------------------- |
| Sustain       | 長く伸ばす             | 安定、広い空間       |
| Repeated Note | 同音反復               | Pulseを強調          |
| Offbeat       | 裏拍中心               | 軽さ、推進           |
| Syncopation   | 弱い位置を強調         | 引っ掛かり、前進     |
| Anticipation  | 次コードを早く出す     | 次へ引っ張る         |
| Tie           | 拍をまたいで保持       | Attack位置をずらす   |
| Rest          | 音を切る               | 次Attackを強調       |
| Pickup        | 次小節直前の短い導入   | 次の1拍目へ接続      |
| Ostinato      | 短いセルを反復         | Grooveの核           |
| Dead Note     | 音高を弱めAttackを残す | Percussiveな内部運動 |

Rootだけを使うベースでも、リズムの違いでかなり性格が変わる。

```text
Rootを4分で反復
C--- C--- C--- C---
```

```text
Rootを裏拍中心で配置
---- C--- --C- C---
```

```text
Root + 休符 + Dead Note
C-xx ---- C-x- ----
```

Pitch vocabularyとRhythm vocabularyを別軸で考えると、音高を動かす量とGrooveの複雑さを独立して調整できる。

### 休符と音価

「どこで切るか」がKickとの関係や低域の空間を大きく変える。

| 形                   | 効果                                   |
| -------------------- | -------------------------------------- |
| 長く伸ばす           | コードの土台を連続させる               |
| Kickと同時に短く切る | KickとBassを一つの打点として感じやすい |
| Kick後まで伸ばす     | KickのAttackからBassの余韻へつなぐ     |
| Attack後すぐ休む     | 次の音やKickへ空間を渡す               |
| 小節後半を休む       | Fillや次のDownbeatを強調する           |

音数を増やさなくても、音価と休符だけでGrooveの輪郭を大きく変えられる。

### 音域

| 音域 | 特徴                    | 使い方                   |
| ---- | ----------------------- | ------------------------ |
| 低域 | Root、5thの重量感が強い | 基礎、長音、簡潔な反復   |
| 中域 | 音程が聞き取りやすい    | Passing、Arpeggio、Motif |
| 高域 | 旋律性とAttackが目立つ  | Fill、対旋律、Octave展開 |

同じMotifでもOctave上へ移すと存在感が変わる。セクションごとに音域を変えると、音数を増やさずに展開を作れる。

### モチーフ

Bass lineにも短いMotifを持たせられる。Motifを作る要素は、音程、Rhythm、Rest、Octave jump、Chromatic Approach、Articulation、終わり方。

```text
Bar 1: A
Bar 2: A'
Bar 3: A
Bar 4: B
```

A'では最後の1音だけ変え、BではFillへ広げる、といった差を付けられる。BerkleeのBass Groove教材では、A-B-A-C型の問いと応答で1小節アイデアを4小節へ展開する方法も紹介されている。

### Pedal / Ostinato

**Pedal**: 同じBass音を保ち、上のコードだけを変える。Bassが一定なので、上声の変化が強く聞こえる。

```text
Bass:    C   C   C   C
Harmony: C | F/C | G/C | A♭/C
```

**Ostinato**: 短いBass patternを複数コードにまたいで繰り返す。同じPitch patternを保持する形、コードごとにRootだけ移す形、Rhythmだけ固定する形などがある。

### Continuous / Walking系のライン

各拍へ継続的に音を置くBassでは、1音ごとのコード適合より、数拍かけた到達線が重要になる。材料は、Chord Tone、Scale Tone、Chromatic Approach、Enclosure、Arpeggio、Repeated Note。

```text
C7: C E G A
F7: B♭ A G F
```

次コードへ近づく方向を持たせると、常に音が鳴っていても線としてまとまりやすい。

### Pentatonic / Blues系の語彙

Bass lineやFillには、Major/Minor Pentatonic、Blues Scale、Mixolydian系なども使える。コードごとに切り替える使い方と、短いMotifを複数コード上で維持する使い方がある。後者では、同じMotifがコードごとに少しずつ違う響きを作る。

### Fill

通常のGrooveから一時的に動きを増やし、次のフレーズへ接続する。

| Fillの材料         | 特徴                           |
| ------------------ | ------------------------------ |
| Arpeggio           | コード感を保ったまま動く       |
| Scale Run          | 順次で滑らかに移動             |
| Chromatic Approach | 次のRootへ強く向かう           |
| Pentatonic / Blues | Groove感のある短いフレーズ     |
| Octave             | 音域差で強調                   |
| Register Jump      | 高域へ飛んで目立たせる         |
| Rhythmic Burst     | 同じ音でも細かなリズムでFill化 |

置きやすい場所は、4・8小節目、コードチェンジ直前、セクション境界、Vocalの休符、Drum Fillとの掛け合い。

### アーティキュレーション

同じPitch/Rhythmでも、**Attack、音価、減衰、Pitchのつなぎ方**でGrooveが変わる。

| 奏法                     | 音の変化                        | リズム上の効果                                  |
| ------------------------ | ------------------------------- | ----------------------------------------------- |
| **Long / Sustain**       | 音を長く保持                    | 拍と拍をつなぎ、低域を連続させる                |
| **Short / Staccato**     | 発音後すぐに切る                | Attackと休符が明確になり、歯切れが出る          |
| **Muted**                | 倍音と余韻を抑える              | PitchよりAttackが目立ち、細かな反復を置きやすい |
| **Ghost / Dead Note**    | 明確な音程を弱める              | 主要音の間へ細かな刻みを追加できる              |
| **Slide**                | Pitchを連続的につなぐ           | 離れた音を一つの動きとして結ぶ                  |
| **Hammer-on / Pull-off** | 再Attackを減らしてPitchを変える | 細かな音を滑らかにつなぐ                        |
| **Accent**               | 特定の音を強くする              | Motif内部の重心を作る                           |
| **Slap**                 | 強いPercussive Attack           | Kickに近い明確な打点をBass側へ作る              |
| **Pop**                  | 高域の鋭いAttack                | Slapとの掛け合い、裏拍Accentを作りやすい        |
| **Palm Mute**            | Attackを残し余韻を抑える        | 短く丸い音で反復を組みやすい                    |

同じ8分音符でも、Long中心なら連続した土台として聞こえ、ShortやDead Noteを混ぜるとAttackと空白が前面に出る。

### 複数小節の展開

```text
Bar 1: Root中心
Bar 2: 同じRhythm + Approach
Bar 3: Bar 1へ回帰
Bar 4: 高域Fill
```

変化の材料は、最後の1音を変える、次コードへのApproachを追加する、Restを増減する、Octaveへ移動する、Articulation変更、Fill、Rhythmは同じままPitchだけ変更する。

## 5. パート間のグルーヴ

グルーヴを、**複数パートが同じ時間をどう共有するか**として見る。同時に鳴る位置、互いに空ける位置、アクセント、音価によって関係が変わる。

### KickとBassの関係

低域ではKickとBassのAttack関係がグルーヴの輪郭を大きく左右する。

| 関係               | 形                         | 聞こえ方                     |
| ------------------ | -------------------------- | ---------------------------- |
| **同時に鳴らす**   | KickとBassのAttackを重ねる | 一体感、強い打点             |
| **一部だけ重ねる** | 主要拍だけ同時             | 基準を共有しつつBassが動ける |
| **交互に置く**     | Kickの隙間へBass           | 掛け合い、連続する低域Rhythm |
| **Bassを伸ばす**   | Bass Sustain + Kickの追加  | Bassを土台にKickが内部を動く |
| **Kickを絞る**     | 少ないKick + 動くBass      | Bass lineの旋律性が前へ出る  |

```text
Kick: X-------X---X---
Bass: X---XX--X-X---X-
```

最初と中間でAttackを共有し、その間をBassが埋めると、低域の基準と動きの両方を作れる。

### Snare / Backbeatとの関係

Snareが2・4拍などで明確なBackbeatを示すと、Kick/Bass側で細かなシンコペーションを作っても拍の位置を感じやすい。逆にSnare自体をずらしたりGhost Noteを増やす場合は、Kick、Hi-hat、Bassのどれかが拍の基準を示すことで、複雑な配置の中にも重心を作れる。

掛け合いの例として、Bass phrase → Snare fill、Kick phrase → Bass responseのように、同時発音を増やす方法と時間を分けて応答させる方法の両方がある。

### 同じ刻みを共有する

複数パートが同じ16分の刻みを共有し、その中から別々の位置を選ぶ方法がある。

```text
16分: xxxx xxxx xxxx xxxx
Hat : x-x- x-x- x-x- x-x-
Bass: x--x --x- x--- -x--
Kick: x--- ---- x--- --x-
```

全パートが同じ時間の細かさを共有しているため、発音位置が違っても一体感を保ちやすい。同じ刻みの中で、Hatが連続性、Kickが主要な重心、Bassがシンコペーション、Ghost Noteが細かな補助、というように役割を分けられる。

### 空白の分担

休符は各パートの関係を作る材料になる。

| 空く場所       | 前へ出やすいもの                 |
| -------------- | -------------------------------- |
| Bassが休む     | Kick、Snare、Chord               |
| Kickが休む     | BassのAttackやSustain            |
| Drum全体が休む | Bass、Guitar、Keys               |
| Melodyが休む   | Bass Fill、Drum Fill、Percussion |
| 全員が休む     | 次のDownbeat                     |

すべてのパートを同じ場所で休ませると強いBreakになり、休符をずらして配置すると掛け合いになる。

### 密度

グルーヴの密度は総音数だけで決まらない。Attack数、同時発音数、刻みの細かさ、Ghost Note、Bassの音高移動、Percussionの層、音価、Fill頻度の総合として聞こえる。

```text
Kick       少
Snare      安定
Hi-hat     多
Bass       中
Percussion 少
```

と、

```text
Kick / Snare / Hi-hat / Bass / Percussion すべて多
```

では総体の圧力が大きく違う。同じ音数でも同時発音を増やすか、時間に分散するかで聞こえ方が変わる。

### シンコペーションの分担

シンコペーションを担うパートを変えると、同じ拍子でも別のグルーヴになる。

| 配置                                | 特徴                         |
| ----------------------------------- | ---------------------------- |
| Drumは安定、BassがSyncopated        | Bassの動きが前へ出る         |
| KickがSyncopated、Bassは長音        | Kickの細かな動きが目立つ     |
| HatはStraight、KeysがOffbeat        | 上物側で浮遊感を作る         |
| SnareはBackbeat、Percussionがずれる | 拍を保ちながら別周期を重ねる |

同じ曲の中でも、VerseとChorusで担当を入れ替えられる。

### セクション間の変化

セクション差はPattern全体の交換以外でも作れる。

| 軸         | 例                          |
| ---------- | --------------------------- |
| Kick密度   | 少 → 多                     |
| Snare      | Cross-stick → Full Snare    |
| Hi-hat     | 8分 → 16分 / Ride           |
| Ghost Note | 少 → 多                     |
| Bass音域   | 低 → 中高域                 |
| Bassの動き | Root中心 → Passing/Fill増加 |
| 音価       | Long → Short                |
| Percussion | なし → 追加                 |
| Feel       | Normal → Half-time          |
| Fill頻度   | 少 → 多                     |

一つの軸だけ変えると連続性を保ちやすく、複数軸を同時に変えると大きなセクション差になる。

## 6. フィール

### Velocityと音価

同じAttack位置でも、Velocityと音価で別のグルーヴになる。Velocityは階層を作る。

```text
Main Accent
Secondary Accent
Normal Note
Ghost Note
```

音価では、BassのLong/Short、Hi-hatのOpen/Closed、SnareのGhost/Mainなど、余韻の長さが各Attackの独立性を変える。

### 前ノリ・後ノリ

グリッドに対してAttackをわずかに前後させると、同じPatternでもフィールが変わる。

| 配置     | 印象                      |
| -------- | ------------------------- |
| やや前   | 急ぐ、押す、前進          |
| 中心     | Tight、明確               |
| やや後ろ | Laid-back、重い、ゆったり |

```text
Kick  = 基準
Bass  = 少し前
Snare = 少し後ろ
```

この関係を数小節通して保つと、ランダムなズレより一貫したフィールになりやすい。

### Microtiming

Microtimingは、16分や3連などの刻みよりさらに細かな時間差を指す。研究では、プロ奏者の自然なMicrotimingと完全Quantizeの両方が高く評価された例があり、ズレを大きく誇張するとGroove評価が下がる結果も報告されている。見るときは次の順に分けると、どの要素がフィールを作っているか把握しやすい。

1. Pattern
2. Accent
3. Swing / Shuffleの長短
4. パート間の前後関係
5. さらに細かなズレ

### Swing / Shuffleの共有

Swingは各パートが同じ長短感を共有すると一体感が強くなる。RideとBassが同じSwing感を共有する形、Drumは強めのShuffleでBassは少しStraight寄りにする形、Hi-hatだけSwingでKick/Snareは大きな拍を維持する形などがある。同じSwing比を全員で共有する形も、パートごとに少し差を付ける形もある。

## 7. 既存グルーヴを見るときの観点

| 観点             | 見るもの                      |
| ---------------- | ----------------------------- |
| 拍               | 何を基準に数えるか            |
| 刻み             | 8分、16分、3連など            |
| Backbeat         | Snareの重心                   |
| Kick             | 強拍、裏拍、Bassとの関係      |
| Bass             | Root、Approach、休符、音価    |
| シンコペーション | どのパートが拍をずらすか      |
| 空白             | 誰が休み、誰が埋めるか        |
| 反復             | 何がGrooveの核か              |
| 変奏             | 2・4・8小節で何が変わるか     |
| Feel             | Swing、前後感、Velocity、音価 |
