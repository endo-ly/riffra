# J-POP コード進行辞典

日本のポップス周辺では、コード進行そのものに楽曲名・作曲家・時代・コミュニティ由来の名前が付く。この辞典は、名前の背後にある構造を知るための索引であり、名称は和声設計の出発点であって、そのまま反復するための型ではない。エントリ間に優劣や階層はなく、すべて並列である。

## 1. この辞典の使い方

度数はローマ数字＋品質で書く（C majorなら`IIm`=Dm、`III7`=E7）。`IIIm`（Em）と`III`（E）は別のコードである。コード例は原則C major / A minor基準で、特定曲由来の進行は構造を壊さないため原曲のキーを残す。

名称を使うときは、7thやテンションの付加、分数コード、セカンダリードミナント、借用和音、コード尺の変更などで必ず調整する。名前は検索と会話のためのラベルであり、品質まで展開したコード列とは別物である。

定着度は、理論上の正しさではなく**名称がコミュニティでどの程度共有されているか**の目安である。

| 記号  | 区分           | 扱い                                         |
| ----- | -------------- | -------------------------------------------- |
| **A** | 広く定着       | 名前だけでもかなり通じる                     |
| **B** | 特定界隈で定着 | DTM、アニソン、コード分析界隈では通じる      |
| **C** | 新興・局所     | 一部コミュニティ、特定サイト、特定作曲家周辺 |
| **D** | 定義不安定     | 名前だけでは進行を一意に決めない             |

辞典への追加は、度数と由来まで確認できた名称だけを行う。名前だけを追加しない。

## 3. 詳細辞典

### 3.1 主要な進行

#### 王道進行（4536）

定着度: A

```text
IV → V → IIIm → VIm
C: F → G → Em → Am
```

別名: J-POP進行、小悪魔コード進行（亀田誠治周辺）、きゅんメロ進行／イケイケダンス進行（スージー鈴木）。

`IV → V`で強く前進しながら`I`へ着地せず`IIIm → VIm`へ抜ける。メジャー2つからマイナー2つへの移行で**高揚感の中に切なさ**を残しやすい。主和音が進行内に現れないため4コードの反復では終止感が弱く、サビを長く引っ張るときに向く。終止は`IIm → V → I`で明るく、`IIm → V → VIm`で切なさを残す。

派生: **後ろ髪**`F → G/F → Em → Am`（2コード目でベースを`F`に残し上声だけ動かす。ベースの引力が強い）／**おくれ毛**`F → G → G/F → Em → Am`（2コード目の途中からベースが下降。YOASOBI「群青」の分析から命名）。

#### カノン進行

定着度: A

```text
I → V → VIm → IIIm → IV → I → IV → V
C: C → G → Am → Em → F → C → F → G
```

パッヘルベルの「カノン」に由来し、「大逆循環」とも呼ばれる。バラード、卒業曲、応援歌、アニソン、アイドル曲まで幅が広い。各コード間の共通音が多く旋律を長く乗せやすく、前半は下降感、後半は`IV → V`による次周期への推進力を持つ。

#### 純情進行

定着度: B

```text
C → G/B → Am → Em/G → F → C/E → Dm → G
Bass: C → B → A → G → F → E → D → G
```

カノン進行を分数コード化しベースを滑らかに下降させた形。亀田誠治の番組で紹介された呼称で、「なめらかカノン」とも。ベースラインの存在感が強く、**叙情性・懐かしさ・素直な感動**を作りやすい。ピアノやストリングスと相性がよい。

#### 小室進行

定着度: A

```text
VIm → IV → V → I
C: Am → F → G → C
```

小室哲哉の楽曲群との結び付きから広まった呼称。マイナーから始まり`IV → V → I`でメジャーへ抜ける流れが明確で、**疾走感・90年代J-POP感・ドラマチックな上昇**を作りやすい。`Am → Dm → G → C`を「小室進行2/3」と呼ぶサイトもあるが、一般的には`VIm → IV → V → I`を指す。

#### 丸サ進行（Just the Two of Us進行）

定着度: A

```text
IVmaj7 → III7 → VIm7
C: Fmaj7 → E7 → Am7
```

丸の内サディスティック進行／Just the Two of Us進行。`4361` `43651`と数字略記されることもある。続きは`... → C7`、`... → Gm7 → C7`、`... → D7`など複数の流派がある。`III7 → VIm`のセカンダリードミナントが強い色を持ち、maj7/min7の多用で**都会的・夜・洗練・浮遊感**を作る。4コードの固定列ではなく、`IVmaj7 → III7 → VIm7`を核にしたファミリーとして扱うのが実用的。

#### コンファメ進行

定着度: B

```text
| I | VIIm7♭5  III7 | VIm | Vm7  I7 | IVmaj7 | IIIm  VI | II | V |
C: | C | Bm7♭5  E7 | Am | Gm7  C7 | Fmaj7 | Em  A | D | G |
```

「コンファメーション進行」のほか、ハレ晴レ進行／マスピ進行とも呼ばれる。Charlie Parker「Confirmation」に由来。

前半の核はカノン進行`| I | V | VIm | IIIm | IV |`の変形で、`V`と`IIIm`の区間を2つに分けて次コードへのリレーテッドII–Vへ置き換えたもの（`Bm7♭5 → E7 → Am`、`Gm7 → C7 → F`）。根音の完全4度上行／完全5度下行の強進行の連鎖になる。コード尺が重要で、`Bm7♭5 → E7`全体が`C`と同じ長さ、`Gm7 → C7`全体が`Am`と同じ長さを占める。`IV`は終点ではなく中間地点で、後半は`IIIm → VI → II → V`のような五度連鎖やカノン系の流れへ戻る形が多い。**前半の変形を核に持ち、後半を強進行やカノン系の流れで展開するファミリー**として扱う。

#### シャンゼリゼ進行

定着度: B

```text
I → III7 → VIm → I7 → IV → ...
C: C → E7 → Am → C7 → F → ...
```

「オー・シャンゼリゼ」のサビに由来。カノン進行の前半をセカンダリードミナントで置き換えた形（`I → V → VIm → IIIm → IV`の`V`→`III7`、`IIIm`→`I7`）。内声に半音進行を作りやすく、明るさの中に**ドラマ性と軽い洒落た感じ**を加えられる。

#### オンリーワン進行（14536）

定着度: B

```text
I → IV → V → III7 → VIm
C: C → F → G → E7 → Am
```

SMAP「世界に一つだけの花」と結び付く。前半`I → IV → V`が素直なまま`I`へ戻らず`III7 → VIm`へ進む。王道進行に主和音を前置きし`IIIm`を`III7`へ強化した形でもある。**希望・青春・前向きさ**を保ちつつ`III7 → VIm`で陰影を付けられる。

#### 落ち葉進行

定着度: B

```text
C → Em/B → Em7♭5/B♭ → A7 → Dm → C#aug → Dm7/C → G7
```

Albert Hammond「For The Peace of All Mankind」の日本語題「落葉のコンチェルト」に由来。コード名より重要なのは**2本の半音下降線**である。

```text
Bass / root-like line: C → B  → B♭ → A
D → C# → C  → B
```

半音下降クリシェとドミナント進行の連続で、**郷愁・喪失感・映画的なドラマ性**を強く出せる。「枯葉進行」とは別物である。

#### 枯葉進行

定着度: B

```text
IIm7 → V7 → Imaj7 → IVmaj7 → VIIm7♭5 → III7 → VIm
C: Dm7 → G7 → Cmaj7 → Fmaj7 → Bm7♭5 → E7 → Am
```

ジャズ・スタンダード「Autumn Leaves／枯葉」に由来。ループさせる場合は末尾に`A7`などを置いて`Dm7`へ戻す。5度進行を長く連結するため解決が次々に続き、**エレガント、都会的、ジャズ的、循環し続ける感覚**を作りやすい。

#### 明菜進行／大きゅんメロ進行

定着度: C

```text
Dm7 → G7 → Cmaj7 → Am → Dm7 → Bm7♭5 → E7
```

スージー鈴木による分析で、中森明菜「セカンド・ラブ」「スローモーション」周辺を説明する呼称。前半の`IIm → V → I → VIm`は親しみやすく、後半の`Dm7 → Bm7♭5 → E7`がA minorへ向かう緊張を作り、昭和歌謡的な**余韻と胸を締め付ける感じ**を強める。著者固有の名称で、一般名称としては扱わない。

#### サイレントイブ進行

定着度: B

```text
C: Am → AmMaj7/G# → Am7/G → D7/F# → F → G7 → C ...
Bass: A → G#      → G    → F#
```

原曲（Key: E♭）では`Cm → CmMaj7/B → Cm7/B♭ → F7/A → A♭ → B♭7 → E♭ ...`。マイナーコード内部でベースが半音ずつ下降する線により、**冬のバラード、別れ、静かな切迫感**を作りやすい。ChordWikiでは独立タグとして複数曲に付与され、原曲分析を超えた共有がある。

#### マリオ進行

定着度: B

```text
♭VI → ♭VII → I
C: A♭ → B♭ → C
```

Super MarioシリーズのBGMとの連想から付いた呼称。同主短調側の`♭VI`と`♭VII`を借りて主和音へ上がる。`IV → V → I`より大きな全音上昇が続き、**ゲーム的な達成感、壮大さ、ポジティブな解放**を作りやすい。

#### ラピュタ進行（順次下降マイナー）

定着度: C

```text
Am → Em/G → F → C/E → Dm → Am/C → B7 → E7 → Am
```

「天空の城ラピュタ」の「君をのせて」に由来し、呼称はコード進行データベースから広がった。長い下降ベース（`A → G → F → E → D → C → B → ...`）が中心で、マイナー起点のため純情進行より暗い。**哀愁・旅・壮大さ・物語の終盤感**を作りやすい。

#### ラムネ進行

定着度: C

```text
III7 → Vm7 → VI7
C: E7 → Gm7 → A7
```

核となる動きは`III7 → Vm7`または`IIIm7 → Vm7`。田中秀和周辺の楽曲、とくに「ラムネ色 青春」と結び付けて一部のコード分析コミュニティで使われる。`III7`が通常進みたがる`VIm`ではなく`Vm`へ飛ぶため予想を裏切り、**明るいキーの中で突然横滑りするような色彩変化**が生まれる。一般理論用語ではなく命名者・コミュニティ色の強い呼称。

#### カフネ進行

定着度: C

```text
Key: F
B♭maj7(9) → A7(#9) → Am7/D → Cm7(9) → Faug
```

「CAFUNÉ」由来。テンション、分数コード、オーギュメント、借用和音を短い区間に集中させ、**ジャズ寄りの複雑さとアニソン/アイドル音楽のキャッチーさを同居**させる用途に向く。定義は固定されておらず、別の部分・別曲では変形が使われる。名前から固定4コードを生成せず、原型または具体的な度数を確認して使う。

#### にゃんぼりー進行

定着度: C

```text
I → ♭V@ → IV → ♭VII@
C: C → G♭@ → Fmaj7 → B♭@
```

`@`はBlackadder Chord系コミュニティの略記。DIALOGUE+「にゃんぼりーdeモッフィー!!」に由来。命名コミュニティでの定義は「ベースが`1 → ♭5 → 4 → ♭7`と動き、2番目と4番目がBlackadder Chordであるもの」。ダイアトニックから大きく外れた和音を声部進行でつなぎ、**派手、奇妙、かわいい、技巧的、現代アニソン的**な色が非常に強い。

#### プリキュア進行

定着度: C（定義はD寄り）

```text
核: I → III7 → VIm
展開例: I → III7 → VIm → Vm7/♭VII → I7 → IV → I/III → IIm → ♭VI → ♭VII
```

`I → III7 → VIm`で強い歌謡的引力を作った後、`Vm7 → I7 → IV`や借用和音で大きく展開する。プリキュア楽曲で頻出とされるアニソン分析界隈の呼称。後半は曲・分析者によって異なるため固定8コードではなくファミリーとして扱い、コンファメ進行と似るが**近縁の別ファミリー**として管理する。

#### 50s進行（1645）

定着度: A

```text
I → VIm → IV → V
C: C → Am → F → G
```

ドゥーワップ進行とも呼ばれる（日本独自の呼称ではない）。4コードで強い循環性を持ち、**懐かしさ、青春、素朴さ、オールディーズ感**が出やすい。メロディを乗せやすく、テンポとアレンジで印象が大きく変わる。

#### 1625進行

定着度: A

```text
I → VIm → IIm → V
C: C → Am → Dm → G
```

「イチロクニーゴー」。5度進行を含む自然な循環で、歌謡曲、ジャズ、ポップス、バラードに広く使える。主和音から離れて再び主和音へ戻るため、**安定した反復**を作りやすい。

#### ポップパンク進行（1564）

定着度: A

```text
I → V → VIm → IV
C: C → G → Am → F
```

回転形`VIm → IV → I → V`（6415）、`IV → I → V → VIm`（4156）も同ファミリー。ダイアトニック4コードだけで**青春、開放、エモーショナルなロック感**を出しやすい。バンド系J-POPやアニソンで非常に多い。

#### ユーロビート進行（456）

定着度: C

```text
IV → V → VIm
C: F → G → Am
```

`IV → V`で上昇させながら主和音ではなく`VIm`へ着地するため、**疾走しながら少し切ない**。王道進行を圧縮したような印象になることもある。名称の範囲はソースによって広いため、度数とセットで扱う。

### 3.2 局所的・著者固有の呼称

存在は確認できるが、日本全体で共有された標準名とは言いにくい小さな呼称。王道進行の派生（後ろ髪・おくれ毛・大きゅんメロ）は3.1に記載済み。

#### クリスマス進行

```text
I → IV → II7 → V7 → III7 → VIm → IIm → V → I
C: C → F → D7 → G7 → E7 → Am → Dm → G → C
```

「We Wish You a Merry Christmas」型。`I → IV`、`II7 → V`、`III7 → VIm`、`IIm → V → I`と5度進行が段階的につながるのが特徴。

#### 始まりの進行

```text
I → II/I → IVm/I → I
C: C → D/C → Fm/C → C
```

主音をベースに残したまま上の和音だけを変え、**物語の始まり・導入・映画的な広がり**を作るタイプ。一部の進行集で使われる名称。

#### YOASOBI進行

```text
F → G → Em7 → Am7 → Dm7 → E7 → Am → Gm7 → C7
```

一部の進行データベースで付けられる長い形。王道進行を起点に、後半へセカンダリードミナントと`Vm → I7`を加えたもの。一般的な固定名としては扱わない。

#### メロウな王道進行

`Fmaj7 → G7/F → Em7 → Am7`。王道進行にテンションとペダルベースを加えた説明的名称。

#### オシャレ丸サ

`Fmaj7 → E7 → Am7 → D7`。丸サファミリーの末尾を`II7`に変えた形。

#### パイレーツ進行

`Am → Dm → E → Am`（マイナーの`Im → IVm → V → Im`）。名前は説明用ラベルに近い。

#### ファンタジー進行

`Am → D → F → G`。借用・モーダル感を使った説明用ラベル。

### 3.3 定義が揺れる呼称

名前は流通しているが、指す進行が一意に決まらない呼称。名前だけからコード列を確定してはならない。

#### アニソン進行

`IV → V → IIIm → VIm`の王道進行、コンファメ／ハレ晴レ系、カノンのセカンダリードミナント細分化、`♭VI → ♭VII → I`系借用進行など、複数の進行に対して使われる。

#### シティポップ進行

丸サ／JTTOU系（`Fmaj7 → E7 → Am7 → ...`）を指す場合と、`Am → C → F → E`など別の4コード進行を指す場合がある。単一の定義がない。

#### 感動進行／感動コード

`I → V → VIm → IV`、カノン系、下降ベース系など複数の意味で使われる。感情ラベルとしては有用だが、コード列の識別子には向かない。

#### バロック進行

マイナーキーの下降・ドミナントを組み合わせた形を指すが、サイト間で形が一致しないため固定式にはしない。

### 3.4 数字ラベル索引

名前より数字で呼ぶ場合が多い。数字だけでは7th、分数コード、借用和音、コード尺が失われるため、検索用エイリアスとして使い、実際の生成時は完全なコード情報へ展開する。

## 4. 関連する和声ラベル

進行そのものではないが、名前付き進行を理解するうえで重要なコード・手法レベルのラベル。

- **クリシェ**: コード機能を保ちながら構成音やベースを半音・全音で連続的に動かす。`VIm`下降クリシェ（`Am → AmMaj7/G# → Am7/G → ...`）はサイレントイブ進行などにつながり、`I`上昇クリシェ（`C → Caug → C6 → C7`）はシャンゼリゼ系に似た内声上昇を作る
- **VImクリシェ進行**: ChordWikiで独立タグとしても使われる。マイナーコード上の下降クリシェを中心とする
- **Blackadder Chord**: アニソン/DTM分析コミュニティで扱われる特徴的な和音。`@`と略記される。にゃんぼりー進行の定義の一部
- **イキスギコード**: Blackadder Chord周辺の俗称。分数オーギュメント系の特殊和音・用法を指す進行名ではない
