# 編曲・音作り・ミックス

この文書は、すでに存在する音楽素材を**どのような編成・音色・密度・空間・音量関係で鳴らし、曲全体の流れとして成立させるか**を扱う。中心となる考え方は、**反復、変化、対比、回帰、密度、役割分担、音域、音色、奥行き、動的変化**である。

制作工程は、編曲・音作り・ミックスを完全に分離して考えるより、互いに影響する一つの設計として捉えた方がよい。音域の競合を編曲で減らせばEQの負担は軽くなり、音色のアタックや残響を設計すればコンプレッションやリバーブの必要量も変わる。ミックスで問題が見えたとき、処理を追加する前に、音源選択・配置・レイヤー数へ戻る判断も重要になる。

## 1. 全体の考え方

### 1.1 三つの工程と往復

編曲は、各素材を**いつ鳴らし、何に担当させ、どの程度の厚さで提示するか**を決める工程である。音作りは、各パートの**スペクトル、時間的な形、質感、動き、広がり**を決める。ミックスは、完成した全体を聴きながら**優先順位、音量、周波数、ダイナミクス、定位、奥行き**を整える。

実際の制作では、この三つを往復する。

```text
構成・役割
   ↓
編成・レイヤー
   ↓
音色・時間的な形
   ↓
音量・定位・空間
   ↓
全体を聴いて競合を確認
   ├─ 配置に問題 → 編曲へ戻る
   ├─ 音そのものに問題 → 音作りへ戻る
   └─ 関係性に問題 → ミックスで調整
```

「ミックスで直せるか」より、「どの工程で直すのが最も自然か」を基準に判断する。二つのパートが同じ帯域で常時ぶつかるなら、EQで細く削り合うより、そもそもの音源選択、オクターブ配置、発音時間、レイヤー数を変えた方が全体は単純になる。周波数マスキングは、録音・音源選択・編曲の段階から競合を減らすことで、後段の処理も軽くできる。

### 1.2 全体を支配する五つの軸

編曲からミックスまでを共通の座標で見ると、判断が散らばりにくい。

| 軸   | 主な問い                       | 主な操作                       |
| ---- | ------------------------------ | ------------------------------ |
| 前後 | 何を主役にし、何を背景に置くか | 音量、残響、明瞭度、アタック   |
| 左右 | どこに配置し、どれだけ広げるか | パン、ステレオ幅、左右差       |
| 上下 | どの音域を誰が担当するか       | 編成、フィルター、EQ           |
| 厚み | どれだけ多層にするか           | レイヤー追加・削除、ダブリング |
| 時間 | どの地点で何を変化させるか     | 出入り、オートメーション、転換 |

この五軸のうち一つだけを極端に動かす方法と、複数を少しずつ動かす方法がある。たとえば大きな到達点を作る場合、単純な音量上昇だけに頼るより、音域拡大、レイヤー追加、ステレオ拡大、残響変化、音色の明るさの上昇を少量ずつ重ねる方が、自然なエネルギー上昇を作りやすい。クレッシェンドも強弱だけで作るものではなく、使用する音色の数、音域、持続時間を広げることで、編曲そのものから上昇感を作れる。

### 1.3 主役と背景

全パートを同じ明瞭度、同じ広さ、同じ音量で鳴らすと、情報量は増えても焦点は失われる。各時点で「何を最初に聴かせたいか」を一つから数個に絞り、それ以外を支える側へ置く。

主役を前に出す方法は、音量を上げることだけではない。周囲より明るい音色にする、アタックを明瞭にする、中央寄りに置く、周囲の帯域を空ける、残響を短くする、競合パートの発音を減らす、といった方法がある。背景側はその逆方向へ調整できる。

重要なのは、**主役の性質そのものより、周囲との差が知覚を作る**ことである。明るい音しかない中では明るさは目立たず、広い音しかない中では広さは目立ちにくい。対比は絶対量より関係性で作る。

## 2. 時間の設計

### 2.1 セクションの役割

Verse、Prechorus、Chorus、Bridge、Intro、Outroなどの名称は、固定された音響状態を意味しない。制作では名称と同時に、各セクションが全体の中で何を行うかを見る。中心となるセクションに対して、導入・接続・上昇・対比・収束を担う区間を配置すると、形式名に縛られず全体の流れを設計できる。

| 役割 | 主な働き                 | 編曲上の典型的な操作                             |
| ---- | ------------------------ | ------------------------------------------------ |
| 導入 | 音世界を提示する         | 音数を絞る、特徴的な音色を先行させる             |
| 提示 | 基本状態を定着させる     | 中核レイヤーを揃える、過度に広げない             |
| 継続 | 同一性を保ちながら進める | 一部の音色・音域・装飾だけ変える                 |
| 上昇 | 次の到達点を準備する     | レイヤー追加、帯域拡大、残響や明るさを変化させる |
| 到達 | 強い印象を作る           | 密度、広さ、帯域、質感を複合的に拡張する         |
| 対比 | 既出状態から距離を取る   | 編成、空間、質感、主役配置を切り替える           |
| 回帰 | 既出状態へ戻す           | 元の特徴を保ちつつ一部を更新する                 |
| 収束 | 終了へ向かう             | レイヤー削減、残響の露出、音域の縮小             |

同じセクションが再登場するとき、完全な複製にする必要はない。基本状態を保ちながら一部を変えれば、記憶と進行感を両立できる。

```text
A   = 基本状態
A'  = A + 背景レイヤー追加
A'' = A + 音域拡大 + 空間拡大
B   = 編成と質感を切り替えた対比状態
A'''= Aへ回帰しつつ最大密度へ
```

この `A'` は、素材そのものを書き換えるというより、**鳴らし方を変えた同一セクション**として扱える。

### 2.2 エネルギー

エネルギーは音量だけでは決まらない。複数の要素が合成された知覚である。

| パラメータ   | 低い状態         | 高い状態       |
| ------------ | ---------------- | -------------- |
| レイヤー数   | 少ない           | 多い           |
| 音域         | 狭い             | 広い           |
| 高域成分     | 少ない           | 多い           |
| 低域の重量感 | 軽い             | 強い           |
| アタック     | 丸い             | 明瞭・鋭い     |
| 持続         | 短い・空白が多い | 長い・連続する |
| ステレオ幅   | 狭い             | 広い           |
| 残響         | 控えめ           | 大きい・長い   |
| 歪み・倍音   | 少ない           | 多い           |
| 音量         | 小さい           | 大きい         |

大きな頂点では、すべてを最大にする必要はない。ある頂点では低域と密度を最大化し、別の頂点では広さと高域を最大化するなど、山の性格を分けられる。

### 2.3 エネルギーカーブ

曲全体をセクション単位のエネルギーとして眺めると、局所的な豪華さに引っ張られにくくなる。

```text
Energy
  high |                         ██████
       |               ████      ██████
       |       ███     ████  ██  ██████
       | ███   ███  ██ ████  ██  ██████
   low | ███ █ ███  ██ ████  ██  ██████
       +---------------------------------> time
         Intro  A   Rise  Peak  B  Final
```

制作時には各セクションを単独で「豪華に」するより、前後関係で必要な差を作る。後半を大きくしたいなら、前半に一定の余白を残す。特定の音色を後半まで温存し、必要な地点で初めて投入するだけでも、構成上の到達感を作れる。

### 2.4 形式と編曲状態

代表的な形式は、素材そのものより、**編曲状態をどの順序で提示・対比・回帰させるか**という視点で利用できる。

| 形式             | 構造                   | 編曲上の見方                           |
| ---------------- | ---------------------- | -------------------------------------- |
| Verse–Chorus系   | V–P–C など             | 基本状態から上昇し、到達状態へ移る循環 |
| AABA             | A–A–B–A                | 同一状態を定着させ、対比後に回帰する   |
| Strophic         | A–A–A…                 | 同一骨格を細部の変化で更新する         |
| Through-composed | 大型反復を前提にしない | 音色・密度・空間を継続的に更新する     |

Verse–Chorus形式では、Prechorus相当の区間がエネルギー上昇を担い、Chorus相当の区間でテクスチャが厚くなる例が多い。ここで重要なのは名称を守ることではなく、**何を温存し、どこで開放するか**を設計することである。

### 2.5 変化の階層

曲中の変化は、三つの時間スケールに分けて考えられる。

| スケール | 主な対象   | 例                                         |
| -------- | ---------- | ------------------------------------------ |
| 長期     | 曲全体     | 後半ほど広く、明るく、厚くする             |
| 中期     | セクション | 編成変更、音色変更、残響変更               |
| 短期     | 数秒以下   | フィルター、パン、ディレイ量、局所的な強調 |

長期変化が存在すると曲全体に方向が生まれ、中期変化が構成を区切り、短期変化が静的な繰り返しを防ぐ。

### 2.6 セクション境界と転換

境界は「何かを足す」だけでなく、「直前に引く」ことでも強調できる。

```text
密度を落とす → 一瞬の余白 → 到達点で拡張
高域を閉じる → 徐々に開く → 新セクション
残響だけ残す → ドライに復帰
幅を狭める → 一気に広げる
低域を一時的に減らす → 復帰させる
```

音色の変化だけでも、セクション境界を滑らかにつないだり、到達点を明確にしたりできる。

転換用エフェクト（ライザー、ダウンリフター、インパクト、逆再生、ノイズスイープ、残響テールなど）は、セクションの境界を時間方向に接着する。単独で派手に鳴らすより、前後の素材から派生させると統一感が出やすい。主役音を逆再生する、残響だけを書き出して反転する、既存音を極端に伸ばす、といった方法なら、元の音世界を保ったまま境界を強調できる。

### 2.7 オートメーション

オートメーションは、ミキサーやエフェクトのパラメータを時間に沿って変化させる。音量やパンだけでなく、フィルター、残響量、歪み、幅、変調量なども時間軸上で動かせる。

代表的な対象は次の通りである。

| 対象               | 用途                                   |
| ------------------ | -------------------------------------- |
| 音量               | 主役の追従、セクション差、局所的な強調 |
| パン               | 移動、広がり、応答感                   |
| フィルター         | 明暗の推移、上昇・収束                 |
| 歪み量             | 緊張、厚み、終盤の強化                 |
| リバーブ送信       | 一時的な遠近変化、語尾や終端の強調     |
| ディレイ送信       | 空白への反応、残像                     |
| ステレオ幅         | 到達点の拡張、ブレイクの収束           |
| モジュレーション量 | 静止から動きへの移行                   |

オートメーションは、固定値では作れない**前後関係**を作る。静的なミックスで一番良い設定を探し続けるより、必要な地点だけ動かす方が自然な場合も多い。

### 2.8 段階的な拡張

同じセクションが複数回現れる場合、毎回一つずつ要素を開放すると進行感を作れる。

```text
1回目: narrow / dry / few layers
2回目: + supporting layer
3回目: + wider image + brighter tone
4回目: + octave layer + ambience + stronger saturation
```

ステレオ幅や音色の温存は、時間の設計そのものとして機能する（3.9音色の温存、5.6ステレオ幅参照）。

## 3. 編成とレイヤー

### 3.1 機能レイヤー

各トラックを楽器名よりも、曲中で果たす役割で捉えると、重複や過剰な追加を判断しやすい。同じ楽器でも場面によって役割は変わり、逆に複数の楽器が一つの役割を共同で担うこともある。

| レイヤー       | 役割                         | 代表的な要素                                     |
| -------------- | ---------------------------- | ------------------------------------------------ |
| アタック・推進 | 時間の輪郭と前進感を支える   | 打撃音、短いパーカッシブ音、クリック感のある音   |
| 低域           | 重量感と土台を作る           | ベース音色、低域ドローン、低い打撃音             |
| 中域充填       | 中央帯域を埋め、厚みを作る   | パッド、ギター、鍵盤、持続音                     |
| 主役           | その時点で最も注目させる     | 声、ソロ音色、特徴的なフック音                   |
| 補助・装飾     | 主役の空白を埋め、色を加える | 短い応答、装飾音、背景フレーズ                   |
| 効果・転換     | セクション境界や到達点を示す | ライザー、インパクト、ノイズ、逆再生、残響テール |
| 環境・質感     | 音世界を連続させる           | ノイズ、アンビエンス、フィールド録音、テクスチャ |

一つの楽器が複数の役割を担ってもよい。逆に、複数のトラックが一つの機能レイヤーを共同で作る場合もある。重要なのはトラック数ではなく、**聴感上いくつの独立した機能が同時に存在するか**である。

### 3.2 テクスチャの型

#### 単一焦点

一つの音像を中心に置き、背景を最小限にする。情報量が少ないため、音色そのもの、細かな表情、空間の余韻が目立つ。導入、ブレイク、終盤の余白に使いやすい。

#### 主役 + 支持層

最も一般的な構造である。主役を一つ置き、低域・中域・空間・装飾を別レイヤーで支える。主役と支持層の差は、音量だけでなく音域、アタック、明るさ、残響、定位で作る。

#### ブロック

複数パートが一体として動き、一つの大きな塊に聞こえる状態。ダブリングや同時発音によって強い到達感を作りやすい。各レイヤーを分離して聴かせるより、ブレンドを優先する。

#### 多層

複数の独立した音像を同時に存在させる。各レイヤーを判別可能にするには、音域・音色・左右位置・アタック・残響のどれかで差を作る。すべてを同じ中央・同じ帯域・同じ明るさに置くと、複雑さより混濁が先に聞こえる。

#### ユニゾン・ダブリング

同一内容を複数の音色やオクターブで重ね、音数の印象を増やさず存在感を強化する。ダブリングでは、別々の音を増やすというより、複数の音色を融合させて一つの大きな音像を作る。

### 3.3 密度

密度はトラック数だけで決まらない。次の要素を合わせた結果として感じられる。

| 要素           | 密度を上げる方向 | 密度を下げる方向 |
| -------------- | ---------------- | ---------------- |
| 同時発音       | 増やす           | 減らす           |
| 音域           | 広げる           | 限定する         |
| 持続           | 長く重ねる       | 短く切る         |
| 残響           | 長くする         | 短くする         |
| ダブリング     | 増やす           | 単体にする       |
| ステレオ幅     | 多層に広げる     | 中央へ集約する   |
| 倍音量         | 豊かにする       | 純音に近づける   |
| 背景テクスチャ | 追加する         | 省く             |

音が多すぎると感じた場合、最初にEQで削るより、**役割が重複するレイヤーを一つ消して成立するか**を確認する。静的なバランスが成立しない編曲は後段でも整えにくい。ミュートしても欠落を感じないトラックは、役割自体を見直す余地が大きい。

### 3.4 レイヤー追加の基準

新しいレイヤーは、次のいずれかの役割を明確に持つときに追加する。

1. 既存の主役を補強する
2. 空いている音域を埋める
3. セクション間に差を作る
4. 新しい質感を導入する
5. 奥行きや左右方向の空間を作る
6. 到達点や転換を強調する

「音が寂しいから」という理由だけで足すと、同じ帯域・同じ役割のトラックが増えやすい。寂しさの原因が、実際には音量、残響、ステレオ幅、倍音量、低域不足である場合も多い。

### 3.5 音域分担

周波数マスキングは、近い帯域を持つ音が同時に鳴ったとき、一方が他方を知覚しにくくする現象である。これはEQだけの問題ではない。音源選択や編成の段階で、各パートの主要帯域を分散させると、ミックス処理の必要量を減らせる。

```text
低域       中低域        中域         中高域        高域
|----------|-------------|------------|-------------|
    AAAAAA
          BBBBBBBBBB
                        CCCCCCCC
                                     DDDDDDDD
```

理想は「各音が狭い帯域しか持たない」ことではなく、**各パートの存在理由となる帯域が完全には重ならないこと**である。倍音を含む実音は広い帯域を持つため、重なり自体は普通に起こる。問題は、重要な部分が互いに隠し合うことである。

### 3.6 音域配置と間隔

低い音域では、近い成分を多く重ねるほど濁りやすい。高い音域では比較的密な配置でも分離しやすい。そのため低域ほど配置間隔を広く取り、中高域へ行くほど密な重なりを許容しやすい。

電子音源でも同じ発想を応用できる。低域を担うパートを複数重ねる場合は、役割を「超低域の重量」「中低域の輪郭」「上側の倍音」に分ける。単に似た低音を三つ重ねるより、分担が明確になる。

### 3.7 音色による分離

同じ音域でも、音色が違えば分離しやすい。特に次の差が有効である。

| 特性       | A      | B        |
| ---------- | ------ | -------- |
| アタック   | 鋭い   | 丸い     |
| スペクトル | 明るい | 暗い     |
| 倍音       | 密     | 純音寄り |
| ノイズ     | 多い   | 少ない   |
| 持続       | 短い   | 長い     |
| 質感       | 粗い   | 滑らか   |
| 定位       | 中央   | 側面     |
| 空間       | 近い   | 遠い     |

音色は、まず**時間方向のエンベロープと周波数スペクトル**の二軸に分けると整理しやすい。そこへノイズ成分、非整数倍音、変調、空間を加えると、音色設計をかなり体系化できる。

### 3.8 ブレンドと分離

編成には二つの方向がある。

**ブレンド**では、複数の音を一つの大きな音像として聞かせる。音域、アタック、残響、強さを近づけ、共通のバス処理を使うとまとまりやすい。

**分離**では、それぞれを別の要素として聞かせる。音色、定位、音域、アタック、残響に差を作る。

すべてを分離すると寄せ集めに聞こえ、すべてを融合すると主役が不明瞭になる。主役周辺は分離し、支持層内部はブレンドする、といった階層構造が扱いやすい。

### 3.9 音色の温存

新しい音色は、それ自体が構成上のイベントになる。序盤から全音色を使い切ると、後半で音色による新鮮さを作りにくい。クライマックスや終盤まで一部の音色を温存すると、追加した瞬間そのものを展開として使える。

温存できる要素は楽器だけではない。

- 超高域のきらめき
- 強い歪み
- 広いステレオ成分
- 長い残響
- ノイズレイヤー
- 大きなユニゾン
- 特徴的な加工音

これらを時間方向に配分すると、音色だけで構成感を作れる。

## 4. 音作り

### 4.1 音色の構成要素

音色は「明るい」「太い」といった一語だけで捉えるより、複数のパラメータへ分解する方が再現しやすい。

| 軸             | 主な内容                     | 調整手段                                   |
| -------------- | ---------------------------- | ------------------------------------------ |
| 音源           | 基本となる波形・録音素材     | オシレーター、サンプル、ノイズ             |
| スペクトル     | どの帯域・倍音が強いか       | フィルター、EQ、FM、ウェーブテーブル       |
| エンベロープ   | 立ち上がりから消失までの形   | Attack / Decay / Sustain / Release         |
| トランジェント | 発音直後の瞬間的な輪郭       | エンベロープ、トランジェント処理、レイヤー |
| 変調           | 時間とともにどのように動くか | LFO、エンベロープ、ランダム変調            |
| 非線形性       | 倍音付加や粗さ               | サチュレーション、歪み、ウェーブシェイプ   |
| 空間           | 距離・広さ・反射             | リバーブ、ディレイ、ステレオ処理           |

同じ音高・音量でも、スペクトルとエンベロープが変われば音色の印象は大きく変わる。

### 4.2 エンベロープ

エンベロープは、音が時間の中でどのように現れ、維持され、消えるかを決める。典型的な ADSR は次の四段階である。

| 要素    | 意味                                 | 聴感への影響                         |
| ------- | ------------------------------------ | ------------------------------------ |
| Attack  | 最大付近へ到達するまでの時間         | 短いほど輪郭が鋭く、長いほど柔らかい |
| Decay   | 初期ピークから持続レベルへ落ちる時間 | 音の「打撃後の落ち着き」を作る       |
| Sustain | 保持中のレベル                       | 長音時の存在感を決める               |
| Release | 発音終了後に消えるまでの時間         | 短いほど切れ、長いほど余韻が残る     |

アタックとリリースは編曲密度にも直接影響する。同じ発音数でも、リリースが長い音を重ねると実際の同時音数は増え、セクション全体が厚くなる。音作りと編曲はここでつながる。

### 4.3 基本的な合成方式

音作りでは、方式ごとの得意な質感を知っておくと出発点を選びやすい。代表的な方式として、減算、加算、FM、ウェーブテーブル、グラニュラー、サンプルベース、物理モデリングなどがある。

| 方式             | 基本原理                                 | 得意な方向                                       |
| ---------------- | ---------------------------------------- | ------------------------------------------------ |
| 減算             | 倍音の多い音源からフィルターで成分を削る | 太いベース、パッド、ブラス系、幅広い電子音       |
| 加算             | 多数の正弦波成分を加えて音を組み立てる   | 精密な倍音設計、特殊な倍音変化                   |
| FM               | ある発振器で別の発振器の周波数を変調する | 金属感、ベル、硬いアタック、複雑な倍音           |
| ウェーブテーブル | 複数波形の間を連続的に移動する           | 動く音色、変形するパッド、複雑な高域             |
| グラニュラー     | 音声を微小断片に分け、再配置・変形する   | テクスチャ、ドローン、崩れた質感、極端な時間伸縮 |
| サンプルベース   | 録音素材を再生・変形する                 | 生々しさ、具体的な物質感、現実音の変形           |
| 物理モデリング   | 発音体や共鳴体の挙動を模擬する           | 弦、管、膜、金属などの物理的質感                 |
| スペクトル処理   | 周波数成分単位で分析・再構成する         | 非現実的な変形、モーフィング、凍結感             |

減算方式では、オシレーターで音源を作り、フィルターでスペクトルを整え、エンベロープで時間形状を作る流れが基本になる。FM はキャリアとモジュレーターの関係で複雑な倍音を生み、比率によって調和的な響きから金属的・非整数的な響きまで変化する。

### 4.4 ノイズ

ノイズは「不要な成分」ではなく、音色を現実的・物質的にする重要な材料である。電子打撃音のアタック、FX、空気感、古びた質感など、狭い帯域の補助成分から音全体の核まで幅広く使える。

ノイズは用途ごとに帯域を分けると扱いやすい。

| 用途         | 主な処理                                   |
| ------------ | ------------------------------------------ |
| アタック補強 | 短いエンベロープ、バンドパス、高域寄り     |
| 空気感       | 高域中心、弱いレベル、長めの持続           |
| 摩擦・機械感 | 中高域、不規則変調、軽い歪み               |
| 風・環境     | フィルター変調、長い残響、ゆっくりした動き |
| 転換         | フィルター掃引、ピッチ変化、逆再生         |

### 4.5 モジュレーション

固定された音色は、長く鳴るほど静的に感じやすい。波形・フィルター・エンベロープで基本形を作った後、モジュレーションを加えると、音に周期性・揺らぎ・時間的な変化を与えられる。

モジュレーションでは、動かす対象と速度を分けて考える。

| 速度       | 主な知覚               | 例                                     |
| ---------- | ---------------------- | -------------------------------------- |
| 非常に遅い | セクション単位の色変化 | フィルター開閉、幅の拡大               |
| 遅い       | 揺らぎ・呼吸           | 音量、パン、フィルター、ウェーブ位置   |
| 中程度     | 明確な周期運動         | トレモロ、ワウ、オートパン             |
| 高速       | 新しい音色の形成       | FM、リング変調に近い効果               |
| ランダム   | 有機性・不安定さ       | 微小ピッチ、フィルター、パン、粒子位置 |

変調は多ければよいわけではない。主役音に複数の大きな変調を同時に与えると、形がつかみにくくなる。目立たせたい変化を一つ決め、他は小さく支える方が意図が明確になる。

### 4.6 サンプル加工とリサンプリング

録音素材は、元の正体を残して使う方法と、別の音へ変換する方法がある。極端なタイムストレッチ、レイヤリング、リサンプリング、コンボリューションなどを重ねると、元素材の質感を残しながら別の音色へ変形できる。

典型的な流れは次の通りである。

```text
source
  ↓ trim / fade
pitch / time
  ↓
filter / EQ
  ↓
envelope
  ↓
distortion / modulation / spatial FX
  ↓
resample
  ↓
再度加工
```

リサンプリングの利点は、複数の複雑な処理を一つの音声素材へ固定し、その結果を再び単純な素材として扱えることである。加工を重ねてもプロジェクト全体の設計を複雑にしすぎない。

### 4.7 レイヤーによる一音の設計

一つの音色を、複数レイヤーに分けて設計する方法も有効である。

```text
        ┌─ Attack layer : 瞬間的な輪郭
Input ──┼─ Body layer   : 音の中心・重量
        ├─ Tone layer   : 倍音・キャラクター
        └─ Air layer    : 高域・空気感
```

各レイヤーは別々の目的を持たせる。全部のレイヤーに低域・中域・高域を満遍なく持たせると、単に音量の大きい塊になりやすい。帯域と時間を分担すると、一音として融合しながら調整もしやすい。

## 5. ミックス

### 5.1 静的ミックス

本格的な処理を始める前に、まずフェーダーとパンだけで全体の関係を作る。ここで主役、支持層、左右配置が成立すれば、後段のEQやダイナミクス処理を必要最小限にできる。

静的ミックスで確認する項目は次の通りである。

| 項目         | 判断                                   |
| ------------ | -------------------------------------- |
| 主役         | 自然に最初へ注意が向くか               |
| 低域         | 一つの大きな塊になっていないか         |
| 中域         | 支持層が主役を覆っていないか           |
| 高域         | 痛さではなく明瞭さとして機能しているか |
| 左右         | 中央に集まりすぎていないか             |
| 前後         | 全パートが同じ距離に聞こえていないか   |
| セクション差 | 音量以外でも差が感じられるか           |

静的ミックスだけである程度成立しない場合、エフェクト追加より先に編成を見直す。これは後工程での過剰処理を減らす最も大きな手段の一つである。

### 5.2 ゲインステージング

ゲインステージングは、信号経路の各地点でレベルを管理し、不要なクリッピングや過度なノイズを避け、後段の処理へ適切な信号を渡す考え方である。

デジタル環境では、トラック単体を常に0 dBFS近くまで上げる理由はない。複数トラックを加算すればマスターのピークは上昇するため、制作途中から余裕を確保しておくと扱いやすい。

ただし、固定的な「必ずこのdBにする」という数値ルールより、次の実務上の目的を優先する。

- クリップさせない
- プラグインが想定する入力範囲を大きく外さない
- フェーダーで調整しやすい余地を残す
- マスターに十分な余裕を残す
- 前後段で意図しない音量差を作らない

### 5.3 ルーティング

トラック、グループ、センド、リターン、マスターの信号経路を整理すると、処理の責務を分けやすい。信号はエフェクト前、エフェクト後、フェーダー後など異なる地点から分岐できるため、目的に応じてどの段階の音を送るかを決める。

```text
Track A ─┐
Track B ─┼─> Group ─> Main
Track C ─┘      │
                ├─send─> Reverb Return ─┐
                └─send─> Delay Return ──┴─> Main
```

空間系をセンドにまとめると、複数パートが同じ空間を共有しやすくなり、空間全体のEQやコンプレッションも一括管理できる。

### 5.4 帯域とEQ

EQは特定の周波数帯域の音量を増減し、全体の周波数バランスと各パートの役割を整える処理である。

主な目的は四つに分けられる。

| 目的           | 内容                                             |
| -------------- | ------------------------------------------------ |
| 不要成分の除去 | 低域ノイズ、耳障りな共振、不要な高域などを抑える |
| 役割の明確化   | そのパートに不要な帯域を整理する                 |
| マスキング軽減 | 他パートの重要帯域と競合する部分を調整する       |
| 音色形成       | 明るさ、太さ、距離感、質感を意図的に変える       |

EQは「各トラックを単独で最高音質にする」ための処理ではない。ソロで心地よく聞こえても、全体へ戻したときに他のパートと競合するなら、その調整はミックス全体には適していない。

周波数問題を見つけたら、次の順で考えると過剰なEQを避けやすい。

```text
1. そのトラックは本当に必要か
2. 音量関係は適切か
3. 音源選択・音域配置を変えられるか
4. パンや奥行きで分離できるか
5. それでも競合する部分をEQする
```

マスキングはEQだけで解消するものではない。編曲、音量、パンを先に見直すことで、そもそもの競合を減らせる。

ハイパス、ローパス、バンドパス、ノッチは、不要な帯域を広く整理する。音作りでは積極的な音色形成に使い、ミックスでは役割外の帯域を抑えるためにも使う。

急峻なフィルターほど便利に見えるが、位相変化や時間領域への影響が大きくなる場合がある。特に類似信号の並列処理やステレオ収録素材では、EQによる位相差が干渉を生み、音色や定位を変えることがある。

### 5.5 ダイナミクス

コンプレッションは、一定以上のレベルへ達した信号を抑え、ダイナミックレンジを制御する。目的によって設定は大きく変わる。

| 目的       | 方向                                   |
| ---------- | -------------------------------------- |
| ピーク抑制 | 速めの反応で突出を抑える               |
| 安定化     | 中程度の反応で音量差をならす           |
| パンチ     | 初期アタックを残して後ろを抑える       |
| 持続感     | 後半成分を相対的に持ち上げる           |
| 一体感     | グループ全体へ共通の動きを与える       |
| 特殊効果   | 大きなゲインリダクションで質感を変える |

重要なのは、コンプレッサーを「音を良くする装置」と考えないことである。アタック、リリース、レシオ、スレッショルドが、音の時間形状をどのように変えるかを判断する。

一般に、速いアタックは初期ピークを抑え、音を丸くしやすい。遅いアタックは初期ピークを通しやすく、輪郭を残しやすい。リリースは、圧縮がどの速度で元へ戻るかを決める。リリースが短すぎるとゲインが細かく上下して不自然な揺れが出ることがあり、長すぎると次の発音まで圧縮が残り、全体が平坦に感じられる場合がある。設定値そのものより、**音の包絡をどの形へ変えたいか**を先に決める。

外部信号を検出器へ入れ、その信号に応じて別トラックを圧縮する方法がサイドチェインである。用途は、明確なポンピングだけではない。主役が鳴る瞬間だけ背景を数dB下げる、低域同士の衝突時だけ一方を抑える、残響だけを一時的に引っ込める、といった**一時的な空間確保**に使える。

トランジェント処理は、発音直後の瞬間成分と、その後の持続成分の比率を変える。アタックを増やすと前に出やすくなり、減らすと奥へ引っ込みやすい。持続を増やすと厚みや余韻が増え、減らすと密度を下げられる。これは音量・EQ・コンプレッションの中間に位置するような処理で、編曲密度を後から調整する用途にも使える。

全トラックを強く圧縮すると、短時間では大きく整って聞こえても、セクション差や奥行きが失われる。強い地点を成立させるためには、弱い地点と瞬間的なピークが必要になる。ダイナミクスは問題ではなく、**構成を知覚させる情報**でもある。

### 5.6 空間とステレオ

ミックスの空間は、左右だけでなく前後と広がりを含む。

```text
                 far
        ambience / long tail

 left        support         right
       secondary elements

              lead
              near
```

前後感は、主に次の要素から作られる。

| 近く感じる       | 遠く感じる         |
| ---------------- | ------------------ |
| ドライ           | 残響が多い         |
| アタックが明瞭   | アタックが丸い     |
| 高域が残る       | 高域が減衰する     |
| 直接音が大きい   | 反射音の比率が高い |
| 中央・焦点が明確 | 広く拡散している   |

パンは左右位置を決めるだけでなく、中央の混雑を軽減し、要素同士の識別を助ける。中央で競合する音を左右へ分けるだけで、EQで大きく削らなくても分離できる場合がある。基本的には、最重要な要素と低域の核を中央付近に置き、補助要素を左右へ展開すると安定しやすい。ただしこれは固定ルールではない。左右差が作品の特徴になるなら、主役を偏らせる選択も成立する。

異なる残響量や反射の性質を使い分けると、前・中・後の距離層を作り、ミックス全体へ奥行きを与えられる。

リバーブは音を「豪華にする」ためだけの処理ではなく、音源がどの空間に存在するかを決める。複数のパートへ共通した反射や残響を与えることで、別々の音源を同じ仮想空間へまとめることもできる。

主要パラメータは次の通りである。

| パラメータ        | 主な効果                           |
| ----------------- | ---------------------------------- |
| Pre-delay         | 直接音から反射が始まるまでの距離感 |
| Decay             | 余韻の長さ                         |
| Early reflections | 壁や部屋の大きさ・距離感の手掛かり |
| Damping           | 高域がどれだけ早く減衰するか       |
| Width             | 残響の左右方向の広がり             |
| EQ                | 残響が占有する帯域                 |

長い残響ほど遠く聞こえるとは限らない。Pre-delayで直接音と残響を分ければ、長い余韻を持ちながら前面に保つこともできる。

リバーブは一つの追加レイヤーとして扱う。残響がドライ信号と同じ帯域を占有すると明瞭度が落ちるため、残響側のEQやダッキングで空間を整理する。特に低域の長い残響は濁りやすい。必要な重量は直接音に残し、残響側の低域を整理すると、サイズ感を維持しながら低域の輪郭を保ちやすい。

ディレイは、明確な反復として使う場合と、残響に近い空間感として使う場合がある。短いディレイは厚みや幅を作り、長いディレイは音の後ろに残像を作る。リバーブよりも反復の輪郭が明瞭なため、主役をぼかさず空間を足しやすい。フィードバックや高域減衰を使えば、反復を徐々に背景へ送れる。

複数パートを同じリバーブやアンビエンスへ送ると、異なる録音・音源でも同じ空間にいるようにまとめられる。共通の空間バスを使えば、各パートの距離差を保ちながら、部屋そのものの性格を共有できる。ただし「全部を同じ量だけ送る」と平面的になる。前景は少なく、背景は多く送るなど、同じ空間の中に距離差を作る。

幅は、左右端まで広げるほど良いわけではない。狭い状態が存在することで、広い状態が大きく感じられる。最も広い状態をクライマックスに温存したり、セクションごとに徐々に広げたりすると、幅そのものを展開として使える。

幅の作り方には次がある。

- 左右へ異なる音を配置する
- ダブルを左右へ分ける
- ステレオ残響を使う
- 微小な時間差・変調を使う
- M/S処理でSide成分を調整する
- 周波数帯域ごとに幅を変える

低域まで大きく広げると、位相差や再生環境による変化が目立ちやすい。低域の核を中央に寄せ、中高域で幅を作る方法は扱いやすい。

左右差や並列処理では、同じ信号の時間差・位相差が干渉を起こす。類似した信号を重ねると、位相関係によって一部の成分が加算・打ち消され、音色や音量が大きく変わることがある。ステレオで気持ちよく聞こえても、モノにすると主役や低域が急に弱くなる場合がある。完成前にはモノでも確認し、重要要素が大きく消えないことを確認する。

「広い = 遠い」ではない。広い主役を前面に置くことも、狭い背景音を遠くに置くこともできる。左右方向と前後方向を別軸として設計すると、ステレオ幅を増やすだけの空間設計から離れられる。

### 5.7 質感とバス処理

サチュレーションや歪みは、波形を非線形に変形し、新しい倍音を加える。軽い処理では密度や存在感が増え、強い処理では音色そのものが変わる。Drive や waveshaping は、この非線形変形の量や形を変えて質感を作る代表的な手段である。

用途は主に次の四つに分かれる。

| 用途     | 効果                                                 |
| -------- | ---------------------------------------------------- |
| 倍音補強 | 小さいスピーカーでも存在を感じやすくする             |
| 密度追加 | 音を前へ出し、薄さを減らす                           |
| 一体化   | グループへ共通の質感を与える                         |
| 特殊音色 | 強いクリップ、ビット低減、波形変形などで別物へ変える |

低域音に中高域の倍音を足すと、超低域を再生できない環境でも存在感を残せる。ただし倍音を増やすほど他パートとの競合も増えるため、全体で判断する。

複数トラックをグループへまとめ、共通処理をかけると、個別トラックでは作りにくい一体感を作れる。

```text
Layer 1 ─┐
Layer 2 ─┼─> BUS ─> EQ / Comp / Saturation ─> Main
Layer 3 ─┘
```

バス処理の目的は、個別処理を省略することだけではない。同じコンプレッサーやサチュレーションを共有することで、複数パートが一つの音像として同時に反応する。バスコンプレッションでは、複数信号が同じゲインリダクションの動きを共有するため、個別に処理する場合とは異なる一体感を作れる。

並列処理は、元の信号を保ちながら、強く加工した別経路を混ぜる。

```text
Dry ───────────────────────┐
                            ├─> Blend
Parallel ─> heavy process ─┘
```

代表例は並列コンプレッションである。強く圧縮した音を少量混ぜると、元のアタックを残したまま持続や密度を加えられる。並列歪み、並列リバーブ、並列フィルターも同様の考え方で使える。

処理の責務は、三段階へ分けると同じ問題を複数箇所で修正することを避けやすい。

```text
個別処理   : 問題修正・役割形成
グループ処理: 共通質感・一体感
マスター   : 全体のごく大きな傾向
```

グループ処理が多すぎると個々の音色差が失われ、個別処理だけだと全体がばらばらになりやすい。

## 6. 診断と仕上げ

### 6.1 基本ワークフロー

制作は、細部を順番に完成させるより、粗い全体像から段階的に精度を上げる方が破綻しにくい。

```text
1. セクションごとの役割とエネルギーを決める
2. 機能レイヤーを配置する
3. 音域と音色の競合を減らす
4. 各音の時間形状と質感を作る
5. フェーダーとパンだけで静的ミックスを作る
6. EQとダイナミクスで残った競合を整える
7. 奥行きとステレオ幅を作る
8. バス処理と質感を加える
9. オートメーションで時間方向の変化を作る
10. 参照音源・モノ・小音量・別環境で確認する
```

この順序は絶対ではないが、問題の原因を上流から下流へ確認する考え方として有効である。

### 6.2 濁り

濁りは「低中域が多い」だけで起きるわけではない。複数の原因を切り分ける。

| 原因         | 確認                           | 対応                               |
| ------------ | ------------------------------ | ---------------------------------- |
| レイヤー過多 | ミュートすると明瞭になるか     | 不要レイヤーを削る                 |
| 音域競合     | 重要帯域が重なっているか       | 編成・音源・EQを見直す             |
| 長すぎる余韻 | 音が次まで残っていないか       | Release、Decay、リバーブを短くする |
| 中央集中     | 全要素が中央にいないか         | パン・幅を整理する                 |
| 残響過多     | 残響単体が濁っていないか       | 残響EQ、送信量、ダッキング         |
| 低域過多     | 低域担当が複数重なっていないか | 役割を分ける                       |

周波数マスキングは、編曲、音量、パン、EQの複数手段で解決できる。

### 6.3 薄さ

薄さを感じたとき、低中域を無条件にEQで持ち上げると濁りへつながりやすい。原因を分ける。

- 中心となるボディ成分が弱い
- 低域担当が軽すぎる
- 倍音が少なく小さい再生環境で消える
- レイヤー間の音量差が大きすぎる
- ステレオだけ広く中央が空いている
- アタックだけ強く持続が短い
- 残響成分が多く直接音が弱い

必要なら音源自体を変えたり、ボディ専用レイヤーを追加したりする。編曲上の不足をEQだけで埋めない。

### 6.4 刺さり

刺さりは、高域量そのもの、狭い共振、強いトランジェント、歪みによる高次倍音、複数パートの同帯域加算などから生じる。

対処は、まず「どの瞬間・どのパートで発生するか」を特定する。常時問題なら静的EQ、特定の瞬間だけならダイナミックEQやオートメーション、アタックだけならトランジェントやコンプレッション、歪み由来なら音作りへ戻る。

### 6.5 主役の埋没

主役を単純に上げる前に、周囲を確認する。

```text
主役を +3 dB する
      ↓ ではなく
背景を -1 dB
競合帯域を少し整理
背景のアタックを丸める
背景を少し外側へ
残響を後ろへ
```

このように周囲を少しずつ譲らせると、主役だけを過剰に大きくせず前へ出せる。

### 6.6 セクション差の不足

セクション間の差を作る軸を確認する。

| 軸           | 変更例                |
| ------------ | --------------------- |
| レイヤー     | 追加・削除            |
| 音域         | 上下へ拡張・縮小      |
| 音色         | 明るさ、粗さ、倍音量  |
| 幅           | narrow → wide         |
| 奥行き       | dry → wet、near → far |
| ダイナミクス | 抑制 → 開放           |
| 質感         | clean → saturated     |
| 環境         | ambienceの追加・変更  |

すべてを変える必要はない。一つを大きく変える方法と、三〜四軸を少しずつ動かす方法を使い分ける。

### 6.7 参照音源

参照音源は「同じ音にする」ためではなく、自分の耳が長時間作業で偏ったときに座標を取り戻すために使う。

比較する項目は、総合音量を揃えた上で次を見る。

- 低域の量と輪郭
- 中域の密度
- 高域の明るさ
- 主役と背景の距離
- ステレオ幅
- 残響量
- セクション間のエネルギー差
- ダイナミクスの残り方

参照音源と比較するときは、音量差による錯覚を避けるため、できるだけ同程度の聴感音量に揃える。

### 6.8 複数環境での確認

完成に近づいたら、同じモニターで細部を追い続けるより、再生条件を変える。

| 条件           | 見つけやすい問題                             |
| -------------- | -------------------------------------------- |
| 小音量         | 主役と背景のバランス                         |
| モノ           | 位相、中央の混雑、重要要素の消失             |
| 小型スピーカー | 中域で成立しているか、低域依存が強すぎないか |
| ヘッドホン     | ノイズ、残響、左右の細部                     |
| スピーカー     | 前後感、低域、空間全体                       |
| 別室・別端末   | 聴覚の慣れによる偏り                         |

### 6.9 処理過多

処理が増え続ける場合、問題が上流にある可能性が高い。

```text
EQで削る
→ 音が細くなる
→ サチュレーションで太くする
→ 刺さる
→ ダイナミックEQを追加
→ 動きが減る
→ 並列処理を追加
```

この連鎖が起きたら、一度すべての処理を外して、音源・編成・音量関係から確認する。制作の目的は処理チェーンを高度にすることではなく、**少ない判断で全体が成立する状態を作ること**である。

### 6.10 最終チェック

| 観点             | 確認事項                                             |
| ---------------- | ---------------------------------------------------- |
| 構成             | セクションごとの役割と差が明確か                     |
| 密度             | 不要なレイヤーが残っていないか                       |
| 主役             | 各時点で焦点が自然に定まるか                         |
| 音域             | 重要帯域が常時競合していないか                       |
| 音色             | 似た音ばかり、または無関係な音ばかりになっていないか |
| 低域             | 重量と輪郭を分けて管理できているか                   |
| 高域             | 明瞭さと刺激の境界を超えていないか                   |
| ダイナミクス     | 到達点のための余白が残っているか                     |
| 空間             | 前後・左右・広さを区別して設計できているか           |
| 位相             | モノで重要要素が大きく消えないか                     |
| オートメーション | 固定値では作れない時間変化が必要箇所にあるか         |
| 処理量           | 上流の問題を下流処理で無理に補っていないか           |
| 参照             | レベルを揃えた比較で大きな偏りがないか               |
