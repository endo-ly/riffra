# J-POPの特殊和音 — dim7・m7♭5・aug・Blackadder

現代J-POP（アニソン、ゲーム音楽、アイドルソング、ジャズ寄りのポップス）で、サビ頭や転調点のような目立つ場所に置かれる変化和音を、作曲で引ける形にまとめたリファレンス。

和声を複雑にする方向は二つある。

| 方向   | 手段                                                                 | 例                                |
| ------ | -------------------------------------------------------------------- | --------------------------------- |
| 足す   | 三和音・7thに9th・11th・13thを積み、色を変える                       | `maj9`、`m9`、`add9`、`sus4`      |
| 変える | 構成音を半音ずらす、ベースを独立させる。3〜4音で方向性と曖昧さを作る | `dim7`、`m7♭5`、`aug`、Blackadder |

二つは組み合わせて使える。「複雑なコード」を求められたAIは前者に偏るため、本書は後者を扱う。どの和音も、響きの珍しさではなく**どの声部が半音で動き、どこへ着くか**で選ぶ。

これらの和音自体はクラシックやジャズで古くから使われている。現代J-POPに特徴的なのは、和音の種類よりも使い方である。

| 使い方                                     | 例                                                  |
| ------------------------------------------ | --------------------------------------------------- |
| サビ頭・サビ直前に強い緊張の和音を置く     | サビ頭の `#IVm7♭5 → IVmaj7`、サビ直前のBlk          |
| 複数の変化和音を連続させる                 | Blkの3連続、分数augの連続                           |
| 半音階的なベースと明快な旋律を組み合わせる | パッシングdim7、`#IV Blk → IVmaj7` のベース半音下降 |

表記は [SKILL.md](../SKILL.md) のディグリー表記に従う。Blackadder Chordは `Blk` と略し、`#IV Blk` はベースが `#IV` のBlackadderを表す。

## 2. 4つの和音の関係

### 構造

| 和音       | 構成音                                  | 対称性                               | 性格                                                        |
| ---------- | --------------------------------------- | ------------------------------------ | ----------------------------------------------------------- |
| `dim`      | R–♭3–♭5                                 | —                                    | dim7から♭♭7を除いた三和音                                   |
| `dim7`     | R–♭3–♭5–♭♭7                             | 短3度の等間隔。4つの根音で同じ音集合 | 2組の三全音を含み、複数の声部が半音で解決する。方向性が強い |
| `m7♭5`     | R–♭3–♭5–♭7                              | 非対称                               | 調性に結び付く。短調の `IIm7♭5`、長調の `VIIm7♭5`           |
| `aug`      | R–3–#5                                  | 長3度の等間隔。3つの根音で同じ音集合 | 5thの半音上昇で次の和音へ導く                               |
| Blackadder | ベースから半音 `0–2–6–10`（R–9–#11–♭7） | 上3音がaug                           | 長3度も短3度もなく、複数の機能を兼ねる                      |

### 一音の変更で互いに移る

| 変換             | 操作                        | 変わる性格                                   |
| ---------------- | --------------------------- | -------------------------------------------- |
| `dim7 → m7♭5`    | ♭♭7を半音上げる             | 対称的な導音和音から、調性的な前置和音へ     |
| `m7♭5 → Blk`     | ♭3を半音下げる（9thになる） | 3度が消え、augやドミナントとの関係が生まれる |
| メジャー `→ aug` | 5thを半音上げる             | 内声のクリシェ、ドミナントの変形             |
| `aug → aug7`     | ♭7を加える                  | ドミナントとしての性格が明確になる           |
| `aug7 → Blk`     | ♭7をベースへ移す            | 同じ音集合を分数augとして読み替える          |

### 担う役割

| 役割             | 仕組み                               | 効果                         |
| ---------------- | ------------------------------------ | ---------------------------- |
| 経過和音         | 二つの和音の間に半音階的な和音を挟む | ベースや内声を滑らかにつなぐ |
| 補助和音         | 元の和音を一時的に変えて戻る         | 装飾、緊張と緩和             |
| 導音的な和音     | 次の和音へ半音で進む音を含む         | 解決先への方向性を強める     |
| ドミナントの変形 | 5thや9thを変化させる                 | 終止の緊張や響きを変える     |
| 借用和音         | 同主調などの和音を取り込む           | 調性感の変化、陰影           |
| 分数コード       | 上声とベースに別々の役割を与える     | ベースを独立して動かす       |
| 転調の接続       | 同じ音集合を複数の調で読む           | 調と調を連続させる           |
| 独立した和声     | 特殊和音を長く保持する               | 不安定さや曖昧さを示す       |

一つの和音が複数の役割を同時に担うことが多い。たとえば半音下降するベース上の経過和音が、同時に裏コードとして働く。

### 機能は後続で決まる

- 同じ和音でも、次のコードで役割が変わる。`#IVm7♭5 → V` なら `II9` の根音省略、`#IVm7♭5 → IVmaj7` ならベースだけの半音下降になる。
- 異名同音の綴りは解決方向で決める。上行する導音は `#`、下行する変化音は `♭` で書く。Blkの10半音上の音は、短7度と読むか増6度と読むかで機能が変わる。

### 声部から組み立てる

コード名を先に決める必要はない。共通音を保持し、残りの声部を半音で動かした結果として特殊和音ができる。

- `I → Iaug/#IV → IVmaj7`：I・IIIを保持し、VをV→#V→VIと上げ、ベースを#IV→IVと下げる
- `#IVm7♭5 → IVmaj7`：上声をすべて保持し、ベースだけを半音下げる

コード名は複雑でも、声部の動きは単純である。複雑な和声を自然に聴かせるのは、この**共通音の保持と半音進行**である。

## 3. ディミニッシュ（dim7）

### 3.1 用法

| 用法               | 進行                          | 声部の動き                               | 効果                                                                                                                           |
| ------------------ | ----------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 導音和音           | `VIIdim7 → I`、`VIIdim7 → Im` | VII→I、IV→III（`Im` なら ♭III）、♭VI→V   | 解決先の根音の半音下の音（導音）が根音へ上がり、ほかの声部も半音か全音で解決先の構成音へ進む。どこへ解決するかが強く予告される |
| パッシング（上行） | `I → #Idim7 → IIm7`           | ベース I–#I–II                           | 隣のコードへ半音で滑らせる                                                                                                     |
|                    | `IV → #IVdim7 → V`            | ベース IV–#IV–V                          |                                                                                                                                |
|                    | `V → #Vdim7 → VIm`            | ベース V–#V–VI                           | 最も使いやすい。`#Vdim7` が `III7(♭9)` も兼ねる                                                                                |
| パッシング（下行） | `I/III → ♭IIIdim7 → IIm7`     | ベース III–♭III–II、♭V→IV、VI・Iは保持   | ベースと内声が揃って下がる                                                                                                     |
| 補助               | `I → Idim7 → I`               | 主音を保持し、ほかの声部だけ半音で揺らす | 主和音の持続に一瞬の陰影                                                                                                       |

導音和音は長短どちらへも解決でき、解決先の長短によって残りの声部の行き先（IV→IIIか♭IIIか）が変わる。

パッシングが次の和音への移動を重視するのに対し、補助は元の和音との往復が中心になる。補助のdim7は、転回形を変えながら同じ和声領域にとどまる使い方もできる。

dim7はドミナント7(♭9)から根音を省いた形と一致する。根音がなくても3rd・5th・♭7th・♭9thが残るため、元のドミナントと同じ方向性を保つ。パッシングのdim7は、ベースをつなぐと同時にセカンダリードミナントとして解決を作る。

| 元のドミナント | 根音省略形 | 解決先 |
| -------------- | ---------- | ------ |
| `V7(♭9)`       | `VIIdim7`  | `I`    |
| `III7(♭9)`     | `#Vdim7`   | `VIm`  |
| `VI7(♭9)`      | `#Idim7`   | `IIm`  |
| `II7(♭9)`      | `#IVdim7`  | `V`    |

### 3.2 異名同音と転調

`#Idim7`・`IIIdim7`・`Vdim7`・`♭VIIdim7` は同じ4音である。どの音を導音と読むかで、半音上の `II`・`IV`・`♭VI`・`VII`（長短どちらでも）の4方向へ解決できる。一つのdim7を新しい調の導音和音として読み替えれば、そのまま転調の入口になる。

転回形を並べて保持すると、根音が定まらない状態を長く続けられる。

### 3.3 置き方

| 置き方                   | 聴こえ方                               |
| ------------------------ | -------------------------------------- |
| 解決の直前に短く         | 導音としての方向性が前に出る           |
| 長く保持、転回形を連ねる | 対称構造による不安定さと緊張が前に出る |
| 旋律が構成音を強調する   | 和音の特異さが目立つ                   |
| 内声だけに置く           | 目立たず、ベースや旋律の連結を補助する |

### 3.4 使用例

| 楽曲                               | 進行・箇所                    | 用法                     |
| ---------------------------------- | ----------------------------- | ------------------------ |
| Mrs. GREEN APPLE「ライラック」     | `V → #Vdim → VIm`、サビ       | パッシング               |
| 米津玄師「さよーならまたいつか！」 | `#Vdim → VIm`                 | VImへの接続              |
| Official髭男dism「ラストソング」   | `#Vdim → VIm`、サビ           | 導音的な解決             |
| aiko「夢見る隙間」                 | `#Vdim7`、`♭IIIdim7`、`#Vdim` | 経過和音                 |
| 斉藤由貴「情熱」                   | `♭VIIdim`、`#IVdim`           | 変化和音からドミナントへ |

## 4. ハーフディミニッシュ（m7♭5）

### 4.1 II–V型の前置

| 進行                   | 効果                                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `IIm7♭5 → V7(♭9) → Im` | 短調の基本終止。`IIm7♭5` が短調のサブドミナント系、`V7` がドミナントの緊張を担う。`V7` に♭9を加えると、`IIm7♭5` との共通音と半音の動きが増える |
| `VIIm7♭5 → III7 → VIm` | 長調の中でVImへ一時的に終止する。`III7` の#V（VIへの導音）がVImへの方向性を強める。Bメロやサビで相対短調を前に出す                             |

### 4.2 #IVm7♭5 — 1つの和音から5方向

`#IVm7♭5` は `#IV–VI–I–III`。長調の中で最も応用範囲の広いm7♭5である。

| 進行               | 声部の動き                           | 性格                                                                                                              |
| ------------------ | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `#IVm7♭5 → IVmaj7` | ベース #IV→IV のみ。VI・I・IIIは保持 | 最小の動きで不安定から安定へ。`IVmaj7` のベースだけ半音上げた形。短い経過でも、長く保持してから解決しても成立する |
| `#IVm7♭5 → IVm7`   | #IV→IV、VI→♭VI、III→♭III。Iは保持    | 3声が同時に半音下がり、サブドミナントマイナーを強調する                                                           |
| `#IVm7♭5 → V`      | ベース #IV→V                         | `II9` の根音省略。Vへのセカンダリードミナント                                                                     |
| `#IVm7♭5 → VII7`   | IIImを主音とする `IIm7♭5 → V7`       | `IIIm` への一時的な短調終止、解決の遅延、転調の接続                                                               |
| `#IVm7♭5 → IIIm7`  | IIIは保持、ほかは近接音へ            | 共通音と内声の移動でつなぐ                                                                                        |

### 4.3 クリシェの終点に置く

`VIm → VIm(maj7) → VIm7 → #IVm7♭5`

`#IVm7♭5` は `VIm6/#IV` と同じ音集合である。上声はVImの響きを保ったまま、ベースだけが新しい方向へ動く。コードを一つずつ独立した和音と見るより、**保持される上声と動くベース**として組み立てる。

### 4.4 dim7との使い分け

`#IVdim7`（#IV–VI–I–♭III）と `#IVm7♭5`（#IV–VI–I–III）は第7音だけが違う。`IV → #IV → V` の経過和音にはどちらも使える。

|          | `#IVdim7`                  | `#IVm7♭5`                          |
| -------- | -------------------------- | ---------------------------------- |
| 第7音    | ♭III（ノンダイアトニック） | III（ダイアトニック）              |
| 緊張     | 導音的で強い               | ダイアトニックとの共通性で柔らかい |
| 向く用途 | 対称性を使った転調         | `IIm7♭5 → V7` 型の調性的な機能     |

旋律や伴奏がIIIを鳴らしているならm7♭5、♭IIIを使いたいならdim7が自然に収まる。

### 4.5 使用例

| 楽曲                               | 進行・箇所                   | 用法                   |
| ---------------------------------- | ---------------------------- | ---------------------- |
| SAKANAMON「ハロ」                  | `#IVm7♭5 → IVmaj7`、歌い出し | IVmaj7への半音下降     |
| Official髭男dism「ラストソング」   | `#IVm7♭5 → IVmaj7`、サビ     | IVmaj7への半音下降     |
| 米津玄師「さよーならまたいつか！」 | `#IVm7♭5 → IVm7`、Aメロ      | サブドミナントマイナー |
|                                    | `#IVm7♭5 → VII7`、サビ       | `IIm7♭5 → V7` 型の連結 |
| 一青窈「ハナミズキ」               | `VIIm7♭5 → III7 → VIm`、サビ | 相対短調への一時終止   |
| 斉藤由貴「情熱」                   | `VIIm7♭5`                    | 短調的な和声への接続   |

## 5. オーギュメント（aug）

### 5.1 半音上昇のクリシェ

メジャーコードの5thを半音上げ、その音を次の和音の構成音へ送る。

| 進行                 | 声部の動き             | 備考                                   |
| -------------------- | ---------------------- | -------------------------------------- |
| `I → Iaug → IVmaj7`  | V→#V→VI。I・IIIは保持  | IからIVへ向かう内声クリシェ            |
| `I → Iaug → I6`      | V→#V→VI                | 根音を固定したまま線だけを動かす       |
| `V → Vaug → I`       | II→#II→III、VII→I      | 通常の `V → I` より半音の動きが2本多い |
| `III → IIIaug → VIm` | VII→#VII（=I）、#V→VI  | VImへのセカンダリードミナントの変形    |
| `VI → VIaug → IIm`   | III→#III（=IV）、#I→II | IImへのセカンダリードミナントの変形    |

### 5.2 ドミナントの変形

`V7(#5)` は `V–VII–#II–IV`。#IIがIIIへ半音で上がり、主和音の3rdを導く。

| 和音        | 構成音       | 性格                                   |
| ----------- | ------------ | -------------------------------------- |
| `aug`       | R–3–#5       | 増三和音。機能は前後で決まる           |
| `aug7`      | R–3–#5–♭7    | ♭7でドミナントとしての機能が明確になる |
| `aug(maj7)` | R–3–#5–7     | ♭7を持たず、ドミナントとして働きにくい |
| `7(#5,♭9)`  | R–3–#5–♭7–♭9 | 解決先への半音が増えた変化ドミナント   |

### 5.3 分数augと異名同音

- ベースが上声から独立して動くため、augのクリシェに加えて、ベースの半音下降やトライトーン代理の性質を組み込める。
- 上声のaugとベースの音程で区別する。`Iaug/III` は転回形にすぎない。ベースから `0–2–6–10` になる分数aug（`Iaug/#IV` など）はBlackadderである（6）。
- `Iaug`・`IIIaug`・`♭VIaug` は同じ3音である。転調の前後で同じ音集合を保ち、別の和音として読み替えられる。

### 5.4 使用例

| 楽曲                             | 進行・箇所                | 用法                             |
| -------------------------------- | ------------------------- | -------------------------------- |
| ヨルシカ「ブレーメン」           | `V(#5)`、冒頭パートの終盤 | 変化した#5を旋律で強調する       |
| Official髭男dism「ラストソング」 | `IIIaug`、`III7(#5)` など | セカンダリードミナント、声部進行 |
| SAKANAMON「ハロ」                | `IIIaug` 系               | マイナーコードへの接続           |
| aiko「夢見る隙間」               | `#Vaug`、`IIIaug`         | クリシェ、フレーズの終端         |
| 斉藤由貴「情熱」                 | `IIIaug`、`♭IIIaug`       | ドミナントの変形                 |

## 6. Blackadder Chord

### 6.1 構造と表記

- ベースから半音 `0–2–6–10`。ベースを根音とすると R–9–#11–♭7 で、3度と5度がない。ここでのベースは最低音であり、和声的な根音とは限らない。
- 3度がないため、長調・短調の性格が決まらない。これが分数aug・ドミナント・ハーフディミニッシュ・増六和音といった複数の解釈を可能にする。
- 上3音はaugで、ベースXの全音上・増4度上・短7度上のどれを根音としても同じ音集合になる。

| Blk        | 分数aug表記の例                |
| ---------- | ------------------------------ |
| `#IV Blk`  | `Iaug/#IV`（= `IIIaug/#IV`）   |
| `♭II Blk`  | `Vaug/♭II`（= `VIIaug/♭II`）   |
| `♭VII Blk` | `Iaug/♭VII`（= `IIIaug/♭VII`） |

- 別名はイキスギコード、Japanese Augmented Sixth。ただし増六和音として働くのは、6つの型のうち増六和音型だけである。
- 3度を補うと機能が確定する。長3度を加えるとドミナント `9(#11)`、短3度を加えると `m7♭5(9)` 系になる。旋律が3度を鳴らすかどうかで、同じBlkの性格が変わる。

### 6.2 別の和音からの導き方

| 見方                     | 導き方                                               |
| ------------------------ | ---------------------------------------------------- |
| aug7の第3転回形          | `Iaug7` の♭7（♭VII）をベースに置くと `♭VII Blk`      |
| m7♭5の変形               | ♭3を半音下げる。`#IVm7♭5` のVIを#Vにすると `#IV Blk` |
| 3度・5度省略のドミナント | `X Blk` に長3度を補うと `X9(#11)`                    |

### 6.3 6つの型

同じ音集合でも成り立ちは一つではない。SoundQuestは3系統6型に分類している。実曲では複数の型が同時に成立することがある。

| 系統             | 型                     | 成り立ち                                          | 典型                                                                       | 置き方                                                  |
| ---------------- | ---------------------- | ------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------- |
| ホールトーン     | ホールトーン型         | 全音音階の構成音から作る                          | `♭II Blk → VII Blk → VI Blk → V7 → Im`（全音ずつ平行移動）                 | 調性から浮かせる。根音の機能より響きの統一感            |
| スラッシュコード | 偶成和音型             | 声部が独立して動いた結果、一瞬だけできる          | `I → Iaug/#IV → IVmaj7`（ベース下降、上声上昇）                            | 短く。複数楽器の合算で成立することもある                |
|                  | ベース単独反転型       | augの上声を保ち、ベースだけ三全音先へ動かす       | `Iaug → Iaug/#IV`                                                          | 長く保持でき、上に旋律を置ける。サビ頭向き              |
| テンションコード | ドミナントナインス型   | 3度・5度を省いたドミナント `9(#11)`               | `IIm7 → ♭II Blk → Imaj7`（裏コード）                                       | 9th・#11thの緊張を強調し、調性は曖昧にする              |
|                  | ハーフディミニッシュ型 | ♭3を省いた `m7♭5(9)`                              | `#IVm7♭5 → #IV Blk → IVmaj7`                                               | `IIm7♭5` 系の進行に入れやすい。後続にドミナントも置ける |
|                  | 増六和音型             | 10半音上の音を増6度と読み、外側へ開いて解決させる | `♭VI Blk → V`（♭VIと#IVがVのオクターブへ）、`♭II Blk → V7`（ナポリ的接続） | ナポリの和音・増六和音のクラシック的な文脈              |

型どうしの違い：

- **偶成和音型とベース単独反転型** — 偶成和音型は各声部が旋律として動いた結果で、短く現れる。ベース単独反転型は、上声のaugとベースの関係そのものが和声構造になるため、長く保持したり和音の上に旋律を置いたりできる。
- **ドミナントナインス型とハーフディミニッシュ型** — ドミナントナインス型は主和音への直接の解決が中心になる。ハーフディミニッシュ型はm7♭5系の機能を持つため、後続にドミナントを置いて解決を先へ延ばす展開も作れる。
- ドミナントナインス型の裏コード進行は、`Vaug/♭II` という分数augとしても読める。同じ音集合が複数の機能を持つ典型である。

### 6.4 主要な進行

| 進行                      | 声部の動き                          | 機能・使いどころ                                                                                                                                            |
| ------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `#IV Blk → IVmaj7`        | #IV→IV、#V→VI。I・IIIは保持         | 最も実用的。Iaugの上声と独立したベース、IVへの裏コード、`#IVm7♭5` の変形、半音移動による偶成和音の4つの読みが重なる                                         |
| `#IV Blk → IVm`           | #IV→IV、III→IV。#V（=♭VI）・Iは保持 | サブドミナントマイナーへの接続                                                                                                                              |
| `♭II Blk → Imaj7`         | ♭II→I、#II→III。V・VIIは保持        | 裏コード型の解決。ベース下降と上声上昇が同時に起き、非常に滑らか                                                                                            |
| `♭VII Blk → VIm`          | ♭VII→VI、#V→VI。I・IIIは保持        | IIIからVImへの進行の変形で、相対短調へ解決する。`III7 → VIm` よりベースが独立する。サビ前の `III7` からサビ頭の `♭VII Blk` へ進むと、緊張をサビへ持ち越せる |
| `IVm7 → ♭VII Blk → Imaj7` | ♭VII→VII、#V→V。I・IIIは保持        | バックドア進行の変形。IVmの陰りを引き継いで主和音へ                                                                                                         |

`#IV Blk` は、`Iaug`・`#IVm7♭5`・`#IV7`・半音階の経過和音のどこからでも入れる。ほかの音度のBlkより進行に組み込みやすい。

### 6.5 機能を時間で変えて転調する

Blkは、同じ音集合が鳴っている間に、聴き手の感じる機能を変えられる。`I` と `Iaug` を反復してから `Iaug/#IV → VIImaj7` へ進むと、#IVを主音とする調へ移れる。

1. `Iaug/#IV` に入った瞬間は、上声が保持されるため `Iaug` の延長に聴こえる。
2. ベース#IVが定着し、旋律が#IV上の長3度（#VI）を出すと、#IV上のドミナントに聴こえ始める。
3. `VIImaj7` へ進むと、BlkはVIIへ向かうドミナントとして働く。この `VIImaj7` を新しい調のIVと読み替える。

コードチェンジの瞬間は前の調の延長として聴かせ、和音の後半で新しい調への方向性をはっきりさせられる。構成音を大きく変えず、和声機能の解釈だけで三全音離れた調へ移る。augの対称性とBlkの3度の不在がこれを可能にする。

### 6.6 置き方

| 置き方         | 聴こえ方                                              |
| -------------- | ----------------------------------------------------- |
| 短い経過和音   | 和音そのものより、声部の滑らかな動きが聴こえる        |
| 長く保持       | augとベースの関係、3度の不在、#11・♭7の緊張が前に出る |
| サビ頭         | 次の和音への解決が、サビの形そのものを特徴づける      |
| 連続して並べる | 通常の調性から一時的に離れた響きの区間になる          |

## 7. 曲の中に置く

### 7.1 緊張と解決の設計

| 方法         | 内容                                       | 向く和音                    |
| ------------ | ------------------------------------------ | --------------------------- |
| 直接解決     | 安定した和音の直前に短く置き、半音で着く   | dim7、aug                   |
| 遅延解決     | ドミナントや変化和音を挟んで到達を遅らせる | m7♭5（→ `VII7` など）       |
| 偽終止       | 予想される解決先と別の和音へ進む           | —                           |
| 長い提示     | 冒頭に長く置き、次の和音で解決する         | m7♭5、Blk                   |
| 連続使用     | 対称性や共通の音階で緊張を持続させる       | dim7の転回形、Blkの全音平行 |
| 装飾的な往復 | 元の和音を一時的に変えて戻る               | dim7、aug                   |
| 転調         | 同じ音集合を別の調の機能へ読み替える       | dim7、aug、Blk              |

### 7.2 セクション別の置き場所

| セクション | 代表的な用法                                    |
| ---------- | ----------------------------------------------- |
| Aメロ      | パッシングdim7、内声クリシェ、短い装飾和音      |
| Bメロ      | セカンダリードミナント、m7♭5、augで緊張を上げる |
| サビ直前   | dim7、変化ドミナント、Blkで解決を遅らせる       |
| サビ頭     | `#IVm7♭5`、Blkで不安定に始める                  |
| サビ途中   | 半音下降の進行、分数コード、ドミナントの変形    |
| 間奏       | 対称的な和音、ホールトーン、異名同音による転調  |
| アウトロ   | 補助的なdim7、クリシェ、終止の変形              |

これは固定の割り当てではない。和音の長さ、旋律、リズム、ベースの置き方で役割は変わる。

サビは通常、`I`・`IV`・`VIm` のような安定した和音で始まる。サビ頭に `#IVm7♭5 → IVmaj7` を置くと、最初に緊張を示して直後に解決し、到達点がサビの2つ目以降の和音に移る。サビの冒頭に独特の浮遊感や切なさが出る。

置き方は二つあり、サビの境界を挟むかどうかで印象が変わる。

| 方法                       | 例                                      | 要になる箇所                         |
| -------------------------- | --------------------------------------- | ------------------------------------ |
| サビ前の緊張を引き継ぐ     | サビ直前に `#IVm7♭5`、サビ頭に `IVmaj7` | サビ直前のドミナントや変化和音       |
| サビの中に新しい緊張を作る | サビ頭に `#IVm7♭5`、2つ目に `IVmaj7`    | サビ頭の特殊和音から次の和音への解決 |
