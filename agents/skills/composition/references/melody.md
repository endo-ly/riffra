# メロディ — 作曲リファレンス

主旋律の音高、輪郭、時間配置、モチーフ、フレーズ、歌詞との対応、コードとの関係を扱う。メロディは、瞬間ごとの音の選択と、数小節から楽曲全体に及ぶ形の両方によって成立する。本稿は、旋律の具体的な設計方法と、得られる音楽的な効果を調べるための資料である。旋律の担い手は歌に限らず、シンセ、ギター、管楽器などのリードも同じ枠組みで扱う。

## 1. 記法と音高の設計

### 旋律の記法

| 記法                          | 内容                                                           |
| ----------------------------- | -------------------------------------------------------------- |
| `旋律: III → IV → V`          | 3つの旋律音の順序。単独の `III` は和音ではなく単音のディグリー |
| `旋律: V↑ → III↑ → I↑`        | `↑` は基準のオクターブより高い音域。同じ記号の `↓` は低い音域  |
| `III(8分) → V(4分) → 休(8分)` | 音価と休符を明示する場合の書式                                 |

たとえば `旋律: VI → #V → VI` と `コード: IVmaj7 → III7 → VIm7` は、前者の最初の `VI` が `IVmaj7` の3rd、次の `#V` が `III7` の3rd、最後の `VI` が `VIm7` の根音という関係を表す。**主音から見た音高**と、**現在のコードから見た役割**は別の座標である。

音価を省略した譜例は音高関係だけを示す。オクターブ記号を省略した場合は、原則として隣接音への移動が分かりやすい配置を想定する。

### 調の中心と旋律音の傾向

同じ音が何度現れても、旋律の中心は頻度だけで決まらない。フレーズの終点、長く保持される音、強調される音、反復して戻る音、伴奏との関係が組み合わさって中心を形作る。主音 `I` に戻る旋律は直接的な帰着を生みやすいが、`III` や `V` を終点にすれば主和音の上で開いた余韻を残せる。

| 主音基準の音 | 長調を中心とする場合の代表的な働き       | 旋律上の扱い                             |
| ------------ | ---------------------------------------- | ---------------------------------------- |
| `I`          | 主音。帰着点、反復の基準                 | 長音、終端、反復開始で中心を明示         |
| `II`         | `I` と `III` の間。前後へ進める          | 導入、通過、`I` への下降、`III` への上行 |
| `III`        | 長調の3rd。長調らしい明るさを明確化      | 主和音上の安定点、`IV` との半音移動      |
| `IV`         | `III` の半音上。近接する解決の期待を作る | `IV → III`、旋律のため息、保留された高音 |
| `V`          | 主音の完全5度上。中心を支える別の柱      | 上昇の中継点、反復音、開放的な終端       |
| `VI`         | 主音に対する6th。`V` と `VII` の間       | 柔らかな色、`VI → V`、`VI → VII → I↑`    |
| `VII`        | 主音の半音下。導音として働きやすい       | `VII → I↑`、長く保つことで未解決感       |

この表は長調における**主音との相対関係**を示す。実際には、各音の背後で和音が変わるたびに性質も変わる。たとえば `III` は `I` 上では3rd、`V` 上では13th、`IVmaj7` 上ではmaj7thである（§4）。

短調では `Im` を中心に、`♭III`、`♭VI`、`♭VII` が自然短音階を特徴付ける。`VII` を導入すると `VII → I↑` の半音引力が得られ、`VI` を使うとドリアンや上行形の旋律的短音階に近い色が現れる。したがって、短調の旋律は一つの固定された7音だけでなく、**導音 `VII` と下方の `♭VII`、長6度 `VI` と短6度 `♭VI` の選択**によって細かな性格を変えられる。

### 音域とテッシトゥーラ

音域は最低音から最高音までの範囲、テッシトゥーラは旋律が主として滞在する音域である。最高音が同じでも、低域から一度だけ跳び上がる旋律と、高域に長く留まる旋律では、強調される場面、演奏・発声の負荷、音色が異なる。主旋律の設計では**最高音そのもの、そこまでの距離、到達までの時間、到達後の滞在**を別々に考えるとよい。

| 音域の使い方                       | 生まれる形                                             |
| ---------------------------------- | ------------------------------------------------------ |
| 中音域を主とし、高音を一度だけ使用 | 最高音を明確な転換点や頂点にできる                     |
| 狭い音域で同音反復を多用           | 音高よりも言葉、アクセント、リズムが主役になる         |
| 高音域を長く保持                   | 継続する緊張や力強さ。瞬間の最高音とは異なる負荷を持つ |
| フレーズごとに中心域を上げる       | 音数を増やさず、セクションに向かう上昇感を作る         |
| 高音到達後に低域へ落とす           | 頂点の輪郭を際立たせ、次のフレーズの出発点を作る       |
| 低い音を反復の終端に置く           | 高さによる解決より、重さ・沈静・余韻を表しやすい       |

音域の意味は旋律の担い手によって変わる。歌では声区の切替、母音、継続時間、音量が負荷と音色を左右し、同じ高さでも張り上げた声と抜いた声では別の表情になる。楽器では、弦やレジスターの切替で音色が変わる位置、その楽器が最も鳴る帯域、速いパッセージを弾ける範囲が同じ役割を持つ。シンセでは物理的な限界がない分、伴奏との帯域の分担と、音色が細くなる・耳に刺さる高さが実質的な上限になる。いずれの場合も、最低音・最高音だけでなく、**長音と頻出音がどこに集まるか**が実用的な判断材料になる。

### 順次進行・跳躍・輪郭

旋律の局所的な動きは、同音反復、隣接する音階音への順次進行、それを超える跳躍に分けられる。順次進行は方向の連続性を、跳躍は遠隔の音への焦点移動を作る。大きな上行跳躍では到達音が突然前景化し、下降跳躍は到達後の音域を一気に変える。連続した跳躍は和音の分散形や鋭い輪郭を作りやすい。

`旋律: I → II → III → V↑ → IV↑ → III↑` は、前半の上行と跳躍を経て、後半で順次下降する山型。`旋律: V → III → I → IV → VI` は一度沈んで上昇する谷型。同じ音高集合でも、頂点の位置と方向転換の順番が変わるとフレーズの意味が変わる。

跳躍の後に逆向きの順次進行を続けると、跳躍の到達点が際立ったまま線を回収できる。一方、`I → V↑ → III↑ → VII↑` のように跳躍を重ねれば、ひとつの大きな上昇運動として聞かせられる。大きな跳躍を「解消する」ことも「連続させる」ことも構造上の選択であり、前者はまとまり、後者は推進や緊迫を作りやすい。

輪郭は局所的な形と大きな形の二層で捉える。1小節の中に山が複数あっても、8小節を通して最高音が少しずつ上がれば大局的には上昇形である。長いフレーズでは**各部分の最高音をつないだ線**と**各部分の終端音をつないだ線**が、音符の細部よりも展開を説明する場合がある。

### 音高語彙の制限と開放

メロディは、同じ調の中でも使用音を絞ることで特徴を持つ。メジャー・ペンタトニック（四七抜き）は `I・II・III・V・VI` を中心とし、長調の半音関係 `III–IV` と `VII–I` を含まない。順次進行の刺激が弱まる分、跳躍形、同音反復、リズムの輪郭を前へ出しやすい。マイナー・ペンタトニックは `I・♭III・IV・V・♭VII` で、マイナーやブルース、ロック由来のメロディの骨格になる。

| 音高語彙                 | 特徴になる音               | メロディ上の効果                           |
| ------------------------ | -------------------------- | ------------------------------------------ |
| メジャー・ペンタトニック | `I II III V VI`            | 半音を含まない開いた節回し、輪郭が明瞭     |
| 長調の7音                | `IV` と `VII` を加える     | `IV → III`、`VII → I` の半音進行が得られる |
| ナチュラルマイナー       | `I II ♭III IV V ♭VI ♭VII`  | 短3度・短6度・短7度による陰影              |
| ドリアン                 | `I II ♭III IV V VI ♭VII`   | マイナー3rdと長6度の共存                   |
| ミクソリディアン         | `I II III IV V VI ♭VII`    | 長3度を保ちつつ、導音を弱めた開放感        |
| リディアン               | `I II III #IV V VI VII`    | `#IV` が明るい浮遊感と新しい半音関係を作る |
| フリジアン               | `I ♭II ♭III IV V ♭VI ♭VII` | 主音の直上にある `♭II` が強い近接色になる  |

たとえば `I → III → V → VI → V → III` を反復しておき、区間の終端にだけ `IV → III` を加えると、同じ調の中で新しい半音関係が聞こえる。特殊音を常時使うよりも、**普段の語彙から外れる音をどこに置くか**が個性を生む。モードの名称をすべて意識するより、各フレーズが実際にどの音を使い、その音がどこで目立つかを把握する方が作曲に直結する。

## 2. 旋律の時間構造と言葉

### 音の開始・保持・終わり

旋律の時間的な形は、音を鳴らし始める瞬間、保持する長さ、音を切る瞬間、次の音までの空白から生まれる。ここでは主旋律上での作用に絞り、拍子やドラムのグルーヴ自体は [rhythm-section.md](rhythm-section.md) で扱う。

**開始位置**では、小節頭で始める形、前小節から食い込む弱起、裏拍から始まる形、小節頭を空ける後発型に違いがある。`旋律: III → III → V → IV` の音高を固定しても、最初の `III` をどこに置くかで音楽的な重心が変わる。小節をまたぐ音の保持も、コードの切替と同時に生じる摩擦や先行感に関わる（§4）。

**持続と密度**では、短音の連続が活動量を作り、長音が到達点や余韻を作る。長音は、ピッチが変わらない時間の中で伴奏や歌唱音色が変化する余地を生む。同じ四音でも「短・短・短・長」と「長・短・短・短」では、重心が終端に向かうか冒頭から提示されるかが異なる。

**音の切り方**では、滑らかにつなぐ、短く切る、長音を減衰させる、次の音を重ね気味に入れる、といったアーティキュレーションが旋律の輪郭を補強する。音高・音価が同じでも、言葉の子音と音の切れ目を揃えるかずらすかで印象は変わる。

### 休符・呼吸・余白

休符はモチーフの境界、次の到達音の強調、歌の呼吸、他パートに渡す時間を生み出す。短い休符は区切りを、長い休符は一時的な不在そのものを際立たせる。休符の直前に置いた音は、余韻の中で聴き手の記憶に残るため、**何の音の後に空白を置くか**が重要になる。

| 形                     | 旋律上の働き                                               |
| ---------------------- | ---------------------------------------------------------- |
| モチーフの後の短い休符 | 同じモチーフの次の反復を認識しやすくする                   |
| 長音の後の休符         | 到達音の余韻を区切りとして聴かせる                         |
| フレーズ開始前の空白   | 歌い出しへの期待を作り、前小節と対比する                   |
| 高音直後の休符         | 到達の強さを残しつつ、次のフレーズを別の高さから開始できる |
| 区間途中の突然の無音   | 連続していた言葉や運動を中断させ、次音に焦点を当てる       |

呼吸は旋律の区切りに自然な時間構造を与える。歌や管楽器では、息継ぎを伴う箇所に語句の切れ目、音価の長い後、小さな下降、モチーフの完了などが重なりやすい。長い一息のフレーズでは、前半の音高・音量を抑え、到達点に向けて集中させると負荷と表情の双方を調整できる。歌唱上の長さはBPMだけでなく、語の密度、子音の連続、高い母音の持続にも左右される。息の制約がない楽器やシンセでも、区切りを置かなければフレーズの境界は聞こえない。呼吸の位置は、物理的な必要がなくても旋律の句読点として設計できる。

### 反復するリズムと音高の独立

メロディの同一性は、音高列だけで決まるわけではない。**同じリズムを異なる音高で反復**すれば、言葉の運び方を保ったまま和声や音域に追従できる。反対に**同じ音高列を異なるリズムで反復**すれば、主題の音の順序を残しながら推進力や言葉のアクセントを変えられる。

たとえば音高が `III → III → V → IV` であるモチーフを、最初は後半に長音を置き、次は冒頭に長音を置くと、同じ四音が別の句読点を持つ。一定のリズムの上で `III → V → VI → V` を `IV → VI → VII → VI` にずらす場合は、歌のリズムを保ちながら旋律だけが上昇する。ここで重要なのはリズムパターンの細部より、**変形後も何が同じものとして聞こえるか**である（§3）。

### 日本語歌詞との対応

日本語の歌メロでは、旋律が言葉を区切り、言葉が旋律の長短やアクセントを決める。歌詞の字数を数えるときは表記文字数より**モーラ（拍）**が有用である。「きょう」は `きょ・う` で2モーラ、「がっこう」は `が・っ・こ・う` で4モーラとなる。ただし促音「っ」、撥音「ん」、長音の後半は、前の音符に含めることも独立した時間を与えることもある。[^1]

| 歌詞側の要素     | メロディへの具体的な影響                                       |
| ---------------- | -------------------------------------------------------------- |
| 語の境界         | 休符、長音、音高の方向転換で意味の単位を明瞭にする             |
| モーラ数         | 音符を細かく分けるか、母音を一音にまとめるかを決める           |
| 促音・撥音・長音 | 発音可能な持続と次の子音の立ち上がりを左右する                 |
| 助詞・接続       | 短い通過音にもできるし、あえて長く引いて言葉の流れを変えられる |
| 語頭・重要語     | 跳躍、長音、拍位置、最高音を置くと記憶に残りやすい             |
| 母音             | 高音の持続、開放的な発声、音色の変化に関わる                   |
| アクセント・抑揚 | 日常の発話の方向を保つと自然な語り、ずらすと歌特有の強調を作る |

日本語は語の高低アクセントを持つため、音の高さと語の抑揚が意味の知覚に関わる。言葉のアクセントに沿う旋律は聞き取りを助け、反対方向の旋律は、強いリズムや反復によって言葉を音楽的な素材として際立たせることがある。詞先では発話の強調点を音高と音価に移し、曲先ではフレーズの着地点に意味上の重要語や伸ばしやすい母音を当てると、両者の関係を設計しやすい。[^2]

高速な歌詞では、モーラを細分するだけでなく、**どの言葉を同じ高さでまとめ、どの単語でピッチを変えるか**が聞き取りやすさを左右する。同音連打に近い部分は子音やリズムの変化を前へ出し、重要語で跳躍や長音を使うと、高密度な言葉の中に焦点が生まれる。逆に、単語ごとに大きく音高を動かせば、音の変化そのものが注意を奪い、疾走感や不安定さを強められる。

### 言葉を持たない旋律

楽器やシンセが主旋律を担うとき、言葉が担っていた区切り・強調・語りの役割は、リズムの輪郭、アーティキュレーション、音色の変化が引き受ける。モチーフの同一性も、音高列よりリズムと奏法の組合せで記憶されやすい。

| 器楽で得られるもの                       | 旋律上の働き                                                         |
| ---------------------------------------- | -------------------------------------------------------------------- |
| 声域・息の制約がない                     | 広い跳躍、速い分散和音、長い無休止のパッセージを主題そのものにできる |
| ベンド、スライド、ポルタメント           | 音高の到達を時間をかけて聴かせ、半音や微分音の揺れを表情にする       |
| ハンマリング、トリル、装飾の連打         | 骨格音の周りに密度を作り、同じ音を保ったまま運動を与える             |
| スタッカート、ミュート、レガートの切替   | 同じ音高列を別のキャラクターとして反復できる                         |
| 音色の時間変化（フィルター、ビブラート） | 長音の中で強弱以外の変化を作り、保持そのものを聴かせる               |
| オクターブや和音での重ね                 | 単音より太い輪郭を持つフックを作る                                   |

歌の旋律を楽器へ移すと、言葉が支えていた抑揚や句読点が抜けるため、同じ音列でも平板に聞こえることがある。逆に、器楽的な音形をそのまま歌へ移すと、跳躍や速さが歌唱の限界に当たる。歌と楽器が交互に主旋律を担う曲では、両者に同じモチーフを持たせつつ、それぞれの得意な形へ変形させると、統一感と対比を両立できる。

## 3. モチーフとフレーズ

### モチーフの識別

モチーフは、繰り返し現れたときに同じ素材の変形だと分かる短い旋律単位である。固有性は音名の列だけでなく、反復音、リズム、跳躍の方向、輪郭、休符、アクセント、終端の長さから生まれる。二音でも固有の間隔とリズムを持てばモチーフになり、数小節あっても内部のまとまりが弱ければ一つのモチーフとしては捉えにくい。

次の三つの仮想素材は、使用音が近くても印象の中心が異なる。

| モチーフの核     | 旋律例                 | 同一性を支える要素                 |
| ---------------- | ---------------------- | ---------------------------------- |
| 同音反復後の跳躍 | `III → III → V↑ → IV↑` | 反復から上行跳躍に転じるタイミング |
| 跳躍と折り返し   | `I → V↑ → IV↑ → III↑`  | 最初の広い跳躍と、その後の下降     |
| 半音の近接       | `IV → III → IV → V`    | 半音の往復を含む細かな揺れ         |

モチーフの輪郭は「上がる・止まる・下がる」、リズムは「短い・短い・長い」、音程関係は「同音反復・跳躍・順次」のように、それぞれ別個に抽出できる。曲を通して何を継承させるかによって、認識される共通性の強さが変わる。

### 変形の語彙

モチーフを変形するときは、**聴き手が同じものと認識する特徴**を残し、ほかの特徴を変更する。以下の操作は単独でも組み合わせても成立する。

| 操作             | 保つもの・変えるもの                           | 音楽上の働き                                         |
| ---------------- | ---------------------------------------------- | ---------------------------------------------------- |
| 反復             | 音高、リズム、配置を保持                       | 短時間でモチーフを記憶させる                         |
| 移高             | 相対的な音程や輪郭を保ち、全体の高さを移す     | 同一性を保ちながら音域と和声に合わせる               |
| 調内移動         | 音階上の位置をずらし、音程の大小を調に合わせる | 同じ形のままダイアトニックな色が変わる               |
| 輪郭保持         | 上下方向を残し、各跳躍の幅を変える             | 似た身振りを残しつつ別の旋律になる                   |
| 反転             | 上行を下行、下行を上行へ変える                 | 元の形への対比・応答を作る                           |
| リズム拡大・縮小 | 相対的な音価を伸縮                             | 素材をゆったり提示、または圧縮して加速する           |
| 拍位置の移動     | 音高・音価を保ち、開始位置を変える             | 同じ素材に別のアクセントが生じる                     |
| 終端変更         | 冒頭を共有し、最後の音高や音価だけ変える       | 問いと応答、未完と完結を作る                         |
| 断片化           | 目立つ一部分だけ取り出す                       | 反復間隔を縮め、展開に速度を与える                   |
| 延長             | 元の素材の前後や内部に音を追加                 | 終点を遅らせる、到達を大きくする                     |
| 装飾             | 骨格音の間に経過音・刺繍音を加える             | 同じ旋律の密度と運動を増やす                         |
| 逆行             | 音の順序を逆に並べる                           | 対称的な変形。反転より元型の認識が弱くなることが多い |
| 特徴の除去       | 目立つ跳躍や反復を減らし、終止へ運ぶ           | 繰り返しが一区切りになる感覚を作る                   |

たとえば原型を `III → III → V → IV` とする。

- **終端変更**：`III → III → V → III`。最初の三音が共通し、最後だけ落ち着いた方向へ戻る。
- **輪郭保持**：`III → III → VI → V`。同音反復、上行、下降という身振りを保ちながら、上行の幅を3度から4度へ広げる。
- **反転**：`V → V → III → IV`。反復の後に下がり、少し戻る。
- **断片化**：`III → III → V`、次に `III → V`。各反復が短くなり、終端へ向かう速度が増す。

変奏が何種類あっても、各回で同時に音高・輪郭・リズム・開始位置を大きく変えると、同じモチーフとしてのつながりは薄くなる。反復から対比へ移る途中では、少しずつ保持要素を減らすことで、新しい素材が現れたときの距離感を調整できる。

### 提示・反復・展開・解消

短いフレーズが繰り返されると、聴き手は次も似た形が現れると予測する。そこで移高、終端変更、断片化などを続けると、認識できる共通性を保ったまま展開が進む。反復を止め、長音・休符・異なる輪郭・別の終端へ切り替えると、まとまりの終わりが聞こえる。音楽理論では、このように特徴的な要素を減らして終結へ向かう操作を**リクイデーション**と呼ぶことがある。[^3]

| 位置 | モチーフの状態                 | 旋律の動き                       |
| ---- | ------------------------------ | -------------------------------- |
| 提示 | 原型A                          | 音程とリズムの特徴を明確にする   |
| 反復 | AまたはA'                      | 同じ素材であることを定着させる   |
| 展開 | A''、短い断片、移高形          | 上昇、圧縮、転換などの運動を増す |
| 解消 | 長音、異なる終端、休符、新素材 | それまでの反復に区切りを付ける   |

たとえば4小節を `A | A' | A'' | 終端` とすると、最後の小節に至るまで同じモチーフの認識を保ちつつ、着地だけを変えられる。より大きな8小節では、前半の4小節全体を大きなAとして、後半で一部を再帰させることもできる。反復は**短い音群の中**にも**フレーズ同士の間**にも現れるため、単に同じ小節が何回あるか以上に多層的である。

モチーフの継承は音高を固定する必要がない。Aメロのリズムをサビの別の音域に移せば、旋律が変わっても曲全体に共通した運動を与えられる。反対に、サビのフックを先に提示し、Aメロでその断片だけを使うと、後で完成した形が現れたときに認識がまとまる。

### フレーズの境界と終端

フレーズは、一つの方向と区切りを持つ旋律単位である。区切りは、**休符・長音・音域・モチーフの完了・言葉・和声との関係**が合わさって成立する。旋律に休符がなくても、最後の音が長く持続して方向が切り替わればフレーズ境界を感じることがある。反対に短い休符が多数あっても、反復が継続するなら大きなフレーズは一続きに聞こえる。

フレーズ終端での旋律音は、コードが同じでも閉じ方を変える。

| 終端の形                      | 代表的な作用                                 |
| ----------------------------- | -------------------------------------------- |
| 主和音上の `I` を長く保持     | 中心への明確な帰着                           |
| 主和音上の `III` を保持       | 和音は安定し、旋律は柔らかく開いた余韻を残す |
| 主和音上の `V` を保持         | 完全5度の支えを残し、次の展開に接続しやすい  |
| `VII → I↑` を終端に配置       | 導音から主音への半音到達が目立つ             |
| `II` や `IV` を保持して区切る | 近接する解決先を想起させ、続きを要求する     |
| 次コードの構成音を先取りする  | フレーズ終端が次の和声を呼び込む             |

これらの傾向は主音と和声が明瞭な場合に分かりやすい。モード中心の反復や、終止感の薄いコードループでは、**前後の反復位置**や**休符の長さ**が終端の役割を強く担う。

### フレーズ間の関係と形式

短いアイデアをどう結び付けるかで、数小節の大きな構造が決まる。反復 `A–A` は定着、変奏反復 `A–A'` は一貫性と変化、対比 `A–B` は新しい輪郭やリズムを提示する。問いと応答は音高の上下ではなく、**前半が残した期待を後半がどう処理するか**で成立する。先行フレーズの終点を不安定な音にし、後続フレーズを長い安定音へ置く方法も、先行を高音で切って後続を低域から始める方法もある。

クラシック由来の二つの典型形式は、ポップスの数小節単位の旋律分析にも使える。[^4]

| 形式                       | 素材の配置                                 | 展開の特徴                                             |
| -------------------------- | ------------------------------------------ | ------------------------------------------------------ |
| **Sentence（センテンス）** | 基本アイデアA → Aの反復・変奏 → 継続・終結 | 後半で断片化、反復の短縮、リズム密度の増加を用いやすい |
| **Period（ピリオド）**     | 前件A＋終端 → 後件A'＋より明瞭な終端       | 両者が冒頭素材を共有し、終端の対比で完結感を作る       |

典型的なSentenceは、2小節のアイデアを2回提示したのち、後半を短い断片にして終結へ運ぶ8小節前後の構造。典型的なPeriodは、似た冒頭を持つ二つの4小節フレーズを対にし、後件が前件より明確に終わる構造である。実際の長さは自由に伸縮し、3小節＋5小節、4小節＋6小節などにもなる。

次のように同じ冒頭を使い分けられる。

```text
Sentence：A（提示）|A'（反復）|a（断片）・a'（断片）|終結
Period  ：A（提示）|開いた終端|A'（再提示）|閉じた終端
```

Sentenceは**素材が発展して終わる感覚**、Periodは**似た二つの発言が応答関係を持つ感覚**に特徴がある。現代ポップスのフレーズは、両者の要素を混ぜたり、途中で変則的な長さを挿入したりできる。

### フレーズの重なりと長さ

フレーズの長さが毎回同じだと、聴き手は境界を予測しやすい。その予測を利用して、次のフレーズを直前の小節後半から始める**重なり（エリジョン）**、反復を一回増やす**拡張**、同じ素材を一小節短く切り上げる**圧縮**が作れる。最後の音を次のフレーズの最初の音として兼用すれば、自然に進行がつながる。

`A（2小節）→ A'（2小節）→ B（4小節）` が基準なら、最後のBを6小節まで伸ばすと到達点が遅れ、終端の価値が増す。逆に `A（2小節）→ A'（1小節）→ B（1小節）` と詰めれば、モチーフの提示から解消までを短時間で進められる。変拍子や拍の細分化を使わなくても、フレーズの長さと始点の重なりだけで予想と異なる時間感覚を作れる。

### 頂点の配置

頂点は、最高音、最長音、最大跳躍、最も強いアクセント、密度の集中、和声的な摩擦、歌唱・演奏上の力点が重なった位置に形成される。最高音が短い装飾音なら頂点として目立たず、長い `VI` が歌詞の重要語や強いアクセントと重なる場合は、それより高い短音よりも強い到達として感じることがある。

局所的な頂点は数音、フレーズの頂点は数小節、セクションの頂点は十数小節、曲全体の頂点は複数セクションの相対関係で決まる。冒頭で最高音を提示して以降のフレーズを下げれば「最初に言い切る」形、最後の1フレーズだけ最高音を上げれば「遅れて到達する」形になる。どちらも曲全体の方向感を作る手法である。

| 頂点の作り方               | 対象となる変化                               |
| -------------------------- | -------------------------------------------- |
| 音域を引き上げる           | 反復するたびに最高音・平均音域を上げる       |
| 跳躍の先に長音を置く       | 大きな位置移動と持続を一点へ集中する         |
| 音数を減らして長音へ到達   | それまでの活動を停止し、到達音を独立させる   |
| 同音反復を加速してから跳躍 | 音高の静止と突然の遠隔移動を対比する         |
| コード外音を頂点で保持     | 安定した旋律より強い和声的な摩擦を中心に置く |
| 頂点の直前を休符にする     | 音を鳴らさない時間で次音への注意を集める     |

頂点の前後には音域・音価・輪郭の対比を置くと、大きなダイナミクスの増幅に頼らず旋律だけで勾配を作れる。

## 4. コードに対する旋律

### 旋律音の二つの役割

旋律音には、**調の中での位置**と**現在の和音に対する音程**が同時に存在する。前者は曲全体の中心との関係、後者はその瞬間の安定感・色彩・摩擦を決める。同じ `VI` が続いても、コードが `IVmaj7 → III7 → VIm7` と変われば、`IVmaj7` 上では3rd、`III7` 上では11th、`VIm7` 上では根音となる。旋律の音高を変えずに和声だけが動いても、メロディの聞こえ方が変わる。

旋律音の働きを左右する主な条件は、次のように整理できる。

| 条件             | 聞こえ方への影響                                   |
| ---------------- | -------------------------------------------------- |
| 和音に対する音程 | コードトーン、テンション、近接する衝突音などの違い |
| 拍位置           | 強い位置ではその音の性格が前景化しやすい           |
| 持続時間         | 短音は通過、長音は独立した響きとして認識されやすい |
| 直前の音         | 半音・全音の近接か、跳躍による到達か               |
| 直後の音         | 安定音へ解決するか、摩擦を維持するか               |
| コード切替の位置 | 同じ音がコードの切替前後で別の役割を持つ           |
| 音域と音量       | 高音域や強調された音は摩擦が目立ちやすい           |
| フレーズの位置   | 冒頭、最高点、終端では同じ音の重要度が変わる       |

### コードトーンとテンションの置き方

コードトーンは和音を明確に知覚させる基準となる。根音と5thは根幹を支え、3rdと7thは長短・ドミナントなどの性質を強く表す。9th、11th、13thは上声の色を増やし、同じ和音の持続中でも旋律に新しい方向を与える。テンションが和音の方向や声部の解決をどう変えるかは [chord-progressions.md](chord-progressions.md) で扱い、ここでは**旋律のどの位置でどの音を聞かせるか**に注目する。

| 旋律上の配置                                   | 効果                                           |
| ---------------------------------------------- | ---------------------------------------------- |
| 強拍のコードトーンを長く保持                   | 伴奏と一体化した到達、歌詞の強調               |
| 強拍のテンションを長く保持                     | 響きの色彩そのものを主旋律の特徴にする         |
| 弱拍の非和声音からコードトーンへ移動           | 動きを保ちながら到達音を明瞭にする             |
| コードトーンを先に置き、その後テンションへ移る | 安定から色彩へ広がる線を作る                   |
| テンションを先に置き、コードトーンへ移る       | 解決に向かう動機を形成する                     |
| テンションのままフレーズを閉じる               | 着地しきらない余韻や次のフレーズへの接続を作る |

たとえば `Imaj7` 上で `III → II → I` と動けば、3rdから9thを経由して根音へ降りる。`IVmaj7` 上で `VI → V → III` と動けば、3rdから9th、maj7thへ進み、最後を根音以外に置いたまま透明な色を残す。音列の「解決」には調の中心へ戻る解決と、特定の和音の構成音へ収まる解決があり、二つが一致する場合もずれる場合もある。

### 12音の旋律上の使い分け

主音 `I` を根音とする**メジャー和音の上**で、オクターブ内の12音をどう聞かせられるかを一覧にする。表の旋律音はすべて調の主音基準のローマ数字。別の根音を持つコードでは、それぞれのコード根音からの音程に読み替える。

| 旋律音 | `I` 和音上での関係 | 主な使い方                                                |
| ------ | ------------------ | --------------------------------------------------------- |
| `I`    | Root               | 確定した帰着、中心への回帰                                |
| `♭II`  | ♭9th               | 根音と半音で擦れ、`I` への上方からの接近に使える          |
| `II`   | 9th                | 根音から一段離れた開放感。長音でも通過音でも使いやすい    |
| `♭III` | ♭3rd相当、#9th相当 | Major 3rdとの併存がブルース的な緊張を作る                 |
| `III`  | 3rd                | 長三和音の品質を直接示す                                  |
| `IV`   | 11th               | `III` と半音関係。`IV → III` の掛留・装飾、独立した保留音 |
| `#IV`  | #11th              | `V` への半音接近、リディアン的な明るい浮遊感              |
| `V`    | 5th                | 和音の安定、跳躍の到達先                                  |
| `♭VI`  | ♭13th              | `V` との半音関係、マイナーからの色の借用                  |
| `VI`   | 13th               | 柔らかく広い響き。`V` への下降にも使える                  |
| `♭VII` | ♭7th               | ドミナント／ブルース／ミクソリディアン的な色              |
| `VII`  | maj7th             | 主音の半音下。主和音上で保持すると繊細な緊張を作る        |

この一覧の役割は「すべての音をいつでも重ねる」ことではなく、**その音がどう進入し、どこへ向かうか**を見つけることである。たとえば `♭II → I`、`IV → III`、`#IV → V`、`♭VI → V`、`VII → I↑` は、いずれも半音の行き先を持つ。これらを短く通過させれば接近音となり、長く保持すればコードの色や摩擦そのものを主旋律に取り込める。

特に `♭III` は、長三和音の3rdである `III` と関係を持たせることで効果が変わる。`♭III → III` と半音で上げればブルースや歌唱上のしゃくりに近い色になり、`III → ♭III` と下げれば明暗の切替を前景化できる。実際の歌唱では二つの高さを明確に分離するほか、その間の音高を滑らかに使う表現も成立する。

### 代表的なコード上での旋律候補

**そのコードが鳴っているときに旋律や上声が占められる位置**の一覧。ディグリーは主音基準で表す。コードトーン以外の音は、主要なテンションまたは特徴的な接近音を挙げる。

| 背後の和音             | コードトーンに当たる旋律音 | 特に特徴的な色・動き                                                                                                                         |
| ---------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `I` / `IV`             | `I III V` / `IV VI I`      | 9th・6thを足すと三和音の明瞭さを保ったまま開いた響きになる。7thまで含めるかで持続的な緊張の有無が変わる                                      |
| `Imaj7`                | `I III V VII`              | `II`=9th、`#IV`=#11th（リディアン的）、`VI`=13th。`IV`=11thは3rdと半音で擦れ、`IV → III` で解決する                                          |
| `Im7`                  | `I ♭III V ♭VII`            | `II`=9th、`IV`=11th、`VI`=13th（ドリアン系）、`♭VI`=♭13th（自然短音階系）                                                                    |
| `IIm7`                 | `II IV VI I`               | `III`=9th、`V`=11th、`VII`=13th（ドリアン的な明るさ）。11thを含めると `V7` への前置が豊かになる                                              |
| `IIIm7`                | `III V VII II`             | `VI`=11th。9thに当たる `IV` はキー内では♭9thとなり、強く擦れる                                                                               |
| `IVmaj7`               | `IV VI I III`              | `V`=9th、`VII`=#11th（キー内の音だけで得られる透明感）、`II`=13th。`III` を保持するとmaj7thが前景化                                          |
| `IVm`                  | `IV ♭VI I`                 | `V`=9th、`II`=13th。`♭VI` は前後の `VI` と半音接続しやすい                                                                                   |
| `V7`                   | `V VII II IV`              | `VI`=9th、`♭VI`=♭9th、`♭VII`=#9th、`♭II`=#11th、`III`=13th、`♭III`=♭13th。到達先が長調なら9th・13th、短調なら♭9th・♭13thが方向をそろえやすい |
| `V7sus4`               | `V I II IV`                | `VI`=9th、`III`=13th。3rdを含まない浮遊感とドミナントの7thが両立する。`I → VII` で `V7` へ解決できる                                         |
| `VIm7`                 | `VI I III V`               | `VII`=9th、`II`=11th、`#IV`=13th（ドリアン系）、`IV`=♭13th（自然短音階系。5thと半音で擦れる）                                                |
| `III7`                 | `III #V VII II`            | `IV`=♭9th、`V`=#9th、`I`=♭13th。`#V → VI` が典型的な到達                                                                                     |
| `IIm7♭5` （`Im` 中心） | `II IV ♭VI I`              | `♭III`=♭9th（自然短音階）、`III`=9th、`V`=11th。`I → VII` や `♭VI → V` の半音移動が後続の `V7` へつながる                                    |

この表は使用可能音の絶対的な一覧ではなく、その調とコードの組合せから生まれる典型的な候補である。いわゆる「アヴォイド」は衝突が起こる理由を説明する語であり、禁止音の一覧ではない。擦れる音も、通過音にする、3rdと離した音域に置く、長く保持して摩擦そのものを聴かせる、といった扱いで表情になる。

ひとつのフレーズがコードをまたぐときは、表の各列に旋律を閉じ込めるよりも、**前後の二つのコードで同じ音が持つ意味の差**を見る（[コードチェンジをまたぐ線](#コードチェンジをまたぐ線)）。[^5]

### 非和声音の種類と聞こえ方

旋律のほぼすべての音をコードトーンとして捉えると、線の動きが失われやすい。コード外の音も、進入と離脱の関係によって明確な役割を持つ。名称より**直前と直後の音の位置**が実際の設計に役立つ。

| 種類                 | 動きの構造                                     | 原型となる旋律例                             |
| -------------------- | ---------------------------------------------- | -------------------------------------------- |
| 経過音               | 目標音の間を順次で通る                         | `III → IV → V`（`I` 上で `IV` が途中の11th） |
| 刺繍音               | ある音の隣へ出て戻る                           | `III → IV → III`                             |
| 掛留                 | 前の和音の音を次の和音へ持ち越し、後から解決   | `V7 → I` で `IV ─ IV → III`                  |
| 遅延                 | 和音の変化後、期待される解決音へ少し遅れて到達 | `III7 → VIm` で `#V ─ #V → VI`               |
| 先取音               | 次のコードの音を和音変更より先に鳴らす         | `I → IV` の直前に `VI` を置き、`IV` 上で保持 |
| アポジャトゥーラ     | 強い位置の摩擦音から安定音へ近接移動           | `Imaj7` 上で強拍の `IV → III`                |
| 逸音                 | 和声音から順次で離れ、跳躍して別の和声音へ     | `I` 上で `III → IV → I`                      |
| クロマティック経過音 | 半音を挿入して目標音へ向かう                   | `III → IV → #IV → V`                         |
| エンクロージャー     | 目標音を上下から挟み込んで到達                 | `♭VI → #IV → V`                              |

掛留と先取音は、コードの変更時刻に対して旋律がどちら側へずれるかによって区別できる。掛留では**旋律が和声より遅れ**、先取音では**旋律が和声より先に到着**する。両方ともコードの境界を跨ぐため、メロディに独立した時間の流れが生まれる。

コード外音は拍の位置と長さによって性格が変わる。`Imaj7` 上で短く通過する `IV` は動きの一部だが、サビの重要語で長く歌う `IV` は11thの擦れが中心的な響きとなる。**コードトーンへの解決**と**色彩音としての保持**は、同じ一音の異なる活用形である。

### クロマティックな線とブルーノート

半音階的な音は、局所的な目的音へ向かう接近と、フレーズ全体の音高語彙の変化という二つの使い方がある。`#IV → V` は半音下からの接近、`♭VI → V` は半音上からの接近であり、どちらも `V` へ到達する。ただし前者は主音基準でリディアン的な色に、後者は短6度を含むマイナー的な色につながる。

**クロマティック・アプローチ**では目的音が比較的明瞭で、短い半音を前置する。**エンクロージャー**では目的音の上下から回り込む。**サイドスリップ**では、モチーフ全体を一時的に半音など移してから戻す。個々のコードとの適合性よりモチーフの形が前へ出るため、元の位置に帰ったときの差が大きく感じられる。

ブルース由来の旋律では、`♭III`、`#IV/♭V`、`♭VII` が、Major/Minorの両方に跨る独特の音高語彙となる。`I` を中心とするメジャーコード上で `♭III → III` と進む形、`IV → #IV → V` の経過、`♭VII → V` の跳躍などが代表的である。固定された鍵盤の音列としてだけでなく、微妙なピッチの揺れ、しゃくり、滑音との組み合わせで意味が強まる。

### コードチェンジをまたぐ線

同じ和音列に対して、旋律の処理で到達先を変えられる。以下はすべて、メロディの音高が**主音基準のローマ数字**で書かれた例である。

**セカンダリードミナントの導音を歌う。**

```text
コード：| IVmaj7 | III7 | VIm7 |
旋律：     VI         #V       VI
```

`IVmaj7` の3rdから `III7` の3rdへ半音下降し、`VIm7` の根音へ半音上行する。`VI → #V → VI` という三音だけで、和音が作る局所的な緊張と解決を旋律にも反映できる。旋律が重要な役割を担う場合、伴奏が複雑なテンションを重ねなくてもこの接続は伝わる。

**借用和音の変化音を歌う。**

```text
コード：| I | IV | IVm | I |
旋律：     V    VI     ♭VI    V
```

`IV` から `IVm` に変わるとき、旋律の `VI` を `♭VI` に半音下げる。伴奏の3rdの変化と歌の音高変化が一致するため、借用和音の色を旋律の表情として直接聞かせられる。反対に旋律を `I` に固定すれば、上声ではなく伴奏の内声変化が中心になる。

**コードが変わっても一音を保持する。**

```text
コード：| Imaj7 | IVmaj7 |
旋律：     VII ───── VII ───
```

`VII` は最初のコードではmaj7th、次のコードでは#11th。コードチェンジの瞬間に旋律の役割が変わるが、耳には一続きの音として保持される。とくにテンションを長く聞かせたい場合に有効で、コードの色彩を切れ目なくつなげられる。

**コード境界の手前から次の音へ入る。**

```text
コード：| I             | IV       |
旋律：     III → V → VI ───── VI → V
```

`VI` は `I` 上では13th、`IV` 上では3rd。先に歌が `VI` に着き、コードが後から安定した響きへ追いつく。逆に `IV` へ変わった後もしばらく `III` を保持すれば、maj7thとして色彩を残し、コード境界に別の緊張を与えられる。

**旋律とコードの周期をずらす。**

4小節のコードループに3小節のモチーフ反復を重ねると、同じ旋律音が毎周異なる和音の上に現れる。フレーズ周期とコード周期が再び一致するのは12小節後である。モチーフを変えずに旋律音と和声の対応関係を変えることができ、ループ自体が長期的な変奏の場になる。

### 旋律が先か、コードが先か

先に旋律がある場合は、**長音・繰り返す音・最高音・各フレーズの終端**を固定し、そこで聞かせたいコードとの音程から伴奏を考える。短い経過音は和声の選択自由度を大きく残すため、最初から一音ずつコードを割り当てるより、重要音の縦関係を明確にする方法が使いやすい。

先にコードがある場合は、各コードの根音を順にたどるより、**コード間で共有できる旋律音**や、隣接コードの3rd・7thの半音関係から線を作る方法がある。少数の音を選ぶだけでも進行は聞こえ、装飾を加えれば同じ骨格のまま活動量を変えられる。

旋律とコードが噛み合わない場合も、旋律を変更する、コードを変更する、コードの切替位置を動かす、テンションとして聞かせる、伴奏の上声を別の位置にする、という複数の設計経路がある。どちらを先に作ったかによって修正対象の優先度が変わるだけで、選択肢は共通している。

## 5. 現代J-POPの旋律設計

日本のポップスでは、短いフックを記憶させる手法と、言葉・音域・和声を複雑に動かす手法が共存している。曲が複雑に聞こえても、**何を反復し、何を一回だけ変えるか**を分けて捉えると、旋律に使われている仕組みが見える。以下では、実際の日本の楽曲で観察される代表的な設計を、作曲に応用できる観点から整理する。

### モチーフの反復と変形

**RADWIMPS『おしゃかしゃま』**のサビには、短い言葉のまとまりを反復し、一部の終端だけを変えてから別の結びへ進む構造がある。同じモチーフが何度も聞こえるため、各回の変化量が小さくても旋律全体の統一感が高い。反復する単位をさらに上位のまとまりとして再度反復する、**小さな反復と大きな反復の入れ子**として捉えられる。[^6]

**井上あずみ『君をのせて』**では、近い輪郭を持つモチーフを音高を変えながら繰り返し、途中で原型の高さへ戻す展開が際立つ。単なるコピーより「同じ身振りのまま景色が変わる」感覚が生まれ、終端の違いがフレーズの句読点になる。[^7]

この二つに共通するのは、**モチーフの認識可能性を残した変形**である。前者では反復の定着が強く、後者では輪郭の継承と移高による運動が前に出る。フックを短い素材から構成する際、メロディの情報量を増やす方法は新しい音列を次々追加することだけではない。元の素材が変わる距離と、その反復を止める位置の方が、全体の展開を大きく左右する。

### 跳躍と順次進行の対比

**Ado『うっせぇわ』**のサビは、冒頭の大きなオクターブ跳躍と、後半で目立つ順次進行の対比が特徴的である。広い音程を連続させる部分では音域の切替自体がフックになり、後半で音程差を小さくすることで、同じセクションの中に明確な形の違いが生まれる。[^8]

跳躍は大きいほど印象が強いが、曲中のすべての小節を大跳躍で満たす必要はない。**大きな間隔を使う区間と、小さな間隔で線を回収する区間**の対比によって、最初の跳躍がより強い特徴として残る。高音そのものの使用頻度が少なくても、到達の仕方を統一することでサビの記憶点になる。

| 旋律の設計                      | 聞こえ方                                 |
| ------------------------------- | ---------------------------------------- |
| 同音反復 → 大跳躍 → 順次下降    | 静止から急激に開き、線を回収する         |
| 上行順次 → 高音長音 → 下行跳躍  | 高まりを一度保持し、瞬間的に解放する     |
| 大跳躍の反復 → 狭い音域への転換 | 跳躍をフックにし、後半の語り口と対比する |
| 狭い音域の反復 → 終端だけ高音へ | 素材の定着後、一音の変化に注意を集める   |

### 限られた音高語彙と特徴音

**yama『春を告げる』**の旋律は、四七抜き（`I・II・III・V・VI`）を基礎にした音の使い方が目立つ。全音中心の開いた輪郭を保ちながら、反復する高音や終端の配置でフレーズに変化を付ける。[^9]

**YOASOBI『アイドル』**については、四七抜き・四抜きのような限られた音高語彙との関係で、`IV` に当たる音をサビの特徴的な高音に集中させる分析がある。ここでの `IV` は分析対象区間の主音を基準とする。主として使う五音に対し、半音関係を生む `IV` を目立つ場所へ置くことで、その音の出現自体が構造上の出来事になる。[^10]

この手法は、**音階の名前より「普段使わない音をいつ解禁するか」**という設計で理解できる。`I・II・III・V・VI` を反復し、最後の高音に `IV` を加える方法なら、音符の数を増やさず半音関係を導入できる。逆に最初から `IV` を頻繁に含めたメロディを作り、サビで `IV` を一時的に省けば、狭まった語彙そのものが対比になる。

### 言葉の密度とメロディの情報量

現代の歌ものでは、**言葉が速く変わる区間と音高が大きく動く区間を分ける**設計により、語りと歌唱の違いを鮮明にできる。短音を詰め込んだ区間でも、同じ高さの反復や狭い音域を基礎にすれば、音高情報の増加を抑えたまま言葉を多く載せられる。旋律が高音長音へ移った瞬間には、言葉の密度が下がり、音そのものが前景化する。

一方、短音の中で音高を頻繁に跳ばすと、言葉とピッチの両方が激しく変化し、緊迫や落ち着きのなさを表現できる。リズム的なフロウを主体とする区間と、明確な歌唱音程を主体とする区間を連続させる方法もある。ラップと歌唱の境界は、音高が固定されているかどうかより、**音高の輪郭をどの程度明確に聴かせるか**によって連続的に変化する。[^11]

同じ歌詞の長さでも、音符を短く刻む、ひとつの母音を複数音高へ伸ばす、一つの音高に多くのモーラを載せる、促音の間を短く切る、という配置で印象が変わる。日本語では特に、詞のモーラ数と旋律音数を一対一に合わせる場合と、特殊モーラを前後とまとめる場合の違いが、発音や聞こえ方に影響する。[^1]

### セクション間の旋律的な対比

Aメロ・Bメロ・サビという呼び方は形式上の位置を示すもので、旋律が担う役割は音域、密度、モチーフの扱いによって変えられる。同じコード進行のまま、旋律の特徴だけでセクションを分けることもできる。

| 旋律の特徴                             | 区間を区別する効果                     |
| -------------------------------------- | -------------------------------------- |
| 同音反復、狭い音域、細かな言葉         | 語り・説明・緊張の持続を前面に出す     |
| 連続上行、短い断片の反復、終端の未解決 | 次の区間へ向かう蓄積を作る             |
| 短いフックの明瞭な反復、長音の到達     | セクションの同一性と記憶点を明確にする |
| モチーフの再帰、音域の切替、長い休止   | 以前の素材を新しい意味で提示する       |

サビの旋律を必ず最高音にする必要はない。最高音をBメロに置いて期待を高め、サビは中音域の反復フックで固定する形も成立する。反対にサビ冒頭で最高音を使い、後半は下降する形なら、サビの始点に焦点がある。**音域・リズム密度・モチーフの反復回数・終端の長さ**のうちどこに差を付けるかで、各区間の役割を作り分けられる。

## 6. 作曲への応用と参照表

### 旋律の作り始め方

旋律の出発点には、音高、リズム、言葉、コード、音域のいずれも選べる。どこから作り始めても、完成時にはモチーフ・フレーズ・コードとの関係が一つの線として結び付く。各出発点で最初に確定しやすい情報が異なる。

| 出発点         | 初期に決める情報                                     | その後に組み合わさる情報                 |
| -------------- | ---------------------------------------------------- | ---------------------------------------- |
| 音高先行       | 数音の輪郭、目標音、最高音                           | 音価、休符、和声に対する位置             |
| リズム先行     | 同音反復・アクセント・言葉の長短                     | 目立つ音での跳躍、終端の音高             |
| モチーフ先行   | 短い素材の特徴と反復方法                             | 変奏、フレーズ構成、頂点                 |
| コード先行     | 各コード上の重要音、共通音                           | それらをつなぐ経過音、歌い出し位置       |
| 歌詞先行       | 語の境界、意味の強調、モーラ数                       | 長音と短音、音域、拍位置                 |
| 音域先行       | 中心域、最高音と最低音、音域移動                     | 輪郭、フレーズ終端、発声・演奏の連続時間 |
| 奏法・音色先行 | 楽器で自然に出る音形（開放弦、ベンド、分散和音など） | 和声に対する位置、反復と変奏             |

**短い素材を曲全体へ発展させる経路**は、モチーフの核を固定し、A・A'・Bなどの関係を作り、各フレーズに異なる終端を与え、セクション単位で音域や密度を変える、という順序で整理できる。先にサビのフックがある場合は、そこからモチーフの一部を抜き出してAメロへ使い、後で完成形を提示する逆向きの構成も可能である。

**複雑なコード上で旋律を作る経路**は、各コードの特徴音を順番に歌わせる方法と、少数の旋律音を複数コードで保持する方法に分かれる。前者は和声の変化を歌でも明示し、後者は旋律の一貫性の中で和声の色を変える。両者を交互に使うと、進行を追う区間と、和声に対して独立した区間を作れる。

### 変えたい印象から参照する

| 目的・聞こえ方             | 旋律側の変更点                               | 変わる仕組み                       |
| -------------------------- | -------------------------------------------- | ---------------------------------- |
| 短い旋律を印象付ける       | リズムまたは跳躍の特徴を残して反復           | 認識できる共通性が増える           |
| 反復に展開を持たせる       | 音域を変え、終端だけ別音にする               | 既知の素材の中に差が生まれる       |
| フレーズを長く聞かせる     | 終端前の断片を反復し、到達を遅らせる         | 予期した句読点が後方へ動く         |
| フレーズを短く切る         | 断片化し、長音や休符へ早く移る               | まとまりの完了が前倒しになる       |
| 高揚する                   | 平均音域を上げる、上行跳躍を集中させる       | 到達音が前景化する                 |
| 余韻を残す                 | 根音以外の長音、長い休符、弱い終端           | 和声上の色を残したまま区切る       |
| 切迫する                   | 反復を詰める、短音を増やす、半音接近を使う   | 予測と解決の間隔が短くなる         |
| 滑らかに歌う               | 隣接する音を多く使う、長音を挟む             | 方向の連続性が高まる               |
| 角張ったフックにする       | 大跳躍と同音反復を組み合わせる               | 輪郭の切替が強い記憶点になる       |
| 和声の色を前面に出す       | コード上の9th、maj7th、#11thなどを長音にする | 旋律がテンションを担う             |
| 借用和音を歌でも際立たせる | 変化する3rdなどをメロディで半音移動させる    | 伴奏と旋律が同じ変化を共有する     |
| コードと独立した旋律にする | 共通音を保持、フレーズ周期をずらす           | 同一音の和声的な意味が変化する     |
| 日本語の語りを前面に出す   | 狭い音域・同音反復と、重要語の跳躍を対比     | 言葉と音高の情報量を配分する       |
| サビの焦点を明確にする     | モチーフを反復し、頂点や終端を一箇所に集める | 局所的な強調が大きな構造につながる |

### 旋律の分析と診断

旋律を聴いて「平坦」「まとまりが弱い」「歌いづらい」と感じるときは、その印象を**どの音高が、どの長さで、どの位置に現れ、何が繰り返されるのか**という具体的な現象へ置き換えられる。既存曲を分析するときも同じ観点で分解すると構造が見えやすい。

| 聞こえる現象                       | 確認する情報                                   | 変化が生まれる部分         |
| ---------------------------------- | ---------------------------------------------- | -------------------------- |
| どこも同じ高さに聞こえる           | テッシトゥーラ、各フレーズの最高音             | 区間ごとの音域・頂点       |
| 旋律の形が記憶に残りにくい         | 反復する音程・リズム・輪郭の核                 | モチーフの同一性           |
| 反復が続きすぎて聞こえる           | 終端変更の頻度、解消位置、フレーズ長           | 反復から完了への移行       |
| 音が絶えず動いて聞こえる           | 同音・長音・休符の位置                         | 音高情報が止まる時間       |
| 一つ一つの音が無関係に聞こえる     | 順次と跳躍、目標音、輪郭の方向                 | 連続した線としての結び付き |
| 高音に到達しても盛り上がらない     | 直前の音域、長さ、発声、休符                   | 頂点の前後の対比           |
| 歌詞が詰まって聞き取りにくい       | モーラ数、同音反復、子音、語の境界             | 発音のまとまりと音高の配分 |
| 重要な歌詞が埋もれる               | 重要語の音価、音域、開始位置                   | 言葉とメロディの焦点       |
| 和声が変わっても旋律の印象が同じ   | 長音とコードの関係、テンションの役割           | 旋律音の縦の意味           |
| 非和声音が偶発的に聞こえる         | 進入・離脱、拍位置、保持時間                   | 摩擦の方向と解決の位置     |
| メロディがコードをなぞるだけになる | コード間の共通音と掛留、旋律の独立周期         | 和声をまたぐ線の持続       |
| 区間ごとの差が小さい               | モチーフ、音域、密度、終端音                   | セクション同士の対比       |
| 音高語彙が単調、または散漫         | 使うディグリー、限られた音集合からの逸脱の位置 | 特徴音の出現のさせ方       |

複雑さそのものは独立した評価軸ではない。音符数が少なくても、反復の位置、半音移動の意味、フレーズの終端が明瞭なら旋律は多くの情報を持つ。反対に多くの音と跳躍を含んでいても、何が繰り返され、どこへ向かうかが捉えにくければ、その複雑さは単なる活動量として聞こえることがある。
