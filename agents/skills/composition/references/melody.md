# メロディ

主役としての旋律を扱う。旋律は単音の列ではなく、時間方向に形を持つ音楽的な線であり、音高・リズム・輪郭・空白・モチーフ・フレーズの要素からなる。前半で旋律そのものの設計、中盤でモチーフとフレーズの構造、後半でコードに対する旋律の響きを扱い、最後に旋律の判断と診断をまとめる。

## 1. 旋律の構成要素

### 音域とテッシトゥーラ

音域は最低音から最高音までの幅、テッシトゥーラは多くの時間を過ごす中心音域である。同じ最高音を持つメロディでも、低域から一度だけ高音へ到達する形と、高域に長く滞在する形では緊張感と歌唱負荷が大きく変わる。フレーズ・セクション・曲全体で音域の役割を分けると、最高音や最低音に意味を持たせられる。

### 音の動き

| 動き       | 効果                                           |
| ---------- | ---------------------------------------------- |
| 同音反復   | リズム、アクセント、想定される言葉を前面に出す |
| 順次進行   | 滑らかな方向感を作る                           |
| 小さな跳躍 | 輪郭に特徴を加える                             |
| 大きな跳躍 | 強いアクセント、頂点、意外性を作る             |

跳躍の後に反対方向へ順次で戻すのが、線をまとめる基本の形。跳躍の連続は角張った輪郭と強い推進を作るため、曲調に応じて使い分ける。

### 輪郭

輪郭はフレーズ全体の上昇・下降の形で、上昇・下降・山型・谷型・波型・水平に分類できる。ただし分類名よりも次の3点が重要である。

1. どこへ向かっているか
2. どこで方向が変わるか
3. 頂点はどこか

フレーズ1つの中の輪郭と、複数フレーズを通した大きな輪郭は分けて見る。

## 2. リズムと空白

メロディの性格は、音高と同じ程度にリズムの配置から生まれる。

### 音価

長音は到達点や余韻を作り、短音の連続は活動量と推進を作る。長音と短音を対比させると、同じ音高素材からも明確な形が生まれる。

### アタック位置

フレーズやモチーフの開始位置は、拍頭、弱拍、裏拍、前小節からの食い込み、小節頭後の遅い入りに分けられる。開始位置を変えると同じ音列でもリズムの重心が変わるため、フレーズごとに揃える方法と、意図的にずらす方法を使い分ける。

### シンコペーション

弱い位置から始まった音を強い位置まで保持する動きや、期待される強拍を避ける配置は、前進感と浮遊感を作る。

### 休符

**休符は一種の音符である**。

| 役割     | 内容                             |
| -------- | -------------------------------- |
| 分節     | フレーズやモチーフの境界を示す   |
| 強調     | 次の音や前の到達音を目立たせる   |
| 呼吸     | 歌唱や管楽器の演奏可能性を支える |
| 対話     | 他パートへ空間を渡す             |
| 密度調整 | セクション内の活動量を変える     |

長音も、新しい音高情報を止める時間として空白に近い働きを持つ。休符のない平易なメロディになりがちなので、休符の設計が旋律の生命線になる。

### 呼吸

歌唱を想定した旋律では、連続発声時間、テンポ、音域、音価、句切れ、子音と母音の密度から呼吸位置を設計に組み込む。自然な休符、長音後の間、語句の切れ目が主な候補になる。長い一息のフレーズも表現手段として、意図を持って配置する。

## 3. モチーフ

モチーフは、反復や変形の中でも識別できる短い素材である。音名の固定列としてではなく、リズム、音程関係、輪郭、アクセント、反復音、特徴的な跳躍、終端、フレーズ内の位置の組み合わせで捉える。

### 変形

モチーフ展開では「何を保持し、何を変えるか」を明確にする。

| 保持するもの | 変えるもの | 効果                         |
| ------------ | ---------- | ---------------------------- |
| リズム       | 音高       | ジェスチャーを保った移高     |
| 輪郭         | 音程幅     | 同じ形の拡大・縮小           |
| 音高素材     | リズム     | 同じ音群へ別の勢いを与える   |
| 冒頭         | 終端       | 認識を保ちながら方向を変える |
| 一部分       | 残りを省略 | 断片化                       |
| モデル       | 開始音     | シークエンス                 |

代表的な操作は、反復、移高、反転、音程拡大・縮小、リズム拡大・縮小、拍位置の移動、装飾、断片化、延長、終端変更、逆行。

## 4. フレーズ

フレーズは、複数の音やモチーフがまとまり、ひとつの方向と区切りを持った単位である。

### 境界

境界は休符だけでは決まらず、複数の要素が重なるほど明確になる。

| 要素     | 境界の作り方               |
| -------- | -------------------------- |
| リズム   | 休符、長音、活動量の低下   |
| 音高     | 到達音、最高音、最低音     |
| モチーフ | パターンの完了             |
| 和声     | 到達感の強いコードや旋律音 |
| 歌詞     | 文節、語句、意味の区切り   |
| アレンジ | フィル、伴奏変化、掛け合い |

### フレーズ同士の関係

反復は素材を定着させ、変奏反復は同一性と変化を両立させ、対比は新しい輪郭・音域・密度・開始位置によって対局を作る。

| 形        | 内容                                           |
| --------- | ---------------------------------------------- |
| `A A`     | 同じフレーズを反復                             |
| `A A'`    | 冒頭やモチーフを共有し、終端などを変化         |
| `A B`     | 新しい素材で対比                               |
| 問い→応答 | 前半を開いた状態にし、後半をより強い到達へ導く |

### SentenceとPeriod

Sentenceは基本アイデアの提示と反復から始まり、後半で断片化・加速・到達へ進む構造。Periodは前件と後件を対にし、後件をより強い到達へ置く構造。どちらもフレーズ構造を観察・設計するための代表型として使う。

## 5. 頂点

頂点は複数のパラメータから形成される。最高音、最長音、最大跳躍、最も強い拍、最大のリズム密度、最も強い和声的摩擦、最大音量、最も厚いテクスチャ。重なる要素が多いほど頂点は強くなり、フレーズ・セクション・曲全体で頂点の強さを段階化すると、時間軸に勾配ができる。

## 6. コードに対する旋律

ここからは、鳴っているコードに対して旋律音が作る響きと動きを扱う。コードトーンは安定の基準になり、テンション、クロマティックな音、モード由来の音、ブルーノート、先取音、掛留などが旋律に色彩と方向を与える。

### 旋律音の評価軸

旋律音の印象は、音名単体ではなく次の条件から決まる。

| 軸             | 内容                                                  |
| -------------- | ----------------------------------------------------- |
| コードとの音程 | Root、3rd、5th、7th、9th、11th、13th、altered tension |
| 拍位置         | 強拍、弱拍、裏拍                                      |
| 持続時間       | 短い装飾音、長い保持音                                |
| 進入           | 順次、跳躍、半音アプローチ                            |
| 離脱           | 解決、保持、別のテンションへの移動                    |
| 次コード       | 次の和声でコードトーンやテンションへ意味が変わる      |
| フレーズ位置   | 開始、途中、頂点、終端                                |
| 音域           | 低音域と高音域で摩擦の感じ方が変わる                  |

ダイアトニックへの所属は、これらの中の一つの情報にすぎない。

### ルートに対する12音の語彙

コードルートを`1`として、12音すべてを旋律候補として捉える。

| 相対音程   | 読み方                       | 性格                           |
| ---------- | ---------------------------- | ------------------------------ |
| `1`        | Root                         | 強い中心感                     |
| `♭2 / ♭9`  | altered tension / approach   | 強い半音摩擦                   |
| `2 / 9`    | 9th                          | 開放感、順次接続               |
| `♯2 / ♯9`  | altered tension / blue color | major 3rdとの摩擦              |
| `3`        | 3rd                          | コード品質を明確にする         |
| `4 / 11`   | 11th                         | 3rdとの関係で性格が変わる      |
| `♯4 / ♯11` | #11                          | 浮遊感、Lydian系の色           |
| `5`        | 5th                          | 安定、比較的中立               |
| `♭6 / ♭13` | b13                          | 暗い色、5thへの半音接続        |
| `6 / 13`   | 13th                         | 柔らかい拡張感                 |
| `♭7`       | b7                           | dominant / minor / blues系の色 |
| `7`        | maj7                         | rootとの半音関係、強い色彩     |

この表は響きの出発点であり、実際の印象はコード品質、ボイシング、前後の旋律、音域によって変わる。

### 安定・色彩・摩擦

旋律音とコードの関係は連続的に捉える。

```text
安定 ─────────────── 色彩 ─────────────── 摩擦
コードトーン        テンション        半音衝突・異なる音高語彙
```

摩擦量は拍位置、長さ、音域、音量、前後の解決によって調整する。弱拍の短い`♭9`と、強拍で長く保持する`♭9`は同じ音程関係でも、前者はアプローチ、後者は響きの中心色として機能する。

### コード品質と基準音

- **Major / Maj7**: 基準は`1 3 5`（Maj7では`7`も構成音）。`9`、`13`、`#11`、`maj7`が拡張色として使いやすい。`11`は3rdと半音関係を作り、`♭3`はmajor 3rdとの衝突になるが、これらの摩擦は短い装飾、長い保持、ブルース的な語彙といった文脈で活用できる
- **Minor / Min7**: 基準は`1 ♭3 5`（Min7では`♭7`も構成音）。`9`と`11`は自然に拡張でき、`6 / 13`、`7`、`♭9`はDorian、harmonic minor、melodic minor、クロマティックな接続を通して別の色を作る
- **Dominant 7**: 基準は`1 3 5 ♭7`。テンションは`9 ♭9 ♯9 11/sus4 ♯11 13 ♭13`と幅が広い。解決先との声部進行が重要で、代表的な半音解決は`♭9 → root`、`♯11 → 5th`、`♭13 → 5th`。保持や次コードへの持ち越しも選択肢になる

### 非和声音と装飾

| 種類                         | 内容                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 経過音                       | 二つの目標音の間を順次でつなぐ（`目標音 → 経過音 → 目標音`）                                                   |
| 刺繍音                       | 一つの目標音から隣接音へ動き、元へ戻る                                                                         |
| 掛留・遅延                   | 前のコードの音を次のコード上でも保持し、コード変化後に解決する。チェンジの瞬間に摩擦が生まれ、解決が強調される |
| 先取音                       | 次のコードの音をコードチェンジ前に鳴らす。旋律が和声を先導する感覚を作る                                       |
| アポジャトゥーラ             | 強い位置へ摩擦音を置き、安定音へ移る。摩擦自体が表情になる                                                     |
| Escape / incomplete neighbor | 順次と跳躍を非対称に組み合わせ、経過音や刺繍音より鋭い線を作る                                                 |

### クロマティックな旋律

- **半音アプローチ**: 目標音へ半音上または下から接近する（`C# → D`、`E♭ → D`）。目標音がコードトーンや重要なテンションなら強い方向性が生まれる
- **エンクロージャー**: 目標音を複数の外側の音で囲み、最後に収束させる（`E♭ → C# → D`）。上下の順番や距離を変えることで多様なアプローチになる
- **クロマティック経過**: ダイアトニックな二音間を半音で埋める（`C → C# → D`）
- **長く保持するコード外音**: コード外音を長音として前面に出すと、装飾から色彩へ役割が移る。次コードの先取り、モード由来の音、ペダル的な旋律音、強いテンションとして扱える

### ダイアトニック外の音高語彙

- **モード混交**: 現在の中心を維持しながら平行する別モードの音を取り込む。C majorなら`E♭ = ♭3`、`A♭ = ♭6`、`B♭ = ♭7`、`F# = #4`。単発の色としても、フレーズ全体の語彙としても使える
- **ブルース**: Major harmony上でも`♭3`、`♭5`、`♭7`が旋律の中心色として機能する。C major chord上のE♭とE naturalの関係は、major/minorの境界を揺らす代表的な摩擦。実演では固定音程より細かなピッチの揺れも重要
- **Pentatonic / Blues語彙の重ね合わせ**: 伴奏コードが変化する中で一定のpentatonicやblues語彙を旋律側で保持すると、旋律の一貫性とコードごとに変わる摩擦を両立できる
- **Side-slip**: 短いモチーフ全体を半音などで一時的に移動し、元へ戻す。個々の音をコードへ適合させるより、モチーフの形を優先した外側の響きを作る

### コードチェンジをまたぐ旋律

旋律線はコードが変わっても独自の時間軸を持つ。

- **共通音の保持**: 一つの旋律音が、前コードではコードトーン、次コードではテンションとして役割を変える
- **遅延解決**: テンションを現在のコード内で解決せず、次のコードまで保持する
- **先行**: 旋律だけが次コードの音へ先に到達する
- **フレーズとコード周期のずれ**: メロディのフレーズ長とコードループの周期をずらすと、同じ進行上でも毎回異なる位置へ旋律が重なり、関係が変化する

## 7. 旋律の判断と診断

### 旋律音の判断

一つの旋律音は、次の順に文脈を確認して評価する。

1. 現在のコードとの音程
2. 拍位置
3. 持続時間
4. 前の音からの進入
5. 次の音への移動
6. 次コードでの役割
7. フレーズ内の位置
8. 音域
9. 曲全体で使っている音高語彙
10. 狙っている安定・色彩・摩擦の量

この順序に沿うと、コードトーン中心の安定した旋律から強いクロマティックな旋律まで、同じ枠組みで扱える。

### 平坦さの分析

「平坦」という印象は、具体的な軸へ分解して原因を特定する。

| 現象                   | 確認箇所       |
| ---------------------- | -------------- |
| 音価が揃い続ける       | リズム         |
| 休符が少ない           | 空白・呼吸     |
| 音域が固定される       | テッシトゥーラ |
| 上下動が小さい         | 輪郭           |
| 毎小節同じ形           | モチーフ展開   |
| 毎回同じ位置から始まる | アタック位置   |
| 活動量が一定           | 密度           |
| 最高音が頻出する       | 頂点           |
| 旋律音の響きが均質     | メロディと和声 |

原因となる軸を特定すれば、素材の個性を保ったまま変化を加えられる。
