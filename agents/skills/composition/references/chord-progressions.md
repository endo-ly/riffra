# コード進行と和音の運用 — 作曲リファレンス

現代のポップス、J-POP、ロック、R&Bなどの作曲で、**どの和音を選ぶと、どの音が動き、どんな進行が生まれるか**を参照するための資料。コードの性質、接続、テンション、ベース、メロディ、時間的配置を、一つの和声として捉える。

コード進行は、コード名の並びだけで決まるものではない。同じ `IV → V → IIIm → VIm` でも、`IVmaj9 → V7sus4 → IIIm7 → VIm9` とするか、ベースを動かすか、歌のどの音で切り替えるかで、音楽的な働きが変わる。本稿では名称の一覧よりも、**選択した音が実際に何をするか**を重視する。

## 1. 和声の基準

和声の基準となるのは、主音、根音、ベース、内声、旋律の五つである。主音はその区間の中心、根音はコードの構造上の基礎、ベースは実際の最低音、内声はコードの中をつなぐ声部、旋律は和音の中にも外にも位置する。特にループ型のポップスでは、主音が一度もベースに現れなくても、旋律の終着点や反復によって中心が成立する。

短調の `V7` は導音を上げた和声的短音階などに基づくドミナントであり、自然短音階の `Vm` とは役割が異なる。

## 2. コードの種類と響き

### 基本和音・セブンス・付加音

同じ根音でも、**3rdは長短、7thは和声の方向、9th以降は旋律や上声の色**を大きく左右する。次の表は響きの形と、楽曲内で生まれる具体的な違いを整理したもの。

| 和音               | 根音からの構成音 | 音楽的な働き・選択場面                                                                           |
| ------------------ | ---------------- | ------------------------------------------------------------------------------------------------ |
| `I`                | R–3–5            | 明確な長三和音。伴奏を簡素にし、旋律の音色やリズムを前へ出す                                     |
| `Im`               | R–♭3–5           | 短三和音。短調の中心、借用、同根の長短切替に使う                                                 |
| `Imaj7`            | R–3–5–7          | 根音と長7thが半音関係。完全な静止より、持続する透明な緊張を作る                                  |
| `Im7`              | R–♭3–5–♭7        | 短三和音の角が和らぐ。`IIm7` の前置、`VIm7` の持続、マイナーループで使いやすい                   |
| `I7`               | R–3–5–♭7         | 3rdと♭7thの三全音が解決方向を示す。`I7 → IV` やブルースの中心など、文脈で役割が変わる            |
| `ImMaj7`           | R–♭3–5–7         | 短3rdと長7thが共存。短調の主音上の半音進行、上昇・下降クリシェに向く                             |
| `Iadd9`            | R–3–5–9          | 7thを置かずに広がりを付ける。三和音の明瞭さを保ったまま、上声に開いた響きが加わる                |
| `I6` / `I6(9)`     | R–3–5–6（–9）    | 長7thの半音的な緊張を避け、6thと9thを同居させられる。R&Bやシティポップ的な落ち着いた終着にも使う |
| `Im6`              | R–♭3–5–6         | マイナーに長6thが混ざる。ドリアン的な明るさ、または借用和音の滑らかな内声を作る                  |
| `Isus4` / `I7sus4` | R–4–5（–♭7）     | 3rdが一時的に保留され、上声の4→3や旋律の4thを強調する。独立した和音色として持続も可能            |
| `I5`               | R–5              | 長短の判定を上声や旋律へ委ねる。倍音の多い音色で重ねても濁りにくい                               |

`Iadd9` と `Imaj9` は響きの密度だけでなく、7thの有無が異なる。前者は `I` に9thを添える形、後者は `Imaj7` に9thを添える形である。同様に `Im9` は `Im7` に9thが加わる。`I6(9)` も明確に6thと9thを含み、`Imaj13` と同義ではない。

セブンスが進行の性格を変える具体例が `I → I7 → IV`。`I7` で導入された♭7thは、次の `IV` の3rdへ半音下降し、`I` の3rdを保持すれば、`IVmaj7` の7thとして響かせることもできる。`Imaj7 → IVmaj7` では同じ `I → IV` でも、短7thによる強い属和音的な引力が生まれず、色の移動として響きやすい。

### ディミニッシュ・ハーフディミニッシュ・オーギュメント

この三者は音程が似ていても、**含まれる7thと、解決先への半音移動**によって用途が異なる。

| 種類    | 構成音      | 主要な性質                                                                              |
| ------- | ----------- | --------------------------------------------------------------------------------------- |
| `Idim`  | R–♭3–♭5     | 2つの短3度を積んだ減三和音。導音上の一時的な和音や経過和音                              |
| `Idim7` | R–♭3–♭5–♭♭7 | すべて短3度間隔の対称形。異名同音で読み替えると複数方向へ解決し得る                     |
| `Im7♭5` | R–♭3–♭5–♭7  | 減三和音に**短7度**を加えたもの。`dim7` より半音高い7thを持ち、前置和音として働きやすい |
| `Iaug`  | R–3–#5      | 長3度間隔の対称形。5thを半音上げて進行先の構成音に導く                                  |

**dim7：到達先を半音下から示す。** `VIIdim7 → I` は導音が主音に上行する形。根音の位置を変えると `#IVdim7 → V`、`#Vdim7 → VIm` のように各和音の直前へ応用できる。`#IVdim7 → V` では、#IVがVへ上行し、ほかの構成音も近接音へ分散して動ける。ドミナント7th(♭9)から根音を省いた形として聴ける場合もある。

**dim7：和音と和音の間を滑らせる。** `I → #Idim7 → IIm7` は根音の半音上行を作り、`I/III → ♭IIIdim7 → IIm7` は低音の半音下降を作る。後者では `♭III` の根音が `II` へ、減5度に相当する声部も次のコードの構成音へ近接解決できる。ほかに `I → Idim7 → I` のような共通音型があり、主音を保ちながら内声だけを上下させ、単純な主和音の持続に一瞬の陰影を付ける。

**ハーフディミニッシュ：短調の前置和音。** `IIm7♭5 → V7(♭9) → Im` は短調の代表的な `II–V–I`。`IIm7♭5` は `V7` と複数の音を共有しやすく、ドミナントへの導入を長く滑らかにする。メジャーキーでも `VIIm7♭5 → III7 → VIm` とすれば、`VIm` を一時的な短調の到達点として際立たせられる。`VIIm7♭5` はメジャーキーのダイアトニック和音でもあり、文脈によって自然に短調側への入口となる。

ハーフディミニッシュは前置だけではなく、ベース上行の途中にも置ける。`IVmaj7 → #IVm7♭5 → V7` は `IV → #IV → V` と根音が上がり、`#IVm7♭5` の上声には `II7(9)` と共通する音が含まれる。`#IVdim7` と比較すると7thが違うため、同じ半音上行の経路でも内声の色が変わる。

**m6とm7♭5の読み替え。** `IVm6` と `IIm7♭5` は、同じ主音を基準にしたとき**構成音の集合が一致する**。前者は `IVm` に6thを加えた和音、後者は `II` を根音とするハーフディミニッシュである。`IVm6 → I` と `IIm7♭5 → V7 → Im` のように、同じ音集合でも**低音と到達先が変わると役割が変わる**。これはコード名を付け替えただけでなく、作曲で同じ素材を異なる方向へ運ぶ有効な視点となる。

**aug：半音上昇する内声の途中に置く。** `I → Iaug → VIm` は、`I` の5thを半音上げ、その音を `VIm` の根音へ導く。`I → Iaug → IV` でも、上げた5thが `IV` の3rdへ進み、`I` の3rdも `IV` の根音へ半音で進められる。`I → Iaug → I6` なら、固定した根音の上で5th→#5th→6thという線が生まれる。増三和音は長3度間隔の対称性を持つため、転回や異名同音によって複数の和音へ結び付く。長い機能進行を挟むより、**1〜2音の半音移動を可聴化する中間和音**として現れやすい。

`V7(#5)` は `Iaug` の単純な別表記ではない。前者には♭7thがありドミナントのガイドトーンを持つ。`V7(#5) → Im` では、#5thと解決先の短3rdが異名同音の関係になる場合があり、短調への接続やドミナントの緊張を濃くできる。

**対称構造の実用的な読み替え。** `Idim7` の四音は、根音を短3度ずらした別のdim7と同じ音の集合になる。`VIIdim7` と `IIdim7`、`IVdim7`、`♭VIdim7` は、異名同音で表すと同じ減七和音になる場合がある。ベースをどこに置き、どの声部を半音で解決するかによって、同じ音集合から別の到達先を作れる。増三和音も長3度ずつ根音を移した転回が同一音集合となる。`Iaug` に対して `IIIaug` と `♭VIaug` は異名同音の解釈が可能であり、メロディを共通音として残したままベース側だけを転換できる。転調の橋渡しに使われるのは、このような**構成音の共有と文脈の読み替え**である。

**特殊なオンコード：Blackadder Chord。** ベースを基準とした音程が半音数で `0–2–6–10` となる四音集合で、上三音は増三和音を形成する。`Vaug/♭II → I` は、到達先Iの半音上にベース♭IIを置き、上側の `Vaug` に含まれる導音をIへ半音上行させる。`Iaug/♭V → IV` ではベースが `♭V → IV` と半音下降し、上声の変化と同時にIVへ集まる。`Iaug/♭VII → I` ではベースが全音上行して主和音へ戻る。通常の増三和音と比べて、**上声の対称性と、ベースに独立した半音進行を持たせる**点が特徴である。増三和音・変化ドミナント・増六系のいずれとしても読めるため、どの読みを採るかより、次にどの音が解決するかで用法が決まる。

## 3. テンションとボイシング

テンションは9th・11th・13thを中心とした拡張音。基本の3rd・7thが和音の長短や機能を示すのに対し、テンションは**旋律との接点、声部の行き先、和音の色**を調整する。コード記号に多くの数字が付くことと、実際に多くの音を同時に鳴らすことは同義ではない。低音が根音を受け持つ場合、伴奏の上声は3rd・7th・テンションの3音程度でも十分に和音の性格を伝えられる。

### テンションの種類

| テンション | 根音からの距離 | 実際に生まれる動き・響き                                                                    |
| ---------- | -------------- | ------------------------------------------------------------------------------------------- |
| `9`        | 長9度          | 開放感と上声の旋律性。`Iadd9`、`Imaj9`、`Im9`、`V9` に広く使える                            |
| `♭9`       | 短9度          | 根音の半音上に位置し、近い音への解決を強く予感させる。`III7(♭9) → VIm` や `V7(♭9) → Im`     |
| `#9`       | 増9度          | ドミナントの長3rdと短3rd相当の音色が並ぶ、ブルージーで強い濁り。`V7(#9)`                    |
| `11`       | 完全11度       | 3rdと近接する場合はsus系の色や意図的な擦れを作る。`Im11`、`V7sus4(9)`                       |
| `#11`      | 増11度         | 根音から増4度。Lydianの特徴音、上声の明るい浮遊感。`Imaj7(#11)`、`IVmaj7(#11)`、`♭II7(#11)` |
| `13`       | 長13度         | 6thの色を7thと併せ持つ。`V7(9,13)`、`IIm13`、`Im13`（ドリアン系）                           |
| `♭13`      | 短13度         | 半音的な陰影を加える。`V7(♭13)`、ナチュラルマイナー由来の `Im7(♭13)`                        |

`9` と `2`、`11` と `4`、`13` と `6` は音名のクラスとしては一致するが、和音の中での扱いは異なる。`add9` は七の和音を前提とせず、`9` は七の和音を含意することが多い。`sus4` は通常3rdの代わりに4thを採用する。`7(11)` で3rdと11thを共存させる場合は、別の和音状態になる。

### 和音ごとの選択肢

コードごとにどの音が9th・11th・13thとして取れ、どの音が擦れるかは、[melody.md の「代表的なコード上での旋律候補」](melody.md#代表的なコード上での旋律候補)に一覧している。旋律で鳴らしても上声で鳴らしても、和音に対する音程は同じである。

**ドミナントでは「どこへ解決するか」がテンションの意味を決める。** `III7(♭9) → VIm` では♭9thが到達先の5thへ半音下降しやすく、3rdは到達先の根音へ半音上行しやすい。`V7(♭9) → Im` では、♭9thを次の5thへ半音下降させる配置が作れる。`V7(9,13) → Imaj7` は滑らかな上声を保ちやすく、`V7(#9,♭13) → Im` は短調の色と強い内声の動きを前面に出す。`V7(#11)` はトライトーン代理やリディアン・ドミナント的な色としても現れる。どのスケール名に属するか以上に、**実際に残る音と動く音**が結果を決める。

### メロディと音域

旋律音がコードの9th・11th・13thに相当する場合、その音自体が拡張和音の役割を担う。伴奏が `I` でも、旋律が9thで伸びれば全体として `Iadd9` 的な響きになる。反対に伴奏で9thまで全部鳴らしているところへ旋律が同じ9thを重ねても、和声上の新情報は増えにくい。**旋律・上声・ベースを合算して和音が成立する**と考えると、声部間の無駄な重複を減らせる。

低音域で3rdと7thやテンションを密集させると倍音が重なり、濁りとして知覚されやすい。低音はベースを中心に、内声は3rdと7th、テンションと旋律は中高音域へ配置すると各音の役割を聴き取りやすくなる。豊かなコードネームでも、実際の鍵盤やギターで5thや根音を省くことが多い。根音をベースが弾くアンサンブルなら、和音楽器の**3rdと7thだけで長短とドミナントの方向を示し、9thや13thで色を決める**配置が効率的である。一方、上声を密集させたクラスターや、低域に短2度を置く選択は、特定の衝突音を前面に出す。作曲時には**コードネームが要求する音の集合**と、**各楽器がどの音を実際に鳴らすか**を分けて設計すると、複雑な和音でもアレンジを整理できる。

ギターの歪みが厚い場面では、三和音や `I5` の明瞭さが旋律を支える。一方、エレピやクリーンギターで中高音域に間隔を取った `maj9`、`m9`、`7sus4(9)` は、音数を抑えながら精緻な和声を表現しやすい。これはジャンルごとの絶対則ではなく、倍音密度と音域による違いである。

### コードに応じたテンションの処理

テンションを「和音を豊かにする音」として選ぶ場合と、「次のコードへの移動音」として選ぶ場合とでは、同じ記号でも働きが違う。`IVmaj9 → III7(♭9) → VIm9` なら、IVの9thを旋律の長音に重ねて保持する使い方がある一方、III7の♭9thは半音下降してVImの5thへ移す使い方がある。`IVmaj7(#11)` における#11thは、メジャーキー内の音を使いながら、IVからIへ帰着する前の光のような広がりを生む。`Imaj7(#11)` の#11thは同じ音程名でもキー外音となるため、トニック上でリディアンの色を長く保持する選択となる。

| 選択              | コード列・上声          | 動く音                                         |
| ----------------- | ----------------------- | ---------------------------------------------- |
| テンションを保持  | `IVmaj9 → IIIm7 → VIm9` | 近い共通音を連続させ、上声の動きを最小にする   |
| ♭9thを解決        | `III7(♭9) → VIm`        | ♭9thがVImの5th、3rdがVImの根音へ半音移動できる |
| 13thを次の長7thへ | `V7(13) → Imaj7`        | V7の13thはImaj7の3rdとして残せる場合がある     |
| 4thを保留・解決   | `V7sus4(9) → V7(9) → I` | V上の4thが3rdへ下降して導音を明確にする        |
| #11thを持続       | `Imaj7(#11) ↔ II/I`     | 主音に対する#IVを共通音として聴かせる          |

7thやテンションが多いコードでも、すべての音を同時に鳴らす必要はない。`V7(9,13)` の5thを省いて3rd・♭7th・9th・13thを中高域へ配置すれば、ドミナントの性質は3rdと♭7thが保ち、9thと13thが旋律の色を担う。対して `V7(♭9,♭13)` は、♭9thと♭13thを半音先のコードトーンへ動かすことで強い収束を作れる。単独で響かせたコードの良し悪しと、**前後の和音と重なったときの音の動き**は分けて判断できる。

## 4. コードの接続と和声の拡張

コードの接続は、**機能**（どこが中心か）、**根音の距離**（どこへ向かうか）、**声部の移動**（どの音が変わるか）の三面から捉えられる。ポップスでは、これらが同じ方向を向くことも、意図的に別の方向を向くこともある。

### 機能と根音運動

| 接続                       | 音楽的な作用                                   | 代表的な形                                  |
| -------------------------- | ---------------------------------------------- | ------------------------------------------- |
| ドミナントからトニック     | 導音と7thが半音解決し、中心を明確にする        | `V7 → I`、`V7(♭9) → Im`                     |
| サブドミナントからトニック | 共通音を保持しながら、穏やかに帰る             | `IV → I`、`IVm6 → I`                        |
| 偽終止                     | ドミナントの方向を利用しつつ、着地を横にずらす | `V7 → VIm`、`V7 → ♭VI`（短調）              |
| 5度下行・4度上行           | 根音を周期的に運び、強い連鎖を作る             | `IIIm7 → VIm7 → IIm7 → V7 → I`              |
| 3度関係                    | 共通音を残しやすく、和音色を変える             | `I → VIm`、`I → IIIm`、`I → ♭VI`            |
| 全音・半音の接続           | 根音そのものを旋律として扱う                   | `IIm7 → IIIm7 → IVmaj7`、`IV → #IVm7♭5 → V` |
| 同根の品質変化             | ベースを固定したまま内声だけ動かす             | `IVmaj7 → IVmMaj7`、`I → Iaug`              |

`IIIm7 → VIm7 → IIm7 → V7 → Imaj7` のような5度連鎖は、部分的に `VIm7 → IIm7 → V7 → I` へ短縮しても作用する。`IIm7 → V7 → Imaj7` のうち `V7` の3rdは `I` の根音へ半音上行し、7thは `I` の3rdへ半音下降する。この**二本のガイドトーン**が、根音の5度移動を単なるベースの跳躍以上のものにする。

一方、`I → VIm` のような3度関係は二つの共通音を持ち、内声をあまり動かさずに根音を変えられる。`I → ♭VI` などダイアトニック外への3度関係では、共通音を軸に遠い和音へ移る色彩感が強まる。どのコード間にもT/S/Dを一意に当てはめるより、共有する音とベースの変化を見る方が接続を説明しやすい場合がある。

### セカンダリードミナントと連鎖

セカンダリードミナントは、**途中のコードを一時的な主和音として聴かせる**仕組み。到達先の完全5度上をドミナント7thにすることで、元の調にはない導音を導入する。

| 形            | 到達先 | 実際に増える動き                                                 |
| ------------- | ------ | ---------------------------------------------------------------- |
| `I7 → IV`     | `IV`   | 元の主音上に♭7thを加え、IVへ向かう半音解決を作る                 |
| `II7 → V`     | `V`    | `II` の3rdを半音上げ、Vの根音へ引く                              |
| `III7 → VIm`  | `VIm`  | `III` の3rdを半音上げ、短調側の主音へ引く                        |
| `VI7 → IIm`   | `IIm`  | `VI` の3rdを半音上げ、次の `IIm` へ接続する                      |
| `VII7 → IIIm` | `IIIm` | `IIIm` を局所的に強調する。導音に相当する音と7thによる解決を生む |

`III7 → VIm` の前に `VIIm7♭5` を置くと、`VIIm7♭5 → III7 → VIm` となる。これは `VIm` を一時的な短調中心と見た `II–V–I` である。メジャー側の到達点なら `VIm7 → II7 → V` のように、到達先に対するマイナー7thを前置できる。さらに `III7 → VI7 → II7 → V7 → I` と連結すると、五度循環の各到達点が次の到達点を呼ぶ構造になる。明快な推進が必要な短い区間にも、間奏などの長い経路にも応用できる。

セカンダリードミナントは毎回その到達先に着地しなくてもよい。到達を遅らせたり、別のコードへかわしたりすることで、局所的な期待を作れる。ただしこの場合でも、導入された導音と7thの線を追うと、なぜ期待が生まれたかが分かる。

### 借用和音・代理・半音接続

**同主短調・同主モードからの借用**は、中心音を保ったまま調の外側の音を取り入れる。典型的な `IV → IVm → I` では、`IV` の3rdだけが半音下がり、次の `I` の5thへさらに半音下降する。`IVmaj7 → IVmMaj7 → IIIm7` なら `IVmaj7` の長7thを保ったまま3rdを下げ、その後すべての上声を近い音へ落とせる。機能名の「サブドミナントマイナー」以上に、この**半音下降の線**が効果の中心にある。

| 接続               | 含まれる音の操作                                        | 進行の性格                         |
| ------------------ | ------------------------------------------------------- | ---------------------------------- |
| `IV → IVm → I`     | `IV` の3rdを半音下降し、さらに `I` の5thへ導く          | 終端に陰影を加える                 |
| `IVm7 → ♭VII7 → I` | 借用マイナーから5度方向に進み、`♭VII7` から主和音へ戻る | バックドア型の帰着                 |
| `♭VI → ♭VII → I`   | 借用和音の全音上行と主音への接続                        | 力強い上昇・ロック的な帰着         |
| `I → ♭III → IV`    | ダイアトニック外の短3度上行と隣接根音                   | 明暗を変えつつIVへ向かう           |
| `Vm7 → I7 → IV`    | `IV` を一時的な中心にした `II–V–I` の後半               | IVへの滑らかな着地とループへの接続 |
| `♭II → V7 → Im`    | 主音の半音上にある借用和音からドミナントへ              | フリジアン／ナポリ風の前置         |

**トライトーン代理（裏コード）**は、`V7` を `♭II7` へ置き換える代表的な方法。両者は3rdと7thに相当する三全音を異名同音で共有し、`♭II7 → I` ではベースが半音下降する。`IIm7 → ♭II7 → Imaj7` は、`IIm7 → V7 → Imaj7` とほぼ同じガイドトーンの方向を保ちながら、ベースを `II → ♭II → I` と一直線にする。`♭IImaj7` は同じ根音でもドミナント7thと構成音が異なり、トライトーン代理と同じ機構ではない。こちらは半音上の長七和音から主和音へ接する色彩的な接続として扱える。

`♭VII7 → I` は `♭II7 → I` と区別する。前者はバックドア的な接続、後者はトライトーン代理で、**根音もガイドトーンも異なる**。ただし `IVm7 → ♭VII7 → Imaj7` のように、IVmの借用音が♭VII7へ引き継がれる場合は、強い `V7 → I` 以外の帰着を作れる。

**クロマティック・メディアント**は、主に三度関係の根音と調外音を利用する。`I → ♭VI`、`I → ♭III`、`I → III` などは共通音を1音程度残しながら調の色を大きく変えられる。機能的な準備を経ずに景色が切り替わるため、その共通音を旋律が保持していると、同じ音のまま背景だけが別の場所へ移ったように聴こえる。対して `Imaj7 → IImaj7 → IIImaj7` のような同品質の平行移動は、機能関係より**ボイシング全体の形と移動量**が統一感を作る。

短い借用と転調の違いは、調外コードの数ではなく、**新しい主音が旋律・ベース・終着点に継続して成立するか**で判断する。単発の `III7 → VIm` は元の調の一時的な強調で済むことが多く、`VIm` を中心とするドミナントや終止が続けば平行短調への転調として聴かれ得る。共通コード、ドミナント経由、共通音、直接移動、dim7・augの異名同音による読み替えはいずれも転調の接続手段となる。

### 反復・シークエンス・経過和音

和音の並びは、単独のコードの機能だけでなく、**数コードをまとめた反復の仕方**によっても統一される。`IIIm7 → VIm7 → IIm7 → V7 → I` は、五度方向の動きを繰り返すシークエンスの一部として読める。`IIm7 → IIIm7 → IVmaj7` のように根音を二度ずつ動かせば、ベースの線そのものが旋律になる。`Imaj7 → IImaj7 → IIImaj7` のような平行移動では、同じボイシングが上方へ滑ることが音楽上のまとまりを作る。

根音が**短3度周期**で巡る `I → ♭III → ♭V → VI → I` はdim7の対称構造と結び付き、**長3度周期**で巡る `I → III → ♭VI → I` はaugの対称構造と結び付く。ただし根音の周期と各和音がdim7／augであることは別の条件で、コード品質は旋律・ベース・到達先に応じて変えられる。短いフレーズを移調して繰り返すシークエンスでは、構成音だけでなく**移動の幅と反復単位**が構造を決める。

経過和音は、その瞬間だけを切り取るより前後の音の動きから理解できる。`I → #Idim7 → IIm7` は低音の半音上昇、`IVmaj7 → #IVm7♭5 → V7` も同じく低音の半音上昇であり、どちらも中間の和音は次へ向かうための位置にある。`I → ♭II7 → I` のような上下の装飾、`I/III → ♭IIIdim7 → IIm7` のような下降、また `I → Im → I` の同根変化は、1音または複数の声部が短い距離を往復することで進行の密度を増やす。

**ナポリ系・増六系の接続。** `♭II → V7 → Im` は主音の半音上の長三和音を前置和音として用いる形で、低い第2音を強調する。増六系では `♭VI` に相当する音をVへ半音下降させ、`#IV` に相当する音をVへ半音上行させる。二つの音が**両側から属音Vへ収束する**ことが核心で、`♭II` を独立した和音として置くこととは異なる。転調では、dim7の同じ四音を新しい導音上の和音として読み替える方法、増六系を異名同音のドミナント7thとして読ませる方法などがある。

### 転調とモードによる中心の移動

新しいトニックが旋律の到達点、ベースの帰着、ドミナントの反復によって持続的に成立すると、同じコードの機能を**新しい主音から**読み直せる。転調の境目には旧調と新調の双方に属する共通コードを使う方法、新調のドミナントを先行させる方法、共通音を保って根音や和音品質を遠くへ動かす方法、シークエンスで移調する方法、準備を置かずに新調の主和音へ直接移る方法がある。いずれも、新しい中心がどこまで続くかで転調としての強さが変わる。

| 中心のモード | 反復・進行             | 主音から見た特徴音 |
| ------------ | ---------------------- | ------------------ |
| Aeolian      | `Im → ♭VI → ♭VII → Im` | ♭VI・♭VII          |
| Dorian       | `Im7 ↔ IV7`            | 長6度（IVの長3rd） |
| Phrygian     | `Im ↔ ♭II`             | ♭II                |
| Mixolydian   | `I7 → ♭VII → IV → I7`  | 短7度と♭VII        |
| Lydian       | `Imaj7(#11) ↔ II/I`    | #IV（#11th）       |

モード的な往復では、強い属和音終止を作らずとも、中心音と特徴音を繰り返すことで和声を成立させられる。たとえば `Im7 ↔ IV7` はIVの長3rdでドリアンの長6度を提示し、`Im → ♭II → Im` はフリジアンの短2度を際立たせる。同じ主音でも、`IIm7♭5 → V7(♭9) → Im` のような短調の属和音終止へ移行すれば、モードにない導音VIIによる収束を加えられる。曲中で中心が変わったときは、新たなキーを宣言し、その区間のディグリーを読み直すと進行が整理できる。

### 同じ構成音を別の役割へ移す

コードを選び替えるとき、構成音の集合がどこまで一致しているかは重要な指標になる。`IVm6` と `IIm7♭5` は同じ四音集合でも、`IVm6 → I` ではIVの長短変化を引き継ぐ借用和音、`IIm7♭5 → V7 → Im` では短調に向かう前置和音となる。`IIm7/V` と `V7sus4(9)` は、同じ音集合を別の根音から記述できる代表的な例。どちらを採るかは、上声をIIm7として保つのか、Vを中心とするドミナントとして捉えるのか、という視点の違いを表す。

また、`♭II7` と `V7` はガイドトーンの三全音を共有するため、`IIm7 → V7 → I` を `IIm7 → ♭II7 → I` に変えてベースを順次下降させられる。一方、`♭IImaj7 → I` では共有するガイドトーンが変わるため、同じ半音下降ベースでも色彩的な接続として響く。`IVm7 → ♭VII7 → I` のバックドアでは、前置和音と属七系の共通音を引き継いでからトニックへ戻る。こうした接続は、コード名が似ているかより**同じ音を残し、どの一音を半音移動させるか**で区別できる。

## 5. ベースと時間構造

和声の性格は、コードの根音だけでなく**どの音を最低音に置くか**によって変化する。同じコード集合を使い続けながら、ベースだけで方向感を作れる点が、オンコードの実用性である。

### 転回形・オンコード・固定ベース

| 型                 | 度数による形                    | 実際に起こること                                              |
| ------------------ | ------------------------------- | ------------------------------------------------------------- |
| 第1転回形          | `I/III`                         | 主和音の3rdが最低音となり、ベースの段階的な移動を作る         |
| 第2転回形          | `I/V`                           | 5thを最低音にして、ドミナント周辺の固定音や一時的な緊張を作る |
| 下降ベース         | `I → V/VII → VIm → IIIm/V → IV` | ベースが `I → VII → VI → V → IV` と順次下降する               |
| ペダル             | `I → IV/I → ♭VII/I → I`         | ベースを主音に固定し、上声だけを変える                        |
| ハイブリッド       | `IV/V`、`IIm7/V`                | 上声の和音とベースを分離し、ドミナント周辺にsus系の色を作る   |
| 同一ベースの色替え | `I → Imaj7 → I7 → IV/I`         | 根音の土台を保ちながら、長7th・短7th・IV由来の音を移す        |

`I → V/VII → VIm → IIIm/V → IV` の各ベースは順番に下降するが、コードの根音は `I → V → VI → III → IV` と異なる。**ベースの旋律と和音の機能を独立して設計できる**。この自由度を利用すると、カノン型などの進行を根本から変えず、流れるようなつながりを加えられる。

`IV/V` と `IIm7/V` は、ともに `V7sus4(9)` に近い響きを作れる。特に `IIm7/V` には、Vを根音と見たときの5thも含まれる。`IIm7 → IIm7/V → Imaj7` とすれば、上声の `IIm7` の形を保ちながらベースだけを V に動かし、その後主音へ戻れる。従来の `IIm7 → V7 → I` に比べ、上声が急にドミナントの3rdへ移らない分、解決を穏やかに保つ。

`II/I` では、ベースIの上にIIメジャーの構成音が重なり、主音に対する9th・#11th・13thの上声が得られる。旋律に#IV相当の音を置けば、Lydian寄りの鮮やかな響きになる。上声とベースの間に3rdを含めないボイシングは、調性感が明確な場面でも和音の長短を保留できる。

### クリシェと声部の線

クリシェは、和音の領域を大きく変えずに一つの声部を連続的に動かす手法。`Im → ImMaj7/VII → Im7/♭VII → IV7/VI` はベースが `I → VII → ♭VII → VI` と半音下降する型で、短調の主音を出発点にしつつ段階的に和声が変わる。`I → Iaug → I6 → I7` では、根音Iを保ちながら上声が `V → #V → VI → ♭VII` と上昇する。前者は低音を動かすクリシェ、後者は内声を動かすクリシェとして、同じ仕組みを異なる場所に置ける。

※ `IV7/VI` のようなコードは、ベースVIと上声IV7を独立させた読みにもなり得る。クリシェではコード名の唯一の正解より、**どの音が連続し、ほかの音が何を保持しているか**が重要である。

ベース以外の声部でも、固定音、反行、平行移動を用いて同じコード列の表情を変えられる。`I → VIm` は二つの共通音を保持でき、`IV → IVm` は3rdだけを半音下げられる。ベースが `I → VII → VI` と下降する間に、上声が `III → IV → V` と上行すれば反行となり、コード自体の変化に加えて上下の広がりが生まれる。ベースがIを保ち、上声だけを `I → II/I → IVm/I → I` と動かすペダル型では、固定された低音と離れる上声の対比が中心になる。

### コード尺とループ境界

| 配置 | 意味   |
| ---- | ------ |
| `    | IV     | V         | IIIm   | VIm                          | `                                                                             | 4小節1周期。各コードの色を明瞭に聴かせる      |
| `    | IV V   | IIIm VIm  | `      | 2小節1周期。和声の回転が早い |
| `    | IVmaj7 | III7 VIm7 | I7     | `                            | 局所的な `III7 → VIm7` の解決を小節内に入れ、最後の `I7` を次周期のIVへつなぐ |
| `    | VIm9   | VIm9      | IVmaj7 | V7sus4                       | `                                                                             | 短調側を長く保持した後、IVとVで変化をまとめる |

コードを切り替える位置はメロディの構造と結び付く。旋律の持続音の途中でコードを替えると、同じ旋律音の和音に対する意味が変わる（[melody.md の「コードチェンジをまたぐ線」](melody.md#コードチェンジをまたぐ線)）。対してフレーズの切れ目でコードを動かせば、歌の区切りを明確にしやすい。弱拍や裏拍で先取りしてコードを変えると、メロディの着地より先に和声が到達する推進も得られる。

一つの和音区間を二つへ細分化する場合は、もとの時間枠と到達点を保つことができる。`| I | V | VIm |` に対して `| I | VIIm7♭5 III7 | VIm |` とすれば、VImへ着地する位置は同じまま、中間で二つのコードが現れる。逆に `| I | VIIm7♭5 III7 | VIm |` を `| I | III7 | VIm |` と整理すれば、局所ドミナントを残したまま細かい動きを減らせる。旋律の開始前や息継ぎで細分化すると伴奏側が動きを補い、長い旋律音の途中で細分化すると同じ音の和声的な意味が変わる。

4コードのループは、最後のコードから**冒頭へ戻る接続**を含めて設計する。`IVmaj7 → III7 → VIm7 → I7` の最後の `I7` は、次周の `IVmaj7` に対するセカンダリードミナントとして機能する。`I → V → VIm → IV` では `IV → I` が境界となり、強い属七の終止を挟まずに循環する。強い属和音終止を含まない循環は、どの位置からでも始まり、どこでも切れる。その区切りは和声ではなく、ドラムのフィル、休符、旋律の着地で示される。曲中でループを切り替える場合は、区間の最後の1コードだけを `V7`、`III7`、`♭VII`、次の冒頭コードの半音上または下からのアプローチなどへ替えると、循環の性格を保ったまま次セクションの冒頭コードへ向けられる。

### 少ないコードの循環

コードの数が少ない進行では、和声の変化が担っていた推進と色を、ほかの層が引き受ける。ループが単調に聴こえるかどうかは、コードの数ではなく、**反復のなかで何が変わり続けているか**で決まる。

| 循環             | 構成音の関係                                | 響き                                                   |
| ---------------- | ------------------------------------------- | ------------------------------------------------------ |
| `Im` のみ        | 和声の変化なし                              | ベースの動き、リズム、旋律の音選びが変化のすべてを担う |
| `Im ↔ ♭VI`       | 共通音2つ。Imの5thだけが半音上下する        | 中心を動かさずに陰影だけが揺れる                       |
| `I ↔ ♭VII`       | 全音下の長三和音との往復                    | 導音を含まないため、終止感を持たないまま明るさが続く   |
| `IVmaj7 ↔ Imaj7` | IVの7thがIの3rd、IVの5thがIの根音として残る | 帰着の強さがなく、二つの色が溶け合ったまま往復する     |

モード的な往復（`Im7 ↔ IV7`、`Im ↔ ♭II` など）は[転調とモードによる中心の移動](#転調とモードによる中心の移動)の表を参照する。二つのコードのどちらが中心に聴こえるかは、小節頭に置かれる側、長い音価を取る側、旋律が着地する側で決まる。同じ二和音でも、この配置を入れ替えるだけで主従が逆転する。

和音を「コード名の並び」ではなく、繰り返す音形として扱うこともできる。パワーコードやオクターブのリフでは3rdが鳴らないため、長短は旋律が決める。長三和音の上に♭3や♭7のブルーノートを乗せても成立し、`I5 → ♭III5 → IV5` のように借用由来の根音へ動いても明暗は確定しない。リフでは和音の種類より、**音形のリズムと反復の周期**が曲の同一性を作る。

### コードを増やさずに変化を作る

この章の手法は、コード進行を変えずに反復へ変化を与える手段として横断的に引ける。

| 層             | 和声を変えずにできること                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------ |
| ベース         | ペダルで固定した区間から動き出す、オクターブや経過音を加える、転回形で最低音だけを替える         |
| 上声の最上音   | 同じコード名のまま、最上音を 5th → 9th → 3rd と移して線を作る                                    |
| 3rdの有無      | `I5` → `Isus4` → `I` → `Iadd9` と、長短の提示と色の量を段階的に変える                            |
| ボイシングの型 | 4度堆積（3rdを含まない積み方）にすると長短と機能が曖昧になり、平行移動しても調の枠に縛られにくい |
| コード尺       | 同じ循環を区間によって倍速・半速にする、切り替えを裏拍へ先取りする                               |
| 旋律           | 同じ和音上で旋律音を根音・3rdから9th・11thへ移し、和声の意味を旋律側から変える                   |
| 鳴らす楽器     | 和音楽器を抜き、ベースと旋律の2声だけで和声を暗示する区間を作る                                  |

## 6. J-POPのコード進行と現代的な和声

日本のポップスで定着した進行名は、音の動きを素早く共有するための語彙として役立つ。同じ通称でも7th・テンション・転回形・小節内の配分まで一定とは限らないため、ここでは**骨格、特徴となる音の動き、発展させる接続、ループの境界**をセットで記す。

### 基本的な循環とその変化

**王道進行（4536）** — `IV → V → IIIm → VIm`。

`IV → V` で高まった期待が `I` へ直接着地せず、`IIIm → VIm` の二つのマイナー和音へ流れる。根音は `IV → V → III → VI`、末尾の `IIIm → VIm` は五度方向の接続である。主和音Iを通らなくても、旋律や次の区間がIを中心として聴かせられる。`IVmaj9 → V7sus4(9) → IIIm7 → VIm9` では解決を保留した柔らかな循環となり、`IVmaj7 → V → III7(♭9) → VIm7` では `III7` の導音によってVImが明確な到達点になる。サビの連続的な高揚感、次のフレーズへ続く余韻の両方に使える。

王道進行のベース変形である**後ろ髪型**は `IV → V/IV → IIIm → VIm`。Vの上声へ進んでも低音IVを保ち、緊張をその場に留める。**おくれ毛型**は `IV → V → V/IV → IIIm → VIm` で、Vの途中に低音IVを挿入する。どちらもコードの機能より、ベースがいつ動き始めるかが重要である。`IVmaj7 → V7/IV → IIIm7 → VIm7` を「メロウな王道進行」と呼ぶ進行集もある。王道進行が終わった後には `IIm7 → V7 → I` と長調へ解決させたり、`IIm7 → III7 → VIm` と短調への帰着を追加したりできる。

**カノン進行** — `I → V → VIm → IIIm → IV → I → IV → V`。

八つの区間からなり、前半は `I → V`、`VIm → IIIm` の4度下行を、`V → VIm`、`IIIm → IV` の2度上行でつなぐ。同じ「4度下がって2度上がる」動きを二度繰り返すシークエンスで、ベースは全体として段階的に下降していく。`V → VIm` は予想されるIへの終止を回避し、`IV → V` が次周期のIへの助走になる。基本形の各コードを一小節ずつ使うと大きな歌の弧を作りやすく、二拍単位に縮めると躍動する循環になる。後半の `IV → I → IV → V` を `IV → I/III → IIm7 → V7` に変えたり、中盤を `VIIm7♭5 → III7 → VIm` と細分化したりしても、元の長い枠を保てる。

**純情進行（なめらかカノン）** — `I → V/VII → VIm → IIIm/V → IV → I/III → IIm → V`。

カノン系の上声を維持しながら、低音が `I → VII → VI → V → IV → III → II → V` と段階的に下降する。`V/VII` や `I/III` は根音を変えずにベースの音だけを選び直したもの。根音の跳躍が多いカノンを、歌うような一本のベース線へまとめられる。ピアノの分散和音やストリングスでは低音と上声を別々に聴かせると効果が明瞭になる。最後を `IIm7 → V7 → I` と明確に閉じる方法と、`IIm7 → V7 → VIm` でマイナーへ回避する方法では同じ下降線の終端が変わる。

**小室進行（6451）** — `VIm → IV → V → I`。

マイナーから開始し `IV → V → I` で長調側へ抜けるため、四つのコードで緊張と帰着が成立する。ビートを強調した反復にも、長く伸ばすメロディを乗せたバラードにも利用できる。`VIm → IIm7 → V7 → I` とすると後半が五度方向の長い経路になる。ループを `… I → III7 | VIm …` とつなげると、Iの安定が次の短調側への導入に変わる。

**ポップパンク進行（1564）** — `I → V → VIm → IV`。

Iの安定からVで前進し、`V → VIm` で偽終止的に方向をずらし、IVから次周のIへ戻る。`VIm → IV → I → V`（6415）、`IV → I → V → VIm`（4156）は同じ円環の開始位置を変えた形で、冒頭コードと終端が変わるため、旋律の重心も移る。三和音やパワーコードなら輪郭が明快になり、`Iadd9 → V7sus4 → VIm7 → IVmaj7` とすると音を延ばしやすい。名称は海外のロックにも関連するため、日本独自の進行ではない。

**50s進行（1645）** — `I → VIm → IV → V`。

ドゥーワップで知られる長い歴史を持つ循環。`I → VIm` は共通音を二つ持ち、`IV → V` が次のIへの推進となる。`I → VIm7 → IIm7 → V7` とすると、後半が五度方向に接続する「1625進行」と近づく。前者はIVを挟むことで比較的はっきりしたサブドミナントの広がりを持ち、後者はIIからVへの連鎖が中心になる。

**1625進行** — `I → VIm → IIm → V`。

一周の中に `VIm → IIm → V → I` の五度方向が含まれる。`Imaj7 → VIm7 → IIm7 → V7` はジャズや歌謡曲的な循環にもなり、`I → VI7 → IIm7 → V7` ならVI7によって次のIIへの引力が増える。`VI7 → II7 → V7 → I` とさらに連鎖させると、局所的な到達点の数が増える。1小節を一和音で取るか、`| I VI7 | IIm7 V7 |` と短く回すかによっても密度が変わる。

**ユーロビート進行（456系）** — `IV → V → VIm`。

IV→Vの期待がIに戻らずVImへ抜ける短い単位。王道進行の `IIIm` を省いたような骨格で、`IV → V → VIm → IIIm`、`IV → V → VIm → I` と先へ延ばせる。速いテンポでは三つの到達点を明確に刻むことで上昇の勢いを作り、7thを足して持続させれば短いコード数でも細やかな色を出せる。

**マリオ進行** — `♭VI → ♭VII → I`。

メジャー中心に同主短調由来の `♭VI` と `♭VII` を置き、根音を全音ずつ上昇させる。`IV → V → I` と似た三段の到達構造でも、上声に `♭VI`・`♭VII` の音が加わり、ロックやゲーム音楽的な広がりを作る。`♭VImaj7 → ♭VII7 → Iadd9`、`♭VI → ♭VII → Im` のように、到達先と和音品質の選択で長調の解放と短調の緊張を切り替えられる。

### セカンダリードミナントと循環の発展

**丸サ進行（Just the Two of Us系）** — 核は `IVmaj7 → III7 → VIm7`。周回形として `IVmaj7 → III7 → VIm7 → I7`、延長形として `IVmaj7 → III7 → VIm7 → Vm7 → I7`。

`III7` はVImに向かう局所ドミナントであり、その3rdはVImの根音へ半音上行できる。`IVmaj7` と `VIm7` の間には共通音もあり、二つの柔らかなセブンスを色彩の異なるドミナントがつなぐ。`I7` は次のIVに向かうドミナント、`Vm7 → I7` はIVに対するリレーテッド `II–V` として働く。したがって一周の中でVImとIVという**二つの局所的な到達点**を作れる。`IVmaj9 → III7(#9) → VIm9 → I7(13)` のように上声を豊かにしても骨格は続く。`IVmaj7 → III7 → VIm7 → II7`（「オシャレ丸サ」と呼ばれることがある）では、末尾がVへ向かうため、次周への接続先を組み直す必要がある。

**コンファメ進行（コンファメーション／ハレ晴レ系）** — 一つの代表的な長い形は次のとおり。

```text
| I | VIIm7♭5  III7 | VIm | Vm7  I7 |
| IVmaj7 | IIIm  VI7 | II7 | V7 |
```

ジャズの「Confirmation」と結び付けられる進行で、カノン系の `I → V → VIm → IIIm → IV` のVやIIImの区間を、次の到達点に対する `II–V` へ分割した形として理解できる。`VIIm7♭5 → III7 → VIm` はVImに向かう短調型の `II–V–I`、`Vm7 → I7 → IVmaj7` はIVに向かう長調型の `II–V–I`。その後 `IIIm → VI7 → II7 → V7` は五度方向の連鎖となり、次のIへ戻る。特に重要なのはコード尺で、`VIIm7♭5 III7` を一小節にまとめると、基本のカノンに近い時間幅のまま二つの小さな和声を入れられる。`IIIm → VI7 → II7 → V7` を `I/III → IIm7 → V7` に整理することも、`III7` のテンションやドミナントの代理を加えることもできる。曲ごとに後半は異なり、この代表形は一つのファミリーを示している。

**シャンゼリゼ進行** — `I → III7 → VIm → I7 → IV → …`。

カノン系の `I → V → VIm → IIIm → IV` の中間に現れる和音を、VImに対するIII7、IVに対するI7へ変更した構造として読める。`III7 → VIm` と `I7 → IV` で異なる到達点を一続きに配置する。三和音中心の歌謡曲的な進行を保ちながら、二か所に半音解決を作れる。`I → III7(♭9) → VIm7 → Vm7 → I7 → IVmaj7` とすると、後半は丸サ系の折り返しに接近する。

**オンリーワン進行（14536）** — `I → IV → V → III7 → VIm`。

王道の `IV → V → IIIm → VIm` にIを前置し、IIImをIII7にして短調側への導音を与える。冒頭 `I → IV → V` が明るく安定した流れを示すため、`III7 → VIm` の色の変化が目立つ。前半のIを長く取り、後半の `V → III7 → VIm` を短く処理すると、歌の終わりに強い陰影を集中させられる。

**枯葉進行** — `IIm7 → V7 → Imaj7 → IVmaj7 → VIIm7♭5 → III7 → VIm`。

長調の `IIm7 → V7 → Imaj7` と、VImに向かう短調型の `VIIm7♭5 → III7 → VIm` を、途中の `IVmaj7` を介して連結する。根音が五度方向に進むため、次々に到達点を更新する感覚が続く。最後を `VI7` にして `IIm7` へ戻す形も作れる。

**明菜進行／大きゅんメロ進行** — `IIm7 → V7 → Imaj7 → VIm → IIm7 → VIIm7♭5 → III7`。

前半が長調の `II–V–I`、後半がVImへ向かうマイナー型の入口となる。末尾 `VIIm7♭5 → III7` の次にVImを置くと、長調と短調の到達感を一つの長いフレーズ内で交替させられる。**長調へ一度到達してから再び短調へ視点を移す二段構え**が核となる。

**クリスマス進行** — `I → IV → II7 → V7 → III7 → VIm → IIm → V → I`。

`II7 → V7`、`III7 → VIm`、`IIm → V → I` のように、局所的なドミナントと五度方向の帰着が連なる。冒頭の `I → IV` で広げ、途中のVとVImをそれぞれ強め、最後は長調のIへ閉じる。長いメロディの各句末に別の到達点を与えるために利用できる。

**プリキュア進行** — 核は `I → III7 → VIm`。展開例は `I → III7 → VIm → Vm7/♭VII → I7 → IV → I/III → IIm → ♭VI → ♭VII`。

冒頭でVImへ短調型の引力を作り、`Vm7 → I7 → IV` を通じてIVへ視点を移し、終盤で借用和音や下降ベースをつなげる。コンファメ進行と共通する局所ドミナントの仕組みを持つが、冒頭の `VIIm7♭5` の有無、コード尺、後半の変形に差がある。

### 下降ベース・半音クリシェ・借用和音

**サイレントイブ進行** — `VIm → VImMaj7/#V → VIm7/V → II7/#IV → IV → V7 → I`。

低音の `VI → #V → V → #IV` が半音ずつ下降し、VImの和音領域を保ちながら内声の構造が少しずつ変わる。`II7/#IV` はIVへ向かう際の経過低音として働き、IVからV7へ動くことで長調へ抜けられる。元の『サイレント・イヴ』ではマイナーコード内部の下降線が印象的で、同型は冬のバラードに限らず、静かに緊張を蓄積する場面で使える。ベースを半音ずつ動かす間、メロディは長音で保持するなど、変化する役割を伴奏側に置くこともできる。

**落ち葉進行** — `I → IIIm/VII → IIIm7♭5/♭VII → VI7 → IIm → #Iaug → IIm7/I → V7`。

前半のベース `I → VII → ♭VII → VI` と後半の `II → #I → I` が二組の半音下降線を作る。`IIIm/VII` はIIImの第2転回形、`IIIm7♭5/♭VII` は低音をさらに半音下げた和音、`#Iaug` は上声と低音のいずれにも中間音を加えられる対称和音である。個々のコード名を独立に暗記するより、**二つの下降線を繰り返している**ことが全体をまとめる。

**ラピュタ進行／マイナー下降型** — メジャーキーの平行短調VImから始める表記では、`VIm → IIIm/V → IV → I/III → IIm → VIm/I → VII7 → III7 → VIm`。

ベースの `VI → V → IV → III → II → I → VII → III → VI` に長い下降が現れる。冒頭の短調感を保ちながら、最後に `VII7 → III7 → VIm` というドミナントの連鎖で短調へ帰着する。`VIm → IIIm/V` の代わりに `VIm → ♭VII` を置けばモード的な色が強まり、`IV → I/III → IIm` の部分は純情進行と同じ下降設計を共有する。

**始まりの進行** — `I → II/I → IVm/I → I`。

低音Iを保ったまま、上声がIの三和音、IIメジャー、IVm、Iへ入れ替わる。`II/I` の構成音にはIから見た9th・#11th・13thが現れ、`IVm/I` では同主短調由来の♭VIを含む。二つの異なるモード由来の色を同一ベース上で連結し、静止する低音に対して上声だけが遠くへ出かけるような印象を作れる。

**パイレーツ進行** — `Im → IVm → V → Im`。短調の前置・属和音・主和音という簡潔な構造。`V7(♭9) → Im` で強める方法、`IVm6` で半音を加える方法によって、同じ骨格に異なる質感を作れる。

**ファンタジー進行** — `Im → IV → ♭VI → ♭VII`。

Imの短3rdを保持しながら、ドリアン的なIVメジャーで長6度を示し、後半で自然短音階由来の♭VI・♭VIIへ移る。短調の中に複数のモードの色が入ることが特徴で、`♭VII → Im` なら同じ短調中心を保ち、`♭VII → I` とすれば同主長調へ抜けることもできる。主音に対する6thが自然か♭かという違いが、旋律と和音の間で動いている。

### 現代アニソン・アイドル音楽の特徴的な和音

**ラムネ進行** — `III7 → Vm7 → VI7`、または核となる `III7 → Vm7`。

通常の `III7 → VIm` ならVImへ半音で解決するが、ここでは進行先がVmへ横滑りするため、III7が作った期待が別の和音へ移る。`Vm7 → VI7` は次のIImなどへ向かう準備にもなり、短い区間で調性感を折り曲げられる。

**カフネ進行** — `IVmaj9 → III7(#9) → IIIm7/VI → Vm9 → Iaug`。

最初はIVの長7thと9thで上声を開き、III7(#9)で強い変化テンションを置く。その次の `IIIm7/VI` は、VIをベースにした11thや9thを含むsus系の響きとしても聞ける。`Vm9` から `Iaug` を経由してIVへ戻ると、IVへの接続に半音の変化と緊張が生まれる。メロディと上声の取り方が響きを大きく左右する。楽曲内ではほかにも `Iaug/♭VII` 系の変化が現れ、augと分数コードを単なる装飾以上の接続手段として聴ける。

**にゃんぼりー進行** — `I → ♭V@ → IVmaj7 → ♭VII@`。

`@` は第2章で扱ったBlackadder Chordを示す略号。`♭V@` は `Iaug/♭V`、`♭VII@` は `Iaug/♭VII` と異名同音で構成できる。ベースは `I → ♭V → IV → ♭VII` と動き、その上に特殊な増三和音の色を置く。`I → ♭V@ → IV` は半音下降するベースによってIVへ近づき、`IV → ♭VII@` は借用和音に近い色を持つ別の緊張を作る。

**YOASOBI進行** — `IV → V → IIIm7 → VIm7 → IIm7 → III7 → VIm → Vm7 → I7`。

最初の4コードは王道進行で、そこから `IIm7 → III7 → VIm` とVImを再び強調し、最後の `Vm7 → I7` で次周のIVに戻る準備をする。旋律・コード尺によっては `IIm7 → III7` の接続の方が主要な効果となる。全体は**王道の反復、短調の局所帰着、IVへの折り返し**という三つのまとまりに分けて扱える。

**範囲の広い呼称。** 「アニソン進行」「シティポップ進行」「感動進行」「バロック進行」などは、単一のコード列ではなく複数の構造の総称として使われる。具体的な和声の運動としては、アニソン系なら王道・コンファメ・借用系、シティポップ系なら丸サやテンションを含む循環、バロック系なら短調の下降低音やドミナント連鎖にあたる。

### 日本の楽曲分析で見る組合せ

**Official髭男dism『LADY』。** 公開分析では、`I → IVmaj7 → III7 → VIm` におけるVImへのセカンダリードミナント、`IIm7 → IIm7/V` という上声を保ったドミナント、`VIm → VIm/#V → VIm/V → #IVm7♭5` の下降ベース、`IV → IVm → I/III` の借用、`IVmaj7 → IVmMaj7 → IIIm7` の内声の半音下降が確認できる。同じメロディを繰り返す箇所に借用和音を置くこと、トニックの代理をテンションを含む分数コードへ置き換えることによって、コードの密度と歌の印象を変えている。[エルエミュージックによる分析](https://er-music.jp/analysis/936/)。

**YOASOBI『もう少しだけ』。** カノン進行の長い骨格を保ち、転回形でベースを下降させ、セクションによって王道進行を重ねる。`IV → V → IIIm → VIm7` の短いまとまりは、その前後のコード尺と終止によって独立したサビの推進にも、長いカノン循環の一部にもなる。`V → VI` の間でパッシングdimを使うなど、基本の骨格を保ちながら小節内部の細かい動きを作っている。[エルエミュージックによる分析](https://er-music.jp/analysis/1576/)。

**『ラムネ色 青春』。** 公開コード譜では、`I → Iaug → I6 → I7` の上昇クリシェに続き、分数augや`III7 → Vm7 → VI7` 系の動きが確認できる。単純な三和音の反復を土台としながら、内声を半音で上げる操作と通常の到達先を変える操作を併せることで、明るい曲想の中にも変化のある和声を実現する。[ChordWikiの掲載譜](https://ja.chordwiki.org/wiki/%E3%83%A9%E3%83%A0%E3%83%8D%E8%89%B2%2B%E9%9D%92%E6%98%A5)。

**『CAFUNÉ』。** `IVmaj9 → III7(#9) → IIIm7/VI → Vm9 → Iaug` では、上声に和音の構成音が次々と現れ、ベースは和音本体から独立して動く。次のIVへの折り返しにaugが働き、響きの選択とループの接続が結び付く。7thとテンションが多いこと以上に、コードの短い配分で音がどこへ移るかが特徴である。[ChordWikiの掲載譜](https://ja.chordwiki.org/wiki/CAFUN%C3%89)。

**DIALOGUE+『にゃんぼりーdeモッフィー!!』と『ようこそジャパリパークへ』。** 前者は `I → ♭V@ → IVmaj7 → ♭VII@` に二つのBlackadderを組み込み、後者の複数アレンジでは `VIm7 → Vm7 → I7 → IV` に至る途中へ特異なオンコードを挿入する形が確認できる。同じ四音集合でも、IVの直前で半音下降させるか、別のベースラインの途中に置くかによって用途は変わる。[Blackadder Chord@wiki：にゃんぼりー](https://w.atwiki.jp/ixgchord/pages/101.html)、[ようこそジャパリパークへ](https://w.atwiki.jp/ixgchord/pages/27.html)。

こうした現代のJ-POP・アニソンの和声は、既存の機能進行を基礎として、オンコード、内声の半音、代理ドミナント、テンション、コード尺の細分化を**同じ短い区間に積み重ねる**例として理解できる。構造が複雑に見えても、到達するコードと継続する旋律を見分ければ、作曲のための選択肢として再利用できる。

## 7. 楽曲への応用と参照表

### 同じ進行を発展させる

次の三つは、**同じ骨格を作曲上どのように展開できるか**を示す構成例である。

**王道進行を旋律とベースに合わせて展開する**

```text
基本       | IV        | V          | IIIm       | VIm      |
拡張       | IVmaj9    | V7sus4(9)  | III7(♭9)   | VIm9     |
ベース方向 | IV        | V          | III        | VI       |
```

`IVmaj9` はIVを柔らかく開始させ、`V7sus4(9)` はドミナントの3rdを保留する。`III7(♭9)` は `VIm9` の直前に局所的な導音と♭9thを作り、短調側への引力を強める。`V7sus4(9)` と `III7(♭9)` の上声を近接配置すれば、コードが大きく変わっても旋律線の連続を保てる。ここでは元の `IIIm` をドミナント型に変えているため、王道進行の感情曲線も変わる。

**丸サ型にサブドミナントマイナーを接続する**

```text
| IVmaj7   IVmMaj7 | IIIm7   VI7 |
| IIm9     V7(♭9)  | Imaj9   I7  |
```

`IVmaj7 → IVmMaj7` では3rdが半音下降する。`IIIm7 → VI7 → IIm9 → V7(♭9) → Imaj9` は五度循環と複数のセカンダリードミナントを含む。最後の `I7` は次周のIVへ戻る。丸サ型の `III7 → VIm7` の代わりに、借用と `III–VI–II–V–I` の経路へ広げた構成で、到達先もVImからIへ変わる。

**コードの数よりもベースと和音の層を変える**

```text
| I         | V/VII       | VIm9      | IIIm7/V   |
| IVmaj7    | IVm6        | I/III     | V7sus4(9) |
```

前半のベースは `I → VII → VI → V` と下降し、後半はIVmの借用によって陰影を加える。`IVm6` は `IIm7♭5` と同じ音集合だが、ここではIVをベースにした色替えとして聴かせる。`I/III` では主和音の3rdをベースへ置き、`V7sus4(9)` で3rdを保留した状態から次周期のIへ戻す。複雑さの中心はコードの希少性より、**低音の線、内声の半音、解決の保留**にある。

### 和声とセクションの設計

セクションごとに全く別の進行を用意する以外に、**共通の和声素材を、軸ごとに異なる設定で配置する**方法がある。セクション間の対比は、次の軸のどれを動かし、どれを据え置くかの組合せで生まれる。

| 軸                 | 動かすと起こること                                                                                               | 例                                                                        |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 和声の変化量       | 1コードを長く保持すると、ベース・リズム・旋律が前に出る。コードを細かく替えると、和声そのものが推進を担う        | `VIm9` の保持と、`IVmaj7 → #IVm7♭5 → V7sus4 → III7` の比較                |
| 局所的な到達点     | 局所ドミナントや半音上行を集めると、次の区間の冒頭への期待が高まる。どこを目標にするかで、次の区間の入口が変わる | `III7` で `VIm` を目標にするか、`V7` で `I` を目標にするか                |
| 反復の把握しやすさ | 短い循環を繰り返すと、聴き手の注意が上声・低音・旋律の変化へ移る                                                 | `IVmaj7 → V → IIIm7 → VIm7` の反復に、上声の9thや低音のアプローチを加える |
| 機能・モード       | 機能やモードを部分的に変えると、旋律が同じでも景色が切り替わる。共通音を軸にすれば、旋律を引き継いだまま移れる   | `♭VImaj7 → ♭VII7 → Imaj7`、`Imaj7(#11) ↔ II/I`、同品質の半音平行移動      |
| 伴奏の音数         | 旋律が高い音域で動く区間で伴奏の音数を減らすと、旋律中のテンションが和声として聴こえる                           | 上声を3rd・7thだけに絞り、9thは旋律に任せる                               |

どの軸をどのセクションに割り当てるかは曲ごとに決まる。コードが少ない区間でも、歌やリズムの密度が上がれば大きく展開する。

### 数字ラベルと回転形

数字ラベルは四つの根音を短く記す呼び方で、コードの長短・テンション・転回形・コード尺はそこに含まれない。`4536` は王道、`1564` はポップパンク系、`6415` と `4156` は1564の回転形、`1645` は50s、`1625` は五度循環、`14536` はオンリーワン系、`4361` は丸サ系の一形態、`456` はIV–V–VIm系を指す。ほかに `4516`（`IV → V → I → VIm`）、`4561`（`IV → V → VIm → I`）、`4563`（`IV → V → VIm → IIIm`）といった系列もある。数字が共通でも、最後から最初への接続を変えると、ループの着地と次の始まりの聞こえ方は変わる。

### 変化させたい音から引く

この表は**コード名からではなく、楽曲で起こしたい音の変化から**引くための索引。具体的な声部の説明は各本文に集約している。

| 起こしたい変化                   | 手法・コード例                           | 主に変わるもの            |
| -------------------------------- | ---------------------------------------- | ------------------------- |
| 1音の半音下降で陰影を増やす      | `IV → IVm → I`、`IVmaj7 → IVmMaj7`       | 内声の3rd                 |
| 1音の半音上昇で次へつなぐ        | `I → Iaug → VIm`、`I → #Idim7 → IIm7`    | 5thまたは根音             |
| 短調の着地を強く示す             | `III7(♭9) → VIm`、`IIm7♭5 → V7(♭9) → Im` | 導音・ドミナントの7th     |
| 主和音の上を静かに広げる         | `Iadd9`、`Imaj9`、`I6(9)`                | 高音域の9th・6th・7th     |
| 主和音に浮遊感を残す             | `Imaj7(#11)`、`II/I`                     | #11th・長七・ベースの固定 |
| ドミナントの解決を穏やかにする   | `IIm7/V`、`IV/V`、`V7sus4(9)`            | ドミナントの3rdの保留     |
| 帰着を半音下降のベースで作る     | `IIm7 → ♭II7 → Imaj7`                    | ベース `II → ♭II → I`     |
| 普通のドミナント以外から帰る     | `IVm7 → ♭VII7 → Imaj7`                   | 借用和音・バックドア      |
| コードの種類を増やさず流れを作る | `I → V/VII → VIm → IIIm/V → IV`          | ベースライン              |
| ループの最後から最初を強く結ぶ   | `… → I7                                  | IVmaj7 → …`               | 次周期への局所ドミナント |
| 調を大きく色替えする             | `I → ♭VI`、`I → ♭III`、同品質の平行移動  | 共通音と調外和音          |
| 同じマイナー中心で表情を変える   | `Im7 ↔ IV7` と `IIm7♭5 → V7 → Im`        | モード中心／機能的終止    |
