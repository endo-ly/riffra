## 1. 表記

度数はローマ数字で書き、コード品質は`m`、`7`、`dim`、`♭`などで添えて明示する。ローマ数字の大文字・小文字にコード品質を持たせない（C majorなら`IIm`=Dm、`III7`=E7、`♭VII`=B♭）。`IIIm`、`III`、`III7`はそれぞれ別のコードとして扱う。分数コードは、`V/III`のような機能表記と混同しないため、ベース音を実音で`G/B`のようにコードネームで併記する。

## 2. 基本構造

コード進行が成立する基本原理は、次の4つに整理する。

| 原理         | 中心となる問い                   |
| ------------ | -------------------------------- |
| **機能**     | どこから離れ、どこへ帰るか       |
| **根音運動** | 根音がどの音程関係で移動するか   |
| **声部進行** | 各音が次の和音へどう移るか       |
| **反復構造** | 複数コードの規則をどう反復するか |

1つの進行では複数の原理が同時に働く。分類の目的は1つに決めつけることではなく、進行を支えている構造を分解して捉えることにある。

### 2.1 機能

機能は、現在のトニックに対するコードの役割を見る。

| 記号 | 名称           | 主な役割                     | 代表例        |
| ---- | -------------- | ---------------------------- | ------------- |
| `T`  | トニック       | 中心・安定・帰着             | `I`           |
| `S`  | サブドミナント | 中心から離れる、緊張へ向かう | `IV`, `IIm`   |
| `D`  | ドミナント     | トニックへの強い方向を作る   | `V`, `VIIdim` |

`VIm`、`IIIm` などは前後関係によって働きが変わるため、固定的な機能に閉じ込めない。

#### 基本の流れ

最小の帰着は `D → T`、すなわち `V → I` である。サブドミナントを挟むと `S → D → T`(`IIm → V → I`、`IV → V → I`)になり、出発点まで含めた

```text
T → S  → D → T
I → IV → V → I
```

が機能進行の基本骨格になる。実際のコード列では、各機能を別のコードへ置き換えたり(§3.1)、複数コードへ展開したり(§3.2)できる。

#### 機能の連続

コードが変化しても、より大きな範囲では1つの機能が継続している場合がある(`T → T`、`S → S`、`D → D`)。

#### 帰着の種類

到達先によって進行の閉じ方が変わる。

| 形        | 性格                               |
| --------- | ---------------------------------- |
| `V → I`   | 強い帰着                           |
| `V → VIm` | トニックへの期待を外して継続       |
| `IV → I`  | サブドミナント側からの帰着         |
| `... → V` | ドミナント上で止まり、次を要求する |

機能進行は `T → S → D → T` を一周する必要はなく、必要な部分だけを使える。

### 2.2 根音運動

根音運動は、コード品質とは別に、根音どうしの音程関係を見る。オクターブと反転関係をまとめると、根音間の関係は次の5種類で覆える。

| 根音関係       | 含まれる音程      |
| -------------- | ----------------- |
| **同根**       | 1度 / オクターブ  |
| **2度関係**    | 半音 / 全音       |
| **3度関係**    | 短3度 / 長3度     |
| **4・5度関係** | 完全4度 / 完全5度 |
| **増4度関係**  | トライトーン      |

#### 同根

根音を維持したままコード品質だけを変える(`C → Cm`、`C → C7`、`C → Caug`)。根音の安定を保ちながら内部の音を変化させるため、機能転換や声部進行を作りやすい。

#### 4・5度関係

完全4度上行・完全5度下行は、強い推進を作りやすい。

```text
3   → 6  → 2  → 5  → 1
E   → A  → D  → G  → C    (C を中心に)
IIIm → VIm → IIm → V  → I
```

この列は一部だけを切り出しても使える(`V → I`、`IIm → V → I`、`VIm → IIm → V → I`)。五度関係は機能進行、シークエンス、ターンアラウンド、局所的な主和音化など多くの構造の土台になる。経路の延長と強化は §3.2 で扱う。

#### 3度関係

3度離れた三和音は共通音を持ちやすい(`C ↔ Am`、`C ↔ Em`)。ダイアトニック外へ広げると `C → E`、`C → E♭`、`C → A`、`C → A♭` のように色彩変化の大きい進行になる。五度ほど強い帰着は作らず、共通音を残しながら和声の色を変えやすい。

#### 2度関係

根音を隣接音へ動かし、上行・下行どちらの旋律線にもできる。

```text
I → IIm → IIIm → IV
VIm → V → IV → IIIm
```

半音まで狭めると、より強い局所的な引力が生まれる(`C → B`、`B → B♭`)。

#### 増4度関係

トライトーン離れた根音は、最も遠い関係として強い対比を作る(`C ↔ G♭`)。ドミナント7th同士はトライトーンを構成する重要な2音を共有するため、代理関係として利用できる(§3.3 トライトーン代理)。

#### 対称的な根音循環

一定の音程を繰り返すと、五度循環とは異なる閉じた構造を作れる。

| 周期  | 例                    | 相性           |
| ----- | --------------------- | -------------- |
| 短3度 | `C → E♭ → G♭ → A → C` | ディミニッシュ |
| 長3度 | `C → E → A♭ → C`      | オーギュメント |
| 増4度 | `C → G♭ → C`          |                |

### 2.3 声部進行

声部進行は、コード名ではなく構成音どうしの移動を見る。機能関係や根音関係が弱くても、各声部の動きが明確なら進行全体を強くまとめられる。

#### 共通音

前後のコードで同じ音を保持する。`C`(C E G) と `Am`(A C E) は `C` と `E` を残したまま `G → A` だけを動かせる。共通音の多いコードは滑らかにつながりやすい。

#### 最小移動

各声部を最も近いコードトーンへ移す。`C → Cm` なら `E → E♭` だけを動かし `C` と `G` を保持する。1音の半音移動でも、コードの性格を大きく変えられる。

#### ベースライン

ベースの線を先に作り、それに合うコードを選ぶ。`Bass: C → B → A → G → F` に対して `C → G/B → Am → Em/G → F`。根音進行とベース進行は一致しないことがあり、転回形を使えば根音を保ったまま別のベースラインを作れる(§4.3)。

#### クリシェ

同じ和音領域を保ちながら、1声だけを連続的に動かす。

```text
Am → AmMaj7/G# → Am7/G → D7/F#
Bass: A → G# → G → F#
```

半音下降・半音上昇のどちらも使える。線を先に決めてコードを後から変える発想は §3.6 に繋がる。

#### ペダル

1つの音を固定し、その上または下の和音を変化させる。`Bass F: F → G/F → Am/F → B♭/F` のように、固定音が中心を保ち、その周囲だけが動く。

#### 反行・斜行

ベースと上声を逆方向へ動かしたり、一方を固定して他方だけを動かしたりする。`Bass: C → B → A` に対して上声を `E → F → G` とすると、コード進行を複数の旋律線が交差する構造として設計できる。

### 2.4 反復構造

複数コードのまとまりを反復すると、個々のコード間関係を超えた構造が生まれる。

#### シークエンス

短いモデルを、一定の規則で別の高さへ移して繰り返す(`model → copy → copy`)。最も代表的なのが五度下降型で、§2.2 の `IIIm → VIm → IIm → V → I` がそのまま例になる。移動幅は2度・3度・4・5度・半音と自由である。シークエンスでは各コードを毎回T/S/Dへ当てはめるより、**反復されているモデルと移動幅**を見る。

#### 循環

最後のコードから最初へ戻る接続まで含めて、閉じた進行を作る。

```text
I → V → VIm → IV   (ループ境界: IV → I)
```

循環では、1周の途中に明確な終止がなくても成立する。同じ集合の開始位置を変えると、接続関係を維持したまま重心だけが変わる(`VIm → IV → I → V`、`IV → I → V → VIm`)。回転の操作は §3.7。

#### 往復とモード中心

2つのコードを往復する進行は、終止へ向かうより特定の中心やモードを維持する働きが強い。

| モード     | 往復       |
| ---------- | ---------- |
| Dorian     | `Im ↔ IV`  |
| Mixolydian | `I ↔ ♭VII` |
| Phrygian   | `Im ↔ ♭II` |
| Lydian     | `I ↔ II`   |

ここでは「どのコードがドミナントか」より、どの音を中心として反復しているか、モード固有の特徴音がどこに現れるか、ベースやメロディがどの中心音へ戻るかを見る。同じ2コードでも、メロディ・ベース・反復位置によって中心の聞こえ方は変わる。

#### 中心保持

1つのコードやペダルを長く保ち、周囲の和音だけを変化させる。

```text
I ─────────────
   IV/I  ♭VII/I  II/I
```

機能進行を弱め、中心音・モード・音色を前面に出せる。

## 3. 変形

基本構造を保ちながら、コード進行を別の形へ変える主要な方法をまとめる。各変形が§2のどの原理を軸にしているかを意識すると、複数の変形を矛盾なく組み合わせられる。

### 3.1 機能を保つ置換

同じ機能を担えるコードへ交換する。

```text
S: IV ↔ IIm     D: V ↔ VIIdim
```

トニック周辺では `I`・`VIm`・`IIIm` が近い働きをする場面があるが、3つを常に同じものとして扱わない。`I → VIm → IV → V` の `IV` を `IIm` へ置き換えても機能の大きな流れは保たれ、根音・共通音・ベースラインだけが変わる。

### 3.2 到達経路の展開

同じ到達点へ向かう経路を長くする操作群である。いずれも**局所的な主和音化**、すなわち途中のコードを一時的な到達点として強調する手法であり、進行全体のトニックは変わらない。短時間で終われば元のトニックへ戻る。

#### 五度方向への延長・圧縮

```text
V → I
IIm → V → I
VIm → IIm → V → I
IIIm → VIm → IIm → V → I
```

必要な長さに応じて、同じ根音骨格を伸縮できる。

#### セカンダリードミナント

到達先の直前に、そのコードを一時的なトニックと見たドミナントを置く。

```text
III7 → VIm
VI7  → IIm
II7  → V
I7   → IV
```

五度連鎖の各リンクをこの方法で強めると、根音の骨格を保ったまま `III7 → VI7 → II7 → V7 → I` のような強い推進になる。

#### セカンダリー・リーディングトーン

到達先の半音下を根音とするディミニッシュ系コードを置く。`#IVdim7 → V`、`#Vdim7 → VIm`。半音解決と対称的なdim7の構造で、次のコードを強く指し示す。

#### リレーテッドII–V

セカンダリードミナントの前に、その局所的な `IIm` を置いて二段階にする。`III7 → VIm` を `VIIm7♭5 → III7 → VIm` へ展開する。メジャー系の到達先では、`Vm7 → I7 → IV` のような形も作れる。

### 3.3 ドミナントの置換

ドミナント機能やガイドトーンを保ちながら、別のコードへ置き換える。

#### トライトーン代理

`V7` とトライトーン離れた `♭II7` は、3rdと7thに相当する重要な2音を共有できる。Cへの解決なら `G7 → C` を `D♭7 → C` へ置き換えられる。根音は半音下降になり、通常の五度解決とは異なるベースラインを作る。連続するドミナント列 `E7 → A7 → D7 → G7` の一部を置換すると、`E7 → E♭7 → D7 → D♭7` のようなクロマティック下降も作れる。

#### バックドア型

トニックへ `♭VII7 → I` と進む(`B♭7 → C`)。`IVm` 系の借用和音と近い構成音を持ち、通常の `V7 → I` とは異なる方向からトニックへ戻れる。

### 3.4 調の外との接続

現在のトニックを保ちながら、平行調・同主調・モードなどからコードを取り込む。

#### 借用和音

```text
IV → IVm → I
♭VI → ♭VII → I
I → Vm → I7 → IV
♭III → IV → I
```

借用和音は、ダイアトニック内にはない根音・コード品質・半音進行を追加する。重要なのは「どの調から借りたか」だけではなく、前後のコードとの共通音・半音移動・到達方向を見ることである。

#### ♭II と増6系

ドミナント `V` へ向かう側をクロマティックに強める。トニックから見た `♭II` を `V` の前に置くと `♭II → V → I`(C中心で `D♭ → G → C`)となり、`♭2` や `♭6` の半音進行が `V` 周辺へ収束するため、通常の `IIm / IV → V` とは違う強い色を作る。`♭6` と `#4` を両側から `5` へ半音で収束させる増6系の響きも同じ原理である。どちらもコード名よりも、`V` へ向かう声部の収束を見ると理解しやすい。

#### クロマティック・メディアント

根音が長3度または短3度離れ、ダイアトニック外のコードを含む三度関係(`C → E`、`C → E♭`、`C → A`、`C → A♭`)。同じ品質のmajor同士、minor同士で使うことも多い。3度関係の共通音を残しながら調性感を大きく変化させられ、連続すると長3度周期・短3度周期の対称構造にも接続できる(§2.2)。

### 3.5 対称構造による接続

#### ディミニッシュ

ディミニッシュコードは対称性と半音解決を利用して、多方向へ接続できる。

- **リーディングトーン型**: 到達先の半音下から入る(`Bdim7 → C`)
- **経過型**: 根音の間を半音でつなぐ(`C → C#dim7 → Dm`、`C/E → E♭dim7 → Dm`)
- **共通音型**: 前後のコードと1音以上を共有しながら、残りの音を半音で動かす

同じdim7は転回・異名同音によって複数の到達先を持てるため、遠いコードや別のトニックへの接続にも使える。

#### オーギュメント

オーギュメントトライアドは長3度を等分した対称構造を持つ(`Caug = C E G#`)。各構成音を半音ずつ動かすと複数のmajor / minorコードへ接続できる(`C → Caug → Am`、`C → Caug → F`)。ベースや内声の半音進行を作る中間和音として使いやすく、長3度周期と組み合わせると、通常の五度関係とは異なる進行を構成できる。

### 3.6 線とボイシングの再設計

#### 平行移動

同じコード品質やボイシングを保ったまま、和音全体を同じ方向へ動かす。

```text
Cmaj7 → Dmaj7 → Emaj7
Cm7   → D♭m7  → Dm7
Cm9   → E♭m9  → G♭m9
```

移動幅は全音・半音・3度など自由である。機能的な解決より、同じ響きの形が移動すること自体が進行の統一原理になる。

#### クリシェ・ペダルによるリハーモナイズ

先に線または固定音を決め、それを満たすようにコードを変える。下降クリシェ `Am → AmMaj7/G# → Am7/G → D7/F#`(§2.3)、上昇クリシェ `C → Caug → C6 → C7`、ペダル `C → D/C → F/C → C`。このタイプでは、コード機能よりも線の連続性や固定音が進行全体をまとめる。

### 3.7 反復構造の変形

#### ループの回転

同じコード集合の開始位置をずらす。`I → V → VIm → IV` を `VIm → IV → I → V` へ回転すると、集合は同じでも各コードの聞こえ方とループの重心が変わる(§2.4)。

#### シークエンスのクロマティック化

ダイアトニックな根音列を保ち、コード品質だけを変える。`IIIm → VIm → IIm → V → I` を `III7 → VI7 → II7 → V7 → I` へ変えると、反復の推進力が強まる。シークエンス自体の延長・短縮は §3.2 に同じである。

### 3.8 転調

新しいトニックが継続的に中心として成立すると、進行全体の基準が変わる。主な接続方法は次の通り。

| 方法               | 構造                                       |
| ------------------ | ------------------------------------------ |
| **共通コード**     | 旧調と新調の両方に属するコードを境目にする |
| **直接**           | 準備コードを共有せず新しいトニックへ移る   |
| **ドミナント経由** | 新しいトニックのドミナントを先に置く       |
| **共通音**         | 旧和音と新和音の共有音を軸に移る           |
| **シークエンス**   | 反復モデルそのものを別の調へ運ぶ           |
| **異名同音**       | dim7やaug6などを別の意味へ読み替える       |

転調後は、同じコードでも度数と機能を新しいトニックから読み直す。

## 4. コード尺とベース

コードの順序だけでは進行は決まらない。コード尺とベースは、ほぼすべての進行構造に横断的に作用する。

### 4.1 コード尺

同じコード列でも、長さが変われば進行感は変わる。

```text
| C | Am | F | G |     1コード1小節
| C Am | F G |        2小節で1周期
| C | Am F | G |      分割と保持の混在
```

コードが変わる頻度を上げると進行感が細かくなり、長く保持すると1コードの重みが増す。

### 4.2 区間の分割と統合

1つのコードが占めていた時間を複数コードへ分けると、`| C | G | Am |` が `| C | Bm7♭5 E7 | Am |` のようになる。`Bm7♭5 → E7` の2コード全体で元の `G` と同じ時間幅を使うため、進行の大きな周期を保ったまま内部だけを細分化できる。逆に複数コードを1コードへ統合すると(`| A B | C |` → `| X | C |`)、細かい推進を減らして大きな和声単位を強調できる。

### 4.3 転回形と分数コード

転回形は根音を変えずにベースだけを変える。`C → G → Am → Em → F` を `C → G/B → Am → Em/G → F` へ変えると、根音進行は同じままベースが `C → B → A → G → F` と滑らかになる。ベース音をコードの構成音以外へ広げる分数コード(`G/F`、`D/C`、`B♭/C`)は、ペダルや経過ベースを作れ、コード機能よりもベースラインを優先して選ばれる場合がある。

## 5. 分析の要点

コード進行を見るときは、すべてをT/S/Dだけで説明しようとしない。まず、進行の中心を作っているものを確認する。

| 見えている現象                   | 主に見るもの                |
| -------------------------------- | --------------------------- |
| 緊張してトニックへ戻る           | 機能                        |
| 根音が5度ずつ連なる              | 根音運動 / シークエンス     |
| 3度関係を飛び回る                | 共通音 / 三度進行           |
| 半音ずつ滑る                     | 声部進行                    |
| 同じ形のコードが移動する         | 平行移動                    |
| 数コードが繰り返される           | 循環                        |
| 同じモデルが高さを変えて反復する | シークエンス                |
| 1音が固定される                  | ペダル                      |
| 一時的に別コードへ強く引かれる   | 局所的な主和音化            |
| 新しい中心が継続する             | 転調                        |
| ダイアトニック外のコードが混ざる | 借用 / クロマティックな接続 |
| コード数だけ急に増える           | コード尺の分割              |

多くの進行は複数の構造を同時に持つ。たとえば `Bm7♭5 → E7 → Am` は、`Am` への局所的な主和音化、`B → E → A` の五度連鎖、半音を含む滑らかな声部進行を同時に持つ。`C → G/B → Am → Em/G → F` は、ダイアトニックなコード進行・下降ベース・共通音の3層が重なって成立している(§2.3、§4.3)。

コード進行は単一の理論へ還元するより、**機能・根音・声部・反復・クロマティックな変形・時間構造のどれが実際に支配的か**を見て捉える。
